## 设计语言（只进 `agentHub.css`）

- 强调色：`--tide1`，不要第二套品牌色，不要稿子近白当主按钮色。
- 背景网格 + 顶光可以留在**本页**，不要泄漏到对话/办公。
- 玻璃描边可以留。
- 动效只三种：状态呼吸、进度环、hover 位移。
- 路径/耗时/token 用等宽（`--mono`）。

## 页面（页内 Tab，不是顶栏）

1. **工作台**：Hero → 胶囊 → 命令台 → 进行中任务条  
2. **任务中心**：四统计卡 + **筛选** + 任务行（取消/重跑）  
3. **任务详情**：徽章 + 左时间线右产物 + 退出码  
4. **产物中心**：卡片网格 + 扩展名筛选  

## 必须补的控件（开发时做，不必改 HTML 演示）

状态灯、安装引导、筛选条、取消、退出码、额度说明、探测失败不可点执行、`App.tsx` 显式路由（否则会打开供应商页）。

V1.3.2 工作台还要有 **添加文件 / 添加资料夹** 和 inbox chip（见 `lunitide-agent-hub-三场景-prd.md`）。不要做成「请自己去资源管理器拷」。
