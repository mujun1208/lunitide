## 1. 设计定位与视觉参考

### 1.1 参考风格解构（DoF Embodied AI Maps）

用户指定的参考海报可提炼 6 个视觉基因，全部继承：

| 基因 | 参考海报做法 | 本设计落地 |
|---|---|---|
| 深色知识材质 | 近黑底 + 卡片分层 | `--ph-bg #0A0A14` + 两级卡片（§3.1） |
| 分节编号 | A/B/C 大写字母 + 标题 + 英文角标 | 分节标题组件（§3.4.1），全站统一 |
| 顶部流程管线 | 横向主流程图作为视觉锚点 | 调用链路 SVG 置于功能卡上部（§4.5） |
| 底部要点条 | bullet 总结收尾 | 功能卡/海报要点区（§4.4 / §4.7） |
| 双语标注 | 中文主 + 英文辅助小字 | 页面/分节/节点统一双语 |
| 克制强调色 | 双主色 + 语义色仅表状态 | 紫/青主色 + 绿/黄/红语义色（§3.1） |

**有意不采用**：渐变、霓虹发光、噪点纹理（与扁平化视觉契约冲突）——以信息密度与层次替代装饰。

### 1.2 设计原则

1. **知识材质而非工作界面**：产品总览是"读"的页面，密度优先于留白，一屏说完一个主题。
2. **流程即主体**：链路图是功能卡的视觉中心，占卡内最大面积。
3. **双语锚点**：所有标题带英文角标，便于检索与国际化预留。
4. **固定深色**：本页面为知识材料展示形态，不随应用主题切换（§8.6）；导出海报/HTML 同源同色，所见即所得。

### 1.3 页面清单

| 页面 | 组件（PRD §7） | PRD Section |
|---|---|---|
| P1 产品总览（三标签） | ProductHubPage + OverviewTab / GraphTab / AnatomyTab | S2-S4、S7 |
| P2 功能知识卡 | FeatureCardPage | S5 |
| P3 调用链路（内嵌 + 全屏） | ChainFlowView | S6 |
| P4 变更时间线（右抽屉） | ChangelogPanel | S9 |

| P6 诊断报告（第四标签） | DiagnosticsTab | S11 |

## 2. 信息架构与导航

### 2.1 入口（S1）

左侧栏「办公」组现有 5 项之后追加第 6 项：

```
办公
├─ 办公工作台
├─ 自动化
├─ 同事聊天
├─ 机务工作台
├─ 会议记录
└─ ◈ 产品总览  Product Hub        ← 新增（page='productHub'）
```

- 图标 `◈`：内联 SVG 线性图标（stroke 1.5），与现有办公组图标风格一致
- `officeOpen` 展开条件增加 `page === 'productHub'`
- 不改动组内其他按钮与排序（零侵入，PRD 验收标准 1）

### 2.2 钻取路径

```
P1 产品总览
 ├─ Tab1 功能全景 ── 模块行展开 → 功能列表行 ──→ P2 功能卡
 ├─ Tab2 知识图谱 ── Feature 节点点击 ──→ P2 功能卡
 ├─ Tab3 解剖视图 ── 资产点击 ──→ 详情条（不跳页）
 ├─ 页头搜索 ── 结果点击 ──→ P2 功能卡 / 图谱定位
 ├─ 页头「变更」──→ P4 抽屉
 └─ Tab4 诊断报告 ──→ P6（页内第四标签，见 §4.8）
P2 功能知识卡
 ├─ 链路图「全屏」──→ P3 overlay（ESC 返回）
 ├─ 面包屑 ──→ 返回任意层级
 └─ 属性 chip 点击 ──→ 图谱内定位该资产
```

面包屑：`产品总览 / {域名} / {模块名} / {功能名}`，分隔符 `/` mono dim。

### 2.3 ESC 语义（遵循用户既定交互偏好）

按优先级退出当前层：**P3 全屏 → P4 抽屉 → P2 返回 P1（保留原标签）→ P1 无操作**（左侧栏由应用全局处理）。

### 2.4 深链

`page='productHub'` 支持可选参数 `?domain=&module=&feature=`（stable_key 值），供变更时间线「查看功能卡」与外部通知直达。

## 3. 视觉规范

### 3.1 色彩 Token（固定深色，独立命名空间 `--ph-*`）

```css
/* web/src/productHub/productHub.css */
:root {
  /* 表面 */
  --ph-bg: #0A0A14;        /* 页面底 */
  --ph-card: #12121F;      /* 一级卡片 */
  --ph-card-2: #171728;    /* 嵌套区域 / 行 hover */
  /* 文字 */
  --ph-text: #E8E8F2;
  --ph-dim: #9C9CB0;
  /* 线 */
  --ph-line: rgba(139, 124, 246, 0.22);
  /* 主色 */
  --ph-brand: #8B7CF6;     /* 紫：品牌 / 主干边 / 选中 */
  --ph-brand-2: #A78BFA;   /* 紫-亮：hover */
  --ph-cyan: #22D3EE;      /* 青：分节编号 / 次强调 / 联动高亮 */
  /* 语义色（仅状态） */
  --ph-ok: #34D399;        /* 成功 / 通过 / 新增 */
  --ph-warn: #FBBF24;      /* 失败分支 / 警告 / 超时 */
  --ph-danger: #F87171;    /* 弃用 / 构建失败 */
  /* 字体 */
  --ph-font: "Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", system-ui, sans-serif;
  --ph-font-display: "Segoe UI Variable Display", "Segoe UI", "Microsoft YaHei UI", sans-serif;
  --ph-mono: "Cascadia Mono", "JetBrains Mono", Consolas, "Courier New", monospace;
  /* 圆角 */
  --ph-r-card: 12px;
  --ph-r-inner: 8px;
  --ph-r-pill: 999px;
}
```

颜色使用规则：

- 卡片底永远中性（`--ph-card` / `--ph-card-2`），**禁止**品牌色/语义色作大面积填充
- 语义色只出现在边框、文字、图标、徽章、链路边——即"状态"本身
- 紫 = 主干与品牌结构；青 = 编号、次级强调、选中联动；一屏内"会动的强调"只允许一种

### 3.2 字体

| 用途 | 规格 |
|---|---|
| 页面大标题 | `--ph-font-display` 20/28 600 |
| 卡头 / 功能名 | 17/24 600 |
| 分节标题 | 15/22 600 |
| 正文 / 描述 | 14/22 400 |
| 辅助 / 角标 | 12/18 400 |
| mono（stable_key / 编号 / 代码） | 12/18 |
| 计数大数字 | 22/26 600 |

- 抗锯齿：`-webkit-font-smoothing: antialiased; text-rendering: optimizeLegibility;`（用户重视字体清晰锐利）
- 最小字号 12（含 mono）；导出海报整体放大 1.5×（§4.7）

### 3.3 间距与尺寸

- 间距阶：**4 / 8 / 12 / 16 / 20 / 24**；页面左右留白 24
- 卡片内边距 16；分区间距 20
- 行高：模块行 44、讲解行 28、属性行 32、roster 行 32
- 页头高 64；Tab 条高 44；图谱详情条高 96

### 3.4 通用组件规范

#### 3.4.1 分节标题（全站辨识组件）

```
A · 简介                                    SUMMARY
```

- 字母编号：mono 13 600 `--ph-cyan`，占位宽 20
- 中文标题：15/22 600 `--ph-text`
- 英文角标：mono 11 `--ph-dim`，uppercase，letter-spacing 0.08em，右对齐至容器右缘
- 标题下间距 12；内容超过一屏时可加 1px `--ph-line` 分隔线

#### 3.4.2 标签 chip（四类词表）

- 胶囊 `--ph-r-pill`，mono 12，padding 2 8，bg `--ph-card-2`，border 1px `--ph-line`
- 词表前缀色点（4px 圆点）：场景 = cyan / 能力 = brand / 入口 = ok / 状态 = warn
- manual 标签右上角 `✎` 角标；可点击（hover border `--ph-brand`）

#### 3.4.3 徽章

| 徽章 | 样式 |
|---|---|
| 版本 | mono 11 pill，border `--ph-line` |
| provenance（manifest / manifest+probe / manual） | mono 10 pill |
| AI 生成 | 紫边 pill「AI 生成」，仅 LLM 补写字段（PRD §6.11 红线） |
| 探针 | `6/6 ✓`（ok）/ `4/6 !`（warn） |

#### 3.4.4 健康度仪表（页头）

环形 SVG r24 stroke6：≥90% `--ph-brand` / 70-89% `--ph-cyan` / <70% `--ph-warn`；中心百分比 14 600；下方 mono 11 `passed/total`。

#### 3.4.5 探针堆叠条（域卡内）

高 6、圆角 3：通过 = `--ph-brand`、警告 = `--ph-warn`、超时 = `--ph-dim`；右侧 mono 11 `n/m`。

#### 3.4.6 流程节点（链路 SVG）

- **主干**：rect w112 h32 rx8，fill `--ph-card-2`，stroke 1 `--ph-line`；内部两行 = 名称 12/16 600 + detail mono 10 `--ph-dim`；序号 ①-⑧ mono 11 cyan 置左
- **成功**：stroke `--ph-ok` 1.5，名称前缀 `✓` ok
- **失败**：stroke `--ph-warn` 1.5，前缀 `✗` warn
- **降级**：失败样式 + 左上角 `▼` 角标
- **选中 `.sel`**：stroke `--ph-cyan` 2，fill rgba(34,211,238,0.08)
- **hover**：stroke `--ph-brand-2`，过渡 ≤120ms

#### 3.4.7 边与箭头

| 类 | 样式 | 语义 |
|---|---|---|
| `.e-m` | `--ph-brand` 1.5 实线 | 主干顺序 |
| `.e-ok` | `--ph-ok` 1.5 实线 | 成功路径 |
| `.e-f` | `--ph-warn` 1.5 实线 | 失败路径 |
| `.e-rt` | `--ph-ok` 1.5 虚线 5 4 | 重试 |
| `.e-dg` | `--ph-warn` 1.5 虚线 3 3 | 降级 |

- marker（紫/绿/黄三色各一）：`viewBox="0 0 8 8" refX=7 refY=4 markerWidth=8 markerHeight=8 markerUnits=userSpaceOnUse orient=auto`，path `M1 1 L7 4 L1 7 Z`，fill 同边色
- 边走向：圆角折线 / 三次贝塞尔，`stroke-linecap="round" stroke-linejoin="round"`
- 边标签：mono 10 `--ph-dim`，置于边中点，加同色 `--ph-bg` 底垫（rect 4px padding）防压线

#### 3.4.8 图例

横排 11px：`— 主干`（紫实线）`— 成功`（绿实线）`— 失败`（黄实线）`-- 重试`（绿虚线）`·· 降级`（黄虚线）；每项前置 24px 线段样本。

### 4.2 P1 · Tab2 知识图谱（S4）

- 画布：SVG `viewBox="0 0 920 640"`，容器宽 100% 高自适应；小窗口横向滚动（min-width 800）
- **五层布局**（y 为节点顶）：

| 层 | y | 布局 |
|---|---|---|
| L1 Product | 24 | cx 460，w 160 |
| L2 Domain | 120 | 5 个均分 cx [92 276 460 644 828]，w 128 |
| L3 Module / 资产 | 216 起 | 按域分组，最多两列，行距 40 |
| L4 Feature | 360 | 默认折叠（域节点 `+n` 徽章，点击展开本域） |

- **边三色**：contains = `--ph-dim` 1（opacity .6）；uses = `--ph-brand` 1.25；calls = `--ph-cyan` 1.25

- **筛选**：Tab 条右侧 chips（域 / 节点类型 / 标签词表），多选，生效 ≤100ms

### 4.3 P1 · Tab3 解剖视图（S7）

三段纵向：

1. **专家六段卡**（2×3 网格）：人格 / 知识 / 技能 / 风格 / 约束 / 记忆；每卡 = 专家名 + 段名（分节标题样式）+ 内容摘要 + 版本链（mono 11）+ 相位挂载徽章
2. **插件 roster 表**（23 行）：名称 / provides / 版本 / 状态点（ok = ready，warn = degraded）；行高 32，表头 sticky
3. **设置控制组**（18 分类 chips 网格）：每 chip = 分类名 + 挂载模块数；点击展开该分类 ↔ 模块双向映射两列小表（缺失映射标 warn，对应探针 settingsCoverage）

## 5. 交互规范

### 5.1 通用

- hover / active 过渡 ≤120ms ease；面板滑入 260ms
- 所有可点元素 cursor pointer + `:focus-visible` 焦点环（2px `--ph-brand`，offset 2）
- 图谱/链路渲染与筛选响应 ≤100ms（数据量 <5k 节点，PRD §6.10 性能预算）

### 5.2 链路图 ↔ 讲解联动（核心交互，Demo 已验证）

- 点击链路节点 → 节点 `.sel`（cyan 描边）+ 讲解区对应行 `.hl`（bg `--ph-card-2` + 左边框 2px cyan）并 `scrollIntoView({block:'nearest'})`
- 反向：点击讲解行 → 高亮对应节点
- 实现：讲解行 `data-step="{branch_type}-{seq}"`，事件委托，不逐行绑监听

### 5.3 刷新与构建反馈

- 点击刷新 → 按钮 spinner + 页头状态点 cyan 脉冲 + 「构建中」；完成 toast「快照已更新」
- 30s 内重复点击 → toast 警告「30s 内仅可手动重建一次」（PH-005）

### 5.4 搜索

- ≥2 字符触发；匹配 name / name_en / stable_key / summary / 标签
- 下拉分组：功能卡 / 模块 / 资产（各 ≤5 条 + 总数）；↑↓ 选择、Enter 跳转、Esc 关闭

### 5.5 导出

- 下拉选择 → 生成中（按钮 spinner）→ toast「已导出：{路径}」
