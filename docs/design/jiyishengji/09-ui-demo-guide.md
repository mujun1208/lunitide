# R3 UI 融合交互原型：简约品牌版

日期：2026-09-15。定位：**供用户确认视觉和交互方向的原型，不是已实现的产品功能。** V2 根据现有 Lunitide 截图复核后重做，替代 V1“深蓝灰设置后台”方向。

## 打开方式

双击 [ui-demo/index.html](ui-demo/index.html)，用 Edge 或 Chrome 打开。单个 HTML 包含样式、脚本与 SVG 图标，无需安装依赖或联网。

所有修改只存在当前页面内存中，刷新恢复初始示例。页面不写产品数据库或浏览器存储，不请求模型、不下载 OCR 包、不读取麦克风、不播放真实音频，并通过内容安全策略禁止网络连接和媒体加载。

本次只修改 UI 原型、验证脚本和相关设计说明；没有修改正式产品源码。

## V2 设计结论

### 品牌视觉

- 主背景使用现有产品的纯黑，侧栏使用接近黑色；不再以深蓝灰卡片铺满页面。
- 薄荷绿—蓝灰—电光紫光场只用于首页和媒体中心两个品牌焦点；记忆、OCR、设置保持克制纯黑。
- 侧栏沿用 `Lunitide / Work / AgentHub`、办公、对话、设置及账户结构，媒体中心加入办公区。
- 取消多数英文眉题、功能胶囊、常驻说明栏和重复的演示声明。
- 每页只有一个主要任务；桌面首屏留出呼吸空间。移动宽度使用单独导航按钮，不依赖隐藏侧栏。

### 智能能力融合与最少设置

正式导航保留现有内部 category id `personal`，用户可见名称为“智能能力”。overview 恰好两张卡：自动记忆、文字识别；不另建 OCR 顶层导航，也不在“路由管理”重复展示。进入详情后才加载对应服务，overview 不预取记忆、项目、provider 或 OCR 状态。

记忆系统默认自动完成：价值判断、问候和天气过滤、去重、适用范围、过期、摘要与召回数量控制。用户只选择：

- 自动记忆（推荐）；
- 仅手动；
- 关闭。

另保留“个人记忆”和“项目记忆”两个开关。来源、纠正、忘记进入单条记忆的“…”详情，不常驻页面。最近变更、审阅、导入导出与清理只从页尾“高级管理”进入，并与设置、单条详情复用同一个抽屉容器。只有真正冲突或隐私授权才打扰用户。

OCR 默认显示“文字识别 · 自动”的只读策略摘要，不是开关，也不表示 Windows OCR 已通过检测。语言、路由、provider、失败回退和旧 PP-OCR 登记放入高级信息。当前原型明确显示 `NO_VERIFIED_RUNTIME_PROFILE` 并禁用 PaddleOCR-VL-1.6 安装；只有真实签名 Windows 完整运行包通过 W0 后，正式产品才能开放安装。

活动中心不再占左侧一级导航，改为顶部安静的“运行状态”入口。正常时只显示绿点，失败、待审批或用户主动查看时才展开。

### 独立媒体体验

- 左侧办公区新增“媒体中心”，与办公工作台、自动化平级。
- 音乐使用独立沉浸页：品牌光场、专辑视觉、标题、来源与核心播放控制。
- 视频使用独立 16:9 剧场表面，不挤进音乐播放器。
- 未开始播放时没有全局播放器；开始播放并离开媒体中心后，右下方出现约 66px 迷你播放器。
- 暂停后迷你播放器保留，方便继续；仅加载但从未开始播放的 idle 会话离页不显示 MiniPlayer。点击关闭后先保留“正在停止”状态，收到原型模拟的已确认终态后才隐藏。
- 不附带音乐或影视内容库；原型中的曲目和画面均是无媒体文件的界面示例。

## 建议体验路径

1. 首页确认视觉是否贴近现有产品：纯黑侧栏、极光主视觉、月亮、对话输入与三个快捷入口。
2. 点击“设置”，确认“智能能力”overview 只有“自动记忆”和“文字识别”两个能力入口。
3. 进入“自动记忆”：单列记忆、搜索、“…”来源/纠正/忘记；设置抽屉仅有三种模式和两个开关；页尾“高级管理”仍复用同一个抽屉。
4. 首页点击“长期偏好”“天气问题”“日常问候”：只有长期偏好新增记忆且自动去重，另两种不保存。
5. 进入“文字识别”：确认没有 WinRT 探针时以警示色显示“尚未检测 / 检查时间：未执行”，不显示就绪，也不提供假重试；Paddle 缺已验证 runtime 时禁用安装；高级区说明旧 PP-OCR 仅登记。
6. 进入“媒体中心”：先看到无会话空态；只加载演示后直接离页仍无 MiniPlayer，明确开始播放后离页才出现；暂停后保留，关闭时等待原型模拟终态再隐藏。音乐与视频分别使用独立表面。
7. 点击顶部“运行状态”：查看“已发送，待核验”与“已确认”的真实状态语义区别。

## 页面与开发合同对照

| V2 区域 | 用户可见内容 | 开发边界 |
|---|---|---|
| 首页 | 现有产品品牌光场、对话入口、3 个快捷入口 | 不改变真实首页业务逻辑；Demo 仅验证视觉衔接 |
| 设置 | 自动记忆、文字识别两个能力卡 | 底层阈值、模型路由、Token 配额不暴露给普通用户 |
| 记忆 | 状态、搜索、单列列表、设置/单条/高级共用抽屉 | 对应 02/03 的来源、纠正、删除保护、作用域与渐进披露合同 |
| OCR | 自动策略/探针边界、增强包禁用态、高级信息 | 对应 04 与 06 C3/C4；本期不新增截图/选文件工作台，真实包门未通过不得开放安装 |
| 媒体中心 | 音乐沉浸页、视频剧场、简洁队列 | 对应 05 与 06 C5；只支持有权播放的媒体来源 |

## 原型边界

- 自动记忆判断是三个预置演示按钮，不是已接入的分类器或 Memory Fabric。任意自由文本不代表真实判断能力。
- 记忆列表、来源、范围、时间和运行状态均为明确标注的示例；不读取用户真实聊天。
- 演示没有真正的过期任务、7 天查询、事务撤销、迁移、跨设备同步或 Token 测量。
- 原型不提供正式 OCR 工作台，不读取屏幕或文件；没有 WinRT probe，也不会下载、检测或运行模型。
- 媒体播放、进度、视频画面及 160ms stop 终态均为页面计时模拟；没有真实后端回执、音频/视频文件、搜索、下载、DRM 或第三方账号授权。模拟等待只能证明交互方向，不能证明产品已实现 stop/release。
- 运行状态是预置场景，不执行电脑操作或外部审批。
- 未覆盖真实 WebView2、完整读屏、迁移、权限、多用户和国际化；不能用 Demo 代替发布验收。
