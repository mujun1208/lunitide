二、可丢弃原型（tools/proto-m9/，独立 go module）

  边界合规声明（DoD：无生产 schema/API/Registry 写入）：
  - 独立模块 tools/proto-m9/go.mod（module github.com/lunitide/lunitide/tools/proto-m9），
    不在主模块依赖图内：主模块 `go list ./...` 零命中 proto-m9（实测），
    生产包结构上无法 import 原型 → 满足"CI 必须拒绝原型依赖进入生产包"。
  - 纯内存实现 + 合成数据；无 SQL、无 Bridge 注册、无 Registry/Runner 连接。
  - 主模块 go build ./... 在原型加入前后均通过（生产面零改动）。

  原型子系统与对应威胁模型/用例种子：
  - IsolationGate       统一拒绝面（跨组织==不存在，存在性零泄漏）+ fail-closed 上下文  T-01/T-02
  - MergeTightenOnly    allow 交集/deny 并集/上限取最小/required 并集 + 放宽拒绝        T-05
  - ApprovalRequest     SoD 自批拒绝/冻结候选/服务身份拒人类门槛/过期失效/撤票回退/主体去重 T-03/04/07/08/09
  - Route + EffectJournal 无安全 Runner 阻断不降级 + UNKNOWN 禁自动重跑副作用            T-13/T-14
  - BudgetLedger        原子预留硬限额 + 幂等结算（重复回执不重复扣款）                  T-15/T-16
  - AuditChain         prev_hash 链 + 篡改检测                                          T-17
  - LegalHoldGate      ACTIVE 保全转受限证据库不物理清除 + 解除后正常删除                T-18
  - PrivacyAggregator  k 阈值低样本抑制                                                 T-20
