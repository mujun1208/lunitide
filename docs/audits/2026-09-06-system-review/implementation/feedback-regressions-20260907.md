## 公共对话链路复核

本机 Host 日志在 08:59:30（上海时间）记录 `engine RPC connection poisoned: unknown Engine frame`，Engine 同时记录认证连接结束后继续运行，说明不是用户必须删除数据库或重装系统。代码中 `handleChatStart` 在正式流建立之前直接发送仅带 type/equip 的事件，正好产生 kind 为空的非法帧。原测试只检查装备标签，未检查完整线协议，因此遗漏了真实桌面失败。

- 将装备事件存入当前流，在统一发送器中补齐版本、类型、ID、流 ID 和连续序号；启动失败时不发送孤立事件。
- Host 补齐 guidance/equip 的载荷校验，与已有前端长度/摘要契约一致；非法跨类型载荷仍拒绝，终态降级时清除其他载荷。
- IPC 发送边界拒绝不完整事件，记录方法/事件类型而非用户正文，避免污染其他请求；每帧更新完整写入期限，避免前一帧期限即将耗尽时截断新帧；一旦发生部分写入失败就关闭损坏连接，禁止继续追加破碎帧。
- 单个请求超时/取消分别显示请求状态，不再统一误报核心引擎不可用。真正断开的连接仍触发原恢复流程。
- 补充输入状态在引擎恢复后重新读取；只清除已经恢复的读取错误，不自动发送、不抹去交付待核对通知。
- 复核发现 Host 仍清除了前端已经支持的 Office/PDF 产物事件。移除过时清理分支，合法工作区路径继续经过校验，可随工具完成事件进入对话；越界路径和无效内容仍移除。

回归分为应用实际事件生产、IPC 帧传输/后续请求、Host 事件验证、前端恢复状态四层。另以 Go overlay 将 chat.go 临时映射到已提交的 0.4.69 原版，不修改工作树，新增回归确实捕获缺少 envelope 的装备事件并失败；当前源码同一回归通过，原始反例记录保存在 evidence/user-regressions-20260907/chat-baseline-reproduction.out。创建技能测试使用隔离适配器与技能服务替身，不调用付费模型，不声称已验证用户 GLM 账号。

## 保留与限制

- 不删除、覆盖或重写用户旧会议原文。修复防止后续识别重复，旧记录中哪些是误写、哪些是真实重复不能仅按文字自动删除。
- Google Drive 授权、运行环境及网络准备属于外部条件；不伪造“已连接”。截图与旧版泛化错误不足以断言 MarkItDown 当次失败的唯一原因，新版保留分类原因以便核对。
- 不自动重放失败自动化，避免重复执行已经发生的操作。新记录保存真实执行会话，旧版未记录关联的历史不能编造关联。
- 麦克风+系统环回、火山可说话打断、其他模式按钮打断、月伴单会话与每周归档等原功能保持。
- 只调整已获授权的能力包滚动及状态提示，不改变对话、月伴等未获授权的外观。

本文件先记录整改内容；最终通过数量、构建与候选哈希在同目录本轮交付回执中记录。没有真实设备、账号和持续运行证据时不将全部功能评为满分。
