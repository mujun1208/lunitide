# 六类能力落地方案与本轮实施范围

日期：2026-09-07。继承本轮全部故障修复，不替换原功能。交付源代码、测试证据和统一复测清单；依用户指令不打包、不安装。本文件需与最终交付回执一起使用，实施过程中的专项通过不代表全系统已验收。

## 对标结论与架构选择

已阅读用户提供的 [竞品分析 HTML](E:/Trae-Work-Projects/6a9e189542eaaabe600fee8d/ai-agent-capability-analysis/ai-agent-capability-analysis.html)。材料用于拆解能力与用户体验，品牌自评分、营销说法和免费描述不直接作为本产品事实。

继续采用现有 Go Host/Engine、React/WebView2、SQLite、同一套工具执行与授权内核。六种能力共用会话、取消、审计、产物和错误回执；文字与三种语音共用工作能力，语音只调整轮次、口头澄清和朗读，不再重配全局电脑控制。

执行优先级如下：有真实结构化数据接口时先用接口；本地文件内容操作先用原生文件/Office 工具；网页操作先用 DOM/可访问元素；Windows 应用先观察 UIA/窗口；自绘界面才用截图定位和鼠标键盘。每次完成必须有真实结果，失败反馈原因，不能把“已派发”当“已完成”。独立检索可由子代理并行；同一个桌面鼠标和浏览器页面不是互相隔离的多代理工作区。

这与 [OpenClaw 的网页工具](https://docs.openclaw.ai/tools/web)、[浏览器能力](https://docs.openclaw.ai/tools/browser)、[Hermes 的搜索](https://hermes-agent.nousresearch.com/docs/user-guide/features/web-search) 与 [浏览器工具](https://hermes-agent.nousresearch.com/docs/user-guide/features/browser/) 在接口、浏览器、工作区和供应商选择上分层的思路相符；本项目直接复用已有内核，不引入第二套 agent 框架。

## 六类能力逐项落实

| 能力 | 本轮落实内容 | 关键验收与真实边界 |
| --- | --- | --- |
| 信息检索 | 新增 weather.get：34,135 个城市离线定位，MET JSON 预报；原网页搜索增加短缓存、来源时间、取消和失败识别；新增 Tushare 官方 MCP 市场预设和路径凭据租用适配 | 天气无 Key；区分预报/实测、城市歧义、日期与缓存时间。Tushare 需个人 Token，基础免费历史日线不等于实时行情；票务没有验证出无账号永久免费报价接口 |
| 电脑 GUI | 保留打开应用、文件、媒体、窗口观察与控制；补右击/双击/组合键、明确元素 ID、负坐标副屏及命中检查 | 根据新观察操作并核对实际结果；保留急停和原授权。不能保证所有自绘控件、UAC、不同软件版本都可直接控制 |
| 浏览器自动化 | 读取实际 MCP schema 适配 target/ref/selector；正确毫秒/秒转换；稳定 endpoint；动作与快照同源；取消、空响应及服务错误明确处理 | 本机 Playwright 不要求付费云浏览器；登录态取决于所用 profile，验证码/网站权限仍需实际处理；不静默切到另一账号页面 |
| 文档内容生成 | Word/PPT/Excel 使用真实完整正文，保留章节、表格、尾部和精确编号；拒绝空占位/超量静默截断；中文 PDF 嵌入免费字体，输出产物可打开 | 生成与回读双向核对，另验 PDF 实际字形。不是对任意复杂 Office 文件无损改写、批注与嵌入对象全部保真的承诺 |
| 文件系统 | 复用路径与授权校验，Office/PDF 文本抽取进入 workspace.read；提供可继续的字符分页；修单文件原子替换及子目录产物回读 | 不把二进制当文本；每次读取适配工具摘要预算；替换失败保留原文件；扫描 PDF 仍需 OCR，多个文件不是一个原子事务 |
| 自动化与系统调度 | 保留 cron、一次性、立即运行、历史与通知；补指定运行取消、IANA 时区和午夜计划；修长任务过早超时与部分输出丢失 | 取消具体运行不误停其他任务，周期与一次性按各自规则继续；旧 UTC 计划不挪时。机器需可运行，单次 20 分钟总限，未新增关机唤醒或入站 webhook 服务 |

## 免费和配置条件

本轮未引入需要购买的桌面、浏览器、文档生成或调度平台。本地工具库、嵌入城市数据与字体可按其许可证使用；免费工具不代表所调用的大模型、商业数据和网站全部零成本。

- **天气**：MET Locationforecast 提供公共预报；城市来自 GeoNames，二者均按 CC BY 4.0 署名。请求使用用户明确授权的客户端联系邮箱；不发送邮件、不携带聊天内容，只发送查询坐标和必要请求标识。保留正常缓存期限，位置保留四位小数，内容最多 1 MiB、单次 12 秒。来源：[MET 条款](https://api.met.no/doc/TermsOfService)、[API 文档](https://api.met.no/weatherapi/locationforecast/2.0/documentation)、[GeoNames 数据说明](https://download.geonames.org/export/dump/readme.txt)。嵌入城市包约 1.82 MB，数据来源、筛选和摘要见 internal/weather/DATA-SOURCE.md。
- **股票**：官方 Tushare MCP 已加入市场，令牌通过原凭据界面保存，地址只存占位模板；运行时才租用凭据，不把完整令牌地址存入端点身份或诊断。免费基础权限只覆盖非复权日线，其他权限由账号实际开通。来源：[官方 MCP](https://tushare.pro/document/1?doc_id=463)、[权限与频次](https://tushare.pro/document/1?doc_id=290)。本轮使用隔离服务验证协议，不伪称查询了用户账号的真实行情。
- **火车票/机票**：保留聚合数据等标准 MCP 接入和任务匹配。未核实到本产品可匿名集成、永久免费且稳定提供真实可售报价/余票的接口；缺少账号或授权时必须说明，不能悄悄改为网页摘要并宣称完成。供应商条件见 [独立复核](six-capability-independent-review-20260907.md)。接入入口、账号权限、真实数据成功是三个不同状态。
- **语音/视频**：本地 Sherpa 可复用已准备好的离线模型；第三方语音和视觉模型费用沿用原配置。公开视频直链处理使用本地 FFmpeg 和抽样，不绕过登录、付费、DRM 或把标题当视频内容。视频实际实现与依赖范围见 [公开视频直链报告](video-direct-content-20260907.md)。

## 执行步骤和验收门槛

1. 保留原用户数据、原三语音路线、月伴单会话/每周归档和已授权 UI 范围，先修断链、卡住和错误终态。
2. 六类能力沿原工具内核增加实际适配和错误处理；数据与字形来源入仓留许可，外部凭据不写入源码。
3. 针对已出现故障编写正确行为回归，覆盖取消、晚回包、断连、路径边界、超量与无权限，不只测试按钮存在。
4. 运行完整前端、完整普通 Go、覆盖率、契约漂移、类型、静态、构建与变更相关并发测试；失败修复后复验，保留失败过程和最终结果，不混算上一版本日志。
5. 更新 [统一复测清单](user-acceptance-checklist-20260907.md)，由用户用真实三语音、音频设备、MCP 账号和目标软件复测。仅记录实际通过，未测项留空。本轮不执行打包安装。

## 4.9 分如何成立

4.9 是验收目标，不能由通过测试数量或补了六类菜单直接换算。需同时满足原功能不回退、已报告代码阻断关闭、输出与真实操作一致、全局权限/数据边界正确，以及清单中的适用功能真机验证。免费票务、任意软件、整片音画、复杂文档无损编辑等没有实现或无法证明的范围不能换名掩盖；对已支持的范围按故障与用例评价。当前分数不提前填写 4.9。
