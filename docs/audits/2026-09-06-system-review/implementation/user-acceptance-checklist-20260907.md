# 本轮问题汇总与用户复测清单

适用范围：本轮 0.4.70 源码整改。按用户要求本轮不打包、不安装、不重启正在运行的应用；当前已安装版本不会自动获得这些源代码修复。完整自动测试数字以本轮交付回执为准。无需卸载或清空聊天、会议、技能及配置。

表内“预期结果”是验收条件，不等于已经完成真机测试。代码自动回归、外部账号/网络联调和设备实测分别记录；旧版没有保存的过程、错误会议原文不伪造补全或自动删除。

**追加范围索引（2026-09-07）：** 最新截图复现与菜单配置见本文 R01–R10；省 Token 见 K01–K08；新增办公平台完整 40 项见 [办公工作台 O01–O40](../../../design/office-studio/RETEST.md)。先在“设置 → 办公菜单”启用需测试的模块；同事聊天、会议记录、机务和办公工作台按新要求默认隐藏，隐藏入口不删除历史数据。

每项记下：使用版本/源码构建标识、通过或不通过、语音模式或文字入口、实际结果、发生时间。失败截图、明确错误码和执行会话有助于定位。未连接服务、缺少本地识别资源、未做真机操作分别记录，不等同于已通过。

本轮还发现并隔离了旧测试直接写真实桌面的夹具，详见 [测试隔离事件记录](desktop-test-isolation-20260907.md)。该记录涉及四个固定文件名及测试前是否已有文件无法确认的事实，不因后续测试通过而删除。
