- 保留个人文字对话与正式项目分离的产品逻辑；正式项目仍执行类型、阶段与权限校验。

## 7. 用户真实验收顺序

1. 正常覆盖升级并保留数据：先验证旧文字对话、普通新对话、项目对话与单一月伴会话。
2. 同事聊天先截图发送，再文字、表情、文件、音视频；点击原件，重启后再点击历史附件。真实联系人测试内容由用户控制。
3. 会议同时播放电脑声音并说话，确认录音包含两路；再测试设备切换、转写补偿、停止与导出。黑白主题分别查看历史与新会议。
4. 三语音路线分别问天气并执行一个已授权桌面任务，确认一问一答、完整结果出声、任务失败也反馈；火山说话打断，其余点按钮。
5. 在本机凭据窗口完成所需 MCP 账号配置，先连接并查看工具目录，再执行查询；保留 Playwright 可选安装，不把它当成全部桌面控制的开关。
6. 项目/技能/专家/资产/机务和设置逐项操作，检查窄窗口与黑白主题；记录新问题的具体步骤，不清空数据掩盖问题。

前述操作是实际设备与账号验收，不是把缺少的代码实现转交用户。候选为未签名开发包，正式签名发布与实机验收独立。此前浏览器启动和截图核验被自动审批策略拒绝，当前只有组件交互与主题变量证据，尚无真实 WebView2 渲染截图。
