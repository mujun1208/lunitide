## 执行顺序

| 顺序 | 真实验收内容 | 重点观察 |
|---|---|---|
| 1 | 在专用测试账户/虚拟机验证 Windows 10/11、WebView2 有/无、安装、升级、默认保留数据及显式清理 | 用同一候选，确认安装和退出无残留；正式签名核验覆盖安装包及四个程序。 |
| 2 | 打字及 cloud/local/volc 三条语音链路，逐项配置真实模型与设备 | 完整答复、打断、取消、断网/限流、麦克风拒绝和设备切换；local 的识别/播报本地不等于所选 LLM 离线。可选 realtime 单独记录。 |
| 3 | 真实长会、麦克风与系统声、停止/重开、转写补偿、纪要和导出 | 原稿、摘要来源和导出可核对；失败/超限保留原始记录，已过期摘要有提示；页面切换无旧结果覆盖。 |
| 4 | 电脑控制、项目、技能/插件/MCP/专家、资料查新、资产、同事与真实数据库 | 控制对象与授权一致、紧急停止生效；项目产物可核对；停用/撤权后不可继续；两台设备送达与真实外部服务分别验证。 |
| 5 | 按主 PRD 混合业务运行 72 小时、观察 14 天并积累至少 3000 次操作 | 记录实际业务成功率、延迟、崩溃/重启和资源趋势，保留失败与恢复证据。进程资源稳定不等于业务全部成功。 |

具体操作矩阵及阈值见[主 PRD 第10—11节](../PRD-system-upgrade.md)和[56组验收计划](../test-plan.csv)；功能组合以[支持矩阵](support-matrix.csv)为准。
