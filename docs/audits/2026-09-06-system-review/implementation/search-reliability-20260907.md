# 信息检索补充复核（2026-09-07）

本次只增强原有无需 API Key 的网页搜索后备链路。DuckDuckGo Lite → Bing 中国 → Bing 国际的顺序、现有网络策略和结果 HTML 点击预览保留；没有安装新搜索服务，没有新增付费依赖，也没有把网页摘要包装为官方火车余票、机票报价或股票行情接口。

## 已确认和修复

1. 原先不检查 HTTP 状态，429/503 限流或故障页只要含类似结果 HTML，就可能被当成成功。现在先检查成功状态，明确挑战页面返回验证提示；没有拿到结果时保留失败原因，不把来源故障说成确定“没有结果”。
2. 父任务取消后原循环继续下一搜索源；现在每次请求前后检查取消，立即结束。单个搜索源超时仍允许尝试健康的备用源，保留每源 8 秒上限。
3. DuckDuckGo 某条链接没有摘要时，解析器会取下一条链接的摘要，形成来源错配。现在摘要只在当前结果与下一结果之间提取，允许本条为空。
4. 同一运行实例增加最多 64 条、10 分钟有效期的搜索结果缓存，包含查询和结果数量两个键维度。只缓存实际取得的正结果；错误、挑战页及空结果不缓存。缓存保留原取得时间，工具输出始终带 `retrievedAt` 和 `cached`，不能把缓存命中时刻说成刚刚检索的时刻。
5. 缓存按最近使用淘汰，标题、摘要、结果数和 URL 长度有界；返回结果复制切片，避免并行调用互相修改。缓存只在内存中，不写会话数据库，不改用户数据。

## 已验证

`internal/toolruntime` 搜索专项与 `internal/webfetch` 搜索解析专项 race 共 **14 项测试/子测试通过**，没有数据竞争。证据：`evidence/feedback-20260907/search-reliability-go.jsonl`。

覆盖带正常结果正文的 HTTP 429/503、取消后的迟到成功不缓存、局部超时后备用源成功、真实 `web.search` 输出与可点击 HTML 产物、时间与过期边界、不同结果数量不误共享、64 条淘汰、空页/验证页不缓存、16 个并行读者不共享可变数据、缺失摘要不借用下一条内容。

## 实际边界

- 首次查询仍受网络和搜索站限制；三条备用线路每条最多 8 秒，并非零延时承诺。成功的重复查询可直接命中短缓存；多个同时开始的全新同词查询本轮未合并为一次请求。
- 本工具返回网页摘要，不保证搜索站页面结构永久不变，也不是实时、权威的金融或票务数据源。准确天气由单独 `weather.get` 结构化接口提供；官方票务和行情源的接入范围由主报告说明。
- 日期敏感信息应按原 `retrievedAt` 解读，来源页面本身的更新时间需要打开实际链接核查。缓存不声称把陈旧网页更新成了最新数据。
- 本次回归使用隔离网络响应，没有访问真实账号、执行真实交易或修改用户浏览器。

## 本机验收

1. 查询一个普通主题，确认回答包含可打开的真实来源，打开搜索产物可查看标题、链接和各自摘要。
2. 十分钟内重复同词、同结果数量查询，确认没有重新等待完整检索，并在过程结果中看到原时间与 `cached: true`。
3. 检索等待中点击停止，确认当前轮次结束，不再继续等待下一个来源，也不会之后冒出已完成搜索结果。
4. 搜索站限流或要求验证时，系统应说明来源暂不可用或需要浏览器验证，不能据此回答不存在相关资料。

## 天气结构化接口的交叉复核

主线新增 `weather.get` 后，本代理另行检查了实际时间、位置和缓存边界，并修复以下确定问题；没有改变数据源或另外请求真实天气服务：

- 本地时间凌晨查询一天预报时，原一小时向前容差会混入昨天。现在取“当前时间前一小时”和“本地当天零点”中较晚者作为下界，`days=1` 不会因为容差变成昨天与今天两天。
- `retrievedAt` 改为网络响应成功读取并解析后的时间，不再记作请求开始时间。
- 缓存不接受时钟回退后“在未来取得”的条目。正常服务 `Expires` 仍原样遵循，测试覆盖两小时有效期，避免过早重复请求；超过取得时间 24 小时的异常头明确拒绝且不缓存，过期头不会扩展成额外 15 分钟缓存。
- 即使重定向仍在同一个天气服务域名，最终 URL 也必须包含与请求相同且唯一的 lat/lon，拒绝位置被替换、重复参数及畸形查询。

`internal/weather` 全包 race **20 项测试/子测试通过**，证据：`evidence/feedback-20260907/weather-review-go.jsonl`。上述条目与主线的城市解析、字段单位、失败响应和取消回归一起运行；并不把预报温度说成实测温度或完整全天最高/最低温。

后续用户授权天气联系邮箱后，另补真实构建版本的专用请求身份与 Last-Modified / 304 条件缓存；普通网页和视频请求不携带该联系信息，重定向跨源后清除自定义头。完整接线及新回归见 [天气 HTTP 完善记录](weather-http-compliance-20260907.md)，不将上面历史 20 项计数冒充后续全部验证。
