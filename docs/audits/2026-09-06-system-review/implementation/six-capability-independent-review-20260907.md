# 六类能力独立复核：真实可用、未实现与外部前置

复核日期：2026-09-07。对象为当前工作树、用户连续追加需求、PRD 1.10 及本轮实施报告。本报告中的六类对应用户对标材料的 **01 信息检索、02 电脑 GUI、03 浏览器、04 文档内容、05 文件系统、07 自动化调度**；不把材料全部 12 类偷换为本轮全部完成。检查采用源码阅读、既有回归证据和官方公开说明；没有注册新账号、购买服务、调用收费接口、操作用户软件或重新执行旧桌面测试夹具。

## 结论

**已有代码改进是真实的，但不能把六类能力写成“全部免费、全部实现、全部实测”。** 四种用户常用数据查询中，仅天气具备当前内置、无 API Key 的结构化客户端。股票随后已补官方 Tushare MCP 入口和路径凭据协议回归，需用户 Token 及实际数据权限；火车票和机票仍未取得无需账号的免费直连证据。MCP 接入代码与语义检索不是数据源已开通的证据。免费额度、开源库、测试沙箱和可售实时数据也不能混为一谈。

PRD 当前明确撤回历史 4.9 结论，且要求代码缺口不能移交为用户真机验收，这一点准确。中文 PDF 在本轮后续已完成字体、换行和读回修复，并有实际渲染证据；仍未关闭的业务接入代码和复杂 Office 保真编辑需继续列为实施方工作，账户授权、实际设备兼容和供应商额度才属于外部前置或用户实测。

## 可按顺序落地的剩余项

1. **先修状态口径，保持现有功能。** C10 的“统一 MCP 接入基础完成”保留，但将四类业务数据拆行：天气代码已实现；股票官方 MCP 协议代码已补，等待真实 Token/数据权限；火车票、机票分别列接入基础与实际业务开通状态。`chat_workflows.go` 已要求没有专用接口就明确说明，不能从旧记忆或网页摘要报实时结果；这是正确的当前行为。
2. **股票低成本路径先限定为历史/收盘数据。** Tushare 官方同时有 HTTP 接口与 MCP 配置说明；后续主线已补市场预设、路径 Token 占位、租约内发送和隔离协议回归。接下来使用用户自己的免费权限先验日线，复用该 MCP 通道；核对真实工具准入及“交易日期/市场/币种/是否延迟”输出后再记为账户可用。官方 MCP 文档不能证明用户账户拥有全部数据权限。[HTTP 接口](https://tushare.pro/document/1?doc_id=130)、[官方 MCP 配置](https://tushare.pro/document/1?doc_id=463)
3. **火车票/机票保留接口任务，不能以免费要求伪造实现。** 当前能采取的办法是接用户已有合法供应商账户，按该账户实际免费额度运行；没有账户和已核实免费权限就保留外部前置。应继续保存“无可用来源”结果，而不是暗中切换为抓网页。新增客户端仍是实施方代码任务，不能全部归为用户真机责任。
4. **报价验收按领域设计。** 股票带交易所、币种、数据时刻和延迟属性；火车票带乘车日期、发到站、席别及检索时间；机票带行程、旅客类型、币种、含税总价和报价失效时间。限额、过期、空响应、部分航线/市场不覆盖必须能明确失败。测试沙箱报价不得展示为真实可售价格。
5. **天气调用身份与条件缓存已随后落实。** 用户提供并授权了联系邮箱；天气专用回调现已携带实际构建版本及授权联系身份，普通网页/视频不携带。正常 Expires 到期后支持原 Last-Modified 条件请求，304 保留原取得时间并记录新核验时间。该代码缺口已经关闭，详情和隔离验证见 [天气 HTTP 完善记录](weather-http-compliance-20260907.md)。这不改变免费服务没有 SLA 的边界。[MET 调用要求](https://api.met.no/doc/TermsOfService)

## 对 PRD 与评分的审阅结论

- 采用现有 Host/Engine、SQLite、工具与审批内核继续补强的路线有代码依据，无需为六类能力另造第二套引擎或收费桌面平台。
- “工具本体开源/本地运行”“数据接口有免费额度”“用户业务全程免费”必须分别写；后两项还取决于供应商及模型用量。
- 股票/票务和复杂 Office 保真编辑等未闭环项不能凭测试通过或一张市场卡片归零；中文 PDF 常见中英文内容已按后续完整生成/回读/渲染证据更新，不扩大为所有 Unicode 字符与复杂排版均已支持。按本报告行项跟踪即可避免漂移。
- 本报告不新增总体评分，也不确认工程或真机已达 4.9。完成实施任务、明确外部前置、关闭已知代码缺口并取得综合门禁证据后再评分，符合当前 PRD 的准入条件。
