# 公共视频直链内容识别补强（2026-09-07）

本次补充 U03 的实际音画读取能力。之前的分享页字幕读取继续保留；没有将分享页标题、简介或模型常识冒充视频识别。

## 实际支持范围

| 来源 | 现在能取得的依据 |
| --- | --- |
| 公开 MP4、MOV、WebM、MKV 文件直链 | 已有 FFmpeg/FFprobe 可用时真实解码，提取第一条音轨前 120 秒；本地离线模型已安装时识别。提取该范围内开始、中间、末尾附近最多 3 个实际画面，拼成证据图交给当前模型，并返回可点击图片产物。 |
| B站、抖音、腾讯视频、YouTube 分享页 | 沿用公开字幕/页面简介读取；没有新增隐藏视频地址提取、浏览器登录、播放器逆向或平台下载器。 |
| 无字幕且无公开文件直链的分享页 | 仍只能依据公开简介，不声称识别了音画。 |
| 账号、验证码、DRM、HLS/DASH 分片 | 本次不支持，也没有绕过。 |

小于 120 秒可覆盖整段音轨范围，ASR 不保证逐字准确；视觉始终仅最多 3 帧抽样。长片仅前 120 秒，不评价后续剧情或声称逐帧看完全片。只处理第一条音轨，不选择多语言音轨，不保证音乐、背景声、无语音声音事件的语义识别。

## 实现与边界

- 直链从当前任务进入原 `video.understand`，保持文字/语音统一权限，没有绕过联网权限的独立入口。
- 复用 `networkpolicy.Fetch` 的每跳重定向、DNS、公网拨号约束；限 64 MiB，下载默认 30 秒，总分析 90 秒。超限不使用截断文件推测内容。
- 网络文件写入专有临时目录；FFmpeg 只接收本地路径，限制协议 `file,pipe` 与常见容器 demuxer，不传远程 URL/播放列表。限制分配、线程、探测、解码时限、输出字节与画面尺寸；结束清理自身临时目录，Windows 不弹控制台。
- 只保存真正抽取的 PNG；工具文字说明从左到右对应的时间位置。沿用当前会话受限文件路径和原产物展示。
- ASR 复用 `VoiceService.refiner` 的 `Ready/Warm/Transcribe`，不安装模型、不添加凭据或另一识别服务。最多每 30 秒一段；失败保留此前文字，分段接缝仍可能影响识别。
- 无本地 ASR 明确 `local_asr_missing` 并保留可用画面；无画面保留音轨。缺 FFmpeg/FFprobe 明确 `ffmpeg_missing`，不自动安装。
- 画面进入原 `VisionData`，没有额外调用收费视觉服务。模型拒图后重试文本请求会明确“画面未被读取”，只保留音轨/文字依据。即便工具前已说“我先读取”，仍能正确降级。
- 音轨/画面标为外部资料，不具有指令权限。没有真实账号登录、网络媒体下载、收费模型调用；未宣称验证所有供应商视觉配置。
- 收尾复核修复了长识别结果可能挤掉范围说明的问题：模型摘要最多 3600 个 UTF-8 字节，追加文字文件路径后仍不超过 3840；覆盖范围、实际识别时段、音轨/画面缺失、帧时间、部分失败和截断标记均在摘录之前，各时段均分剩余预算。已取得的文字另存当前会话 TXT 文件，不替换 PNG 产物；每段原有 8 KiB 保存上限若截断，也在文件中明示，不能称为完整逐字稿。

参数语义核对使用 FFmpeg 官方[协议文档](https://www.ffmpeg.org/ffmpeg-protocols.html)、[容器文档](https://www.ffmpeg.org/ffmpeg-formats.html)及[命令文档](https://www.ffmpeg.org/ffmpeg.html)。未依赖第三方博客作实现结论。

## 验证证据

`internal/videounderstand/testdata/direct-short.mp4` 是本地 FFmpeg 合成的 2 秒红色画面与 440 Hz 正弦波。它验证真实容器解码、像素、音频格式与完整接线；ASR 文本和模型回答使用隔离适配器，不能证明真实语音准确率。

- 真实解码验证非零 PCM、16 kHz 单声道 16 位大小、3 帧实际红色像素、1920×360 证据图。
- 实际 `chat.start → video.understand → 测试下载接口 → FFmpeg → 测试 ASR → 模型下一轮`：收到图像与识别文字，产物事件含 PNG。
- 模型先说“我先读取”，随后拒图：重试无图片且明确未读画面，保留音轨，不重复下载/识别。
- 120 秒四段长中文识别、最后一段失败，以及三帧时间位置，均验证通过实际 `clipToolSummary` 后元信息和 UTF-8 保持完整；四个已识别时段不会被第一段长文字挤掉。
- 覆盖 ASR 缺失保留画面、中途失败保留文字、音频分段上限、64 MiB 实际超限/transport 截断、403、登录 HTML、SSRF 私网拒绝且不拨号、取消不下载、解码取消、缺依赖、播放列表拒绝、非法/过大画面、进程输出上限与直链识别。
- `go test -race ./internal/videounderstand -count=1` 全量通过；app 视频/视觉/路由/Section8 普通回归及同范围 race 均通过，app race 用时 45.360 秒。
- toolruntime 视频回归通过；bootstrap 编译通过（筛选没有匹配测试）；修改范围空白检查通过。

## 用户验收

1. 提供自己允许读取的公共短视频文件直链，发送：“分析这个视频，分别说明音轨内容和抽样画面，写明实际覆盖范围：<直链>”。应调用真实工具，说明取得的依据。
2. 点击返回的 PNG 产物，核对实际抽样画面与工具标出的时间位置。抽样图不能代替视频播放。
3. 缺本地语音模型时应说明音轨未识别，仍保留画面；模型不支持图像时应说明画面不可读并保留音轨。
4. 分享页无字幕、受限链接、长片、超限和缺依赖场景，应准确说明实际范围，不能说“看完了”。

U03 现在是“公开视频文件直链有真实音轨与抽样画面链路”；平台分享页无公开媒体时仍无完整音画读取，不能标为所有来源已覆盖。无新增依赖、未写用户数据、未打包。
