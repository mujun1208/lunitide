## 2026-09-07 02:00 增量核验

- 语音回答不再按两句/80 字硬截断并取消任务。完整回答交给流式播放器，末尾无结果时明确说明没有收到可确认结果。
- 火山实时通话调用工具时由任务播报接管声音；新一轮回到通话音频，旧原生字幕不得覆盖执行结果。其他模式仍由打断按钮中止。
- 语音使用同一执行权限和受控工具入口，原始 cc.* 仍由 computer.act 内部调用。移除的是“仅语音不可用”的限制；原有文件授权、桌面开关、审计与紧急停止继续由共同执行层检查。
- 同时查询、生成文件、发消息的指令保留各步骤工具；删除仅按工具名称就跳过第二次查询/播放的限制，继续由已有参数摘要去重处理真正重复调用。
- 每周摘要覆盖该周原文，原始记录保留。摘要验证并持久化即为归档完成，不替换用户当前选择的压缩上下文；只有明确回忆请求才注入归档。新进入的对话以进入时的消息序号为边界，本次仍可连续聊。
- 前端桥接代码生成两次遇到 Windows 打开现有文件 UNKNOWN 错误。改为完整生成临时文件后原子替换，生成与一致性校验通过，避免失败生成破坏在读文件。

- 内置目录修复无效包、错误参数、缺少环境变量及远程端点。手动配置先保存，再填本机凭据并连接；多项环境变量逐项递增版本保存。卸载后重装创建新端点，已撤销端点不再复用。长 MCP 工具名转换成稳定短别名，搜索返回参数结构，调用时恢复原工具名。
- 公共 Hugging Face MCP 仅目录探测的联网尝试在本机 DNS/连接阶段超时。未提交用户数据，未证明真实外部服务已可用；本地 TLS 服务协议测试通过。
- 产物详情使用现有预览桥接，增加实际路径、大小、原文件及所在目录入口。HTML 使用隔离预览，图片复用有大小/像素限制的编码器。PDF 和暂不支持的格式给出本机打开入口，不显示虚假的预览成功。图片缩略图损坏后可继续打开原文件。
- 修复绝对路径被改写到桌面的定位错误。允许当前会话、已选工作区、桌面，以及已确认完全访问会话的真实绝对路径；未授权目录仍拒绝。
- 产物记录并发写入加锁并原子替换，取消先删除旧文件的做法；Office 生成替换同样保留失败时的旧文件。24 个并发消息的产物记录在重新构造引擎后完整恢复。
- 下一步建议由文字回答的同一次模型请求结合目标、完成结果、证据和缺口生成两个选项；不额外请求模型，不加入语音提示。模型未输出规范建议时，按实际产物、未完成问题或方案给出两个明确的回退选项；回退不是再次模型推理。用户点击之前不执行任何建议。
- 引导确认补充持久化执行回执，结果丢失后重试只读取已提交的同一决定，不重复写文件，也不扩大原有审批范围。原始调用 CAS 保持单次执行；工作区变化、执行未返回、失败、失效分别报告。客户端取消后保留最多 5 秒完成结果持久化。
- 语音安装工具和浏览器操作不再额外禁用，采用与文字相同的已授权模式。已开启的完全访问能力在有人使用的语音会话中绑定并审计本次会话；不改全局关闭开关、不解除紧急停止、不授权外部同事入站消息。紧急停止后仍可正常聊天。
- 原生语音回调加入连接代次校验，旧连接不得播放声音、下发任务或清空新连接。语音完整回答、工具结果播报和进入时的历史边界继续保留。
