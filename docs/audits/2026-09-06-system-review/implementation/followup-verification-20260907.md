## 已落地的追加修复

| 问题 | 复现与根因 | 实现及自动证据 |
|---|---|---|
| 火山完整句变尾字 | 已提交音频被末包重新分段，新的 start timestamp 落在旧音频范围，旧 start-only 水位把它当新话 | 同时记录音频结束位置；12 轮光标与 ASR 回调回归，后到尾字不重开轮次 |
| 同一个识别段包含下一句 | 产品静音计时提交后，供应商沿用相同 start 延长音频 | 只有更晚音频且精确保留已提交前缀时提取新后缀；新位置的相同短句保留；会议乱序快照不重复 |
| 创建周报技能生成文档失败 | “周报/PPT”等主题词抢走技能创作路由 | 独立创作意图识别，真实 runStream + SQLite 验证生成技能草稿；不是假文件或占位成功 |
| 创建的技能无法真正调用 | SKILL.md 默认入口不在执行合同内，长正文被展示摘要替代 | 正文工作约定真实传入模型；独立预算保护、重复调用保留原完整正文，失败不转自动文档生成 |
| 首轮附件未传给模型 | 空历史/无历史 reader 回退到显式文字，绕过刚加载的附件及图像 | 空历史仍走同一预算/证据装配；完整文字及图像直传/配置视觉模型路径均由实际 adapter request 断言 |
| JSON/TS 无法读取 | Windows 将 TS 标为 video/mp2t、JSON 标为 octet-stream | 受支持扩展名 + 完整 UTF-8/控制符校验后按文本解析，二进制不伪装文本 |
| 解读材料误开生成流程 | 上传正文或 OCR 里的任务词进入确定性路由 | 路由只使用当前操作要求；材料全文仍提供给模型作为证据 |
| 预算不足丢装备 | 最小系统回退会删除技能/专家/工作流 | 去掉静默降级；保留选择并说明预算不足，要求减少材料或用更大上下文模型 |
| 自动化返回后历史消失 | 已绑定执行会话无消息时被 UI 当空草稿删除；历史 limit 早于组织过滤与状态去重 | 绑定会话免于前端清理；返回保留页签/展开项；后端按真实归属过滤、最终状态去重后再 limit |
| 调度取消被错误拒绝 | automation.runId 被通用权限层当作 agent_runs 的 ID | 使用调度记录所属会话验证，跨组织拒绝仍有效 |
| 草稿回收竞态 | 列表时为空，删除前已写入消息/绑定任务，旧候选仍被删 | 同一 SQLite 事务重新验证资格；新消息/附件/Office/自动化绑定、改名/置顶等受保护，普通空草稿仍可清理 |
| 全局办公菜单 | 四个模块默认不可配置、机务在项目、搜索位置不符 | 设置四开关全局保存；默认隐藏；机务移办公；新对话→搜索→办公；原模块数据保留 |
| 长 Office 结果进入聊天被裁断 | Bridge 分页通过，但模型侧仍受 4 KiB 摘要约束 | 独立 3.8 KiB JSON 页，正文/指标字符偏移、版本/交付文件游标与真实摘要；读取全部内容才可完整编辑 |
| 提交成功被当失败 | 第一次结果快照失败导致用户重复执行写入 | 明确 committed + snapshotIncomplete，保留已知任务与原展示，只 GET 刷新；依赖快照的写操作等待恢复 |
| 缓存与整轮统计不准确 | DeepSeek 缓存字段被忽略；Anthropic 真实嵌套流格式不同；仅计最后一次模型请求 | 三供应商真实合同解析；整轮调用按回执聚合；失败/取消保留已取得计量；未知不冒充 0% |
| Anthropic 出站形状错误 | system 数组无 type；同轮工具结果拆散 | 补齐 type:text 与同轮 tool_result 分组；Complete/Stream 实际出站请求、缓存和图像归属回归 |

省 Token 独立架构、默认策略、回退和来源依据见 [专用 PRD](../../../design/PRD-token-efficiency-v1.md)。新办公平台的完整代码支持范围与尚未满足的完整设计条目见 [实施报告](../../../design/office-studio/IMPLEMENTATION-REPORT.md)。
