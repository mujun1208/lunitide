# M9 威胁模型 1/6：跨组织隔离与存在性侧信道

> 阻断期产物（T-9.0.2）。本文是概念威胁模型，不是生产合同；不含 DDL/API 决策。
> 范围：FR-01 Organization / FR-02 TeamSpace / 个人资产进入组织硬边界。
> 映射用例：T-01（跨组织访问）、T-02（空间切换残留）、PRD「个人资产进入组织的硬边界」。

## 1. 资产
- 组织隔离根 `org_id`（不可变，创建时写入，禁止 UPDATE 改绑）
- 组织内容与元数据：会话、KB、记忆、任务、审批、账本、审计、blob/cache/queue
- 存在性元数据：对象是否存在、计数、时序、错误码差异
- 个人资产（M8 私有）：私人思维过程、聊天正文、未发布记忆

## 2. 威胁主体
- 越权成员/被攻陷成员凭证（同平台他组织）
- 被攻陷的后台作业：消费者、索引重建、备份恢复、数据迁移、支持工具
- 恶意/配置错误的管理员（尝试读取私人资产或跨组织对象）
- 外部攻击者经伪造 org_id 注入

## 3. 攻击面（STRIDE）
| # | 攻击场景 | 类别 | 影响 |
|---|---|---|---|
| S1 | 请求正文/查询参数/Runner 自报携带 org_id 覆盖已验证会话上下文 | Spoofing | 跨组织读写 |
| S2 | Repository 层某条查询遗漏 `org_id = :verified_org_id` 谓词（后台任务/聚合/删除路径） | Elevation | 全层泄漏 |
| S3 | 外键仅用全局 id 而非 `(org_id, id)` 复合键，跨组织引用建立 | Tampering | 关系串联泄漏 |
| S4 | 对象存储路径/缓存键/队列 topic/去重键未带组织前缀 | Information Disclosure | 缓存串台 |
| S5 | 运维用 super-tenant/缺省组织上下文跨组织批处理 | Elevation | 绕过谓词 |
| S6 | 错误码/时序/计数差异泄露对象在他组织的存在性 | Information Disclosure | 存在性泄漏 |
| S7 | 搜索/指标/审计侧信道推断 M8 私人资产存在性 | Information Disclosure | 隐私违约 |
| S8 | 组织 suspended 后成员仍开新会话/运行；closed 被误当物理删除 | Repudiation/DoS | 治理失效 |

## 4. 缓解措施（与 02 技术设计对齐）
1. org_id 只能来自已验证会话或签名能力票据；正文/参数/自报一律忽略（S1）。
2. Repository/ORM 强制注入组织谓词；缺少组织上下文 fail closed；禁止调用方选择性关闭（S2）。
3. 复合外键 `(org_id, id)`、复合唯一键含 org_id；TeamSpace 复合 FK 只指向同组织父节点（S3）。
4. blob 引用、缓存 key、幂等/去重 key、queue topic/partition、死信队列带组织前缀并验证票据组织（S4）。
5. 后台任务逐组织授权、执行、审计；跨组织运维必须拆分；恢复器/管理员同受谓词约束（S5）。
6. 跨组织访问统一 M9-003 应答，无 found/not-found 差异；聚合指标按 k 阈值抑制（S6）。
7. 组织管理员/审计员/支持人员对私人思维过程、聊天正文、未发布记忆零读取路径；搜索、指标、审计不收录（S7）。
8. suspended 拒绝新会话/运行并保留 Hold 数据；closed ≠ 清除（S8，FR-01 GWT）。

## 5. 可验证断言（解封后落入测试）
- T-01：A 组织访问 B 的空间/缓存/索引/事件 → 全层拒绝且无存在性泄漏（M9-003）。
- T-02：切换 TeamSpace → 旧搜索与缓存上下文清除。
- 伪造 org_id/缓存键/索引命名空间的故障注入 → 全层拒绝。
- 管理员经目录/搜索/审计/指标/支持工具查询私人资产 → 内容与存在性均不可见。
- 个人→组织：未显式选择/未脱敏/旧授权/引用私人原件/未发布记忆 → 全部拒绝。

## 6. 残余风险与移交
- 谓词注入依赖代码纪律 → 解封后须有静态断言（每条 SQL 出现 org 谓词或白名单登记）。
- 存在性侧信道无法穷举 → 以 T-01/T-20 + 渗透演练覆盖，退出包附零泄漏报告。
