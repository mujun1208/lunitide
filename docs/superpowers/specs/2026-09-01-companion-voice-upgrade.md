## 2. 「对答如流」是门闩，不是口号

改造后**保障**的是下面全部勾上。不是保障像真人电话 200ms，也不是保障没有 realtime 模型时火山 4.8。

| 门闩 | 含义 | 云端 / 本地 | 火山（有通话核） | 火山（仅级联） |
|---|---|---|---|---|
| **快** | 说完 → 第一声**正经回答**（不是嗯） | ≤800ms | ≤400ms | ≤800ms 报 4.1，顶 4.3 |
| **一轮一句** | 一句用户话只开一次想；不切半句；不复读已读 | 要 | 要 | 要 |
| **闲聊不调工具** | 「今晚月色如何」「继续聊」「我随便说说」零工具 schema | 要 | 要 | 要 |
| **开口就是回答** | 禁止先垫嗯；第一句 8–20 字，。？！收尾 | 抽测 | 抽测 | 抽测 |
| **答完能听** | 播完 + 回声门 ≥300ms 识别器活着 | 要 | 通话核持续听 | 要 |
| **手动打断** | 立刻停声、字幕已读、1s 内能再说 | 要 | 要 | 要 |
| **自动打断** | 对着麦插话 300ms 停 | **不要**（对着麦不应停） | **要** | **要**（G0-B） |
| **不卡死** | 无空听、无假启动中、工具 20s 口播、UAC「要你点」 | 要 | 要 | 要 |
| **灯诚实** | 听/说/打断方式与事实一致 | 要 | 会话中写「通话核」 | 要 |

业界对照（不是本机埋点）：人类轮换 ~200ms；半双工调好级联 500–800ms = 本尺 4.5 速度；语音原生 200–400ms = 火山 4.6–4.8。
