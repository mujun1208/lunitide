# 月汐本职 9.5 场验矩阵

日期：2026-09-19  
对照：`docs/superpowers/specs/2026-09-19-score-95-upgrade-prd.md` §WP7  
平台：Windows x64，本机 WebView2 Host  
诚实边界：未安装含 WP0 媒体 COM 修复的 Host 时，媒体行不得报绿。本文件是清单，不是已 soak 的证明。

| 表面 | 必须绿 | 怎么验 | 失败即停 |
|---|---|---|---|
| 文字 Chat 一轮 | 出字、可停 | 新对话发一句；点停止后不再续写 | 空转、停不住 |
| 月伴问候 | 立刻出声，不带工具 | 「你好」；热路径不跑压缩、不挂工具 | 先压缩再出声、问候带 desktop |
| 月伴「打开记事本」 | `desktop.open` 验窗成功才说打开 | 任务话术；空成功禁止 | 没开窗却说已打开 |
| 媒体中心选本地音频播放/暂停 | Host 不退 | `ringing_short.mp3` 播→停→再播；杀 Host 再开不自动出声 | 秒退、启动即崩 |
| 设置灯 | 点设置即见 | 返回下方四盏；无活动全绿；MCP 检疫黄 | 前台再出「运行状态」 |
| 记忆确认 | 未确认不出现在下一轮系统注入 | 提名列出；不点确认则下一轮不进指令 | 自动 confirm |
| 未配电脑控制 | 入口不可用 | GUI 未绑定时「三步启用」不可点，写明原因 | 点进去半路失败当主路径 |
| Hub loopback | 能建 thread，投影进 session | create/get 有 `sessionId`；「在对话中打开」进同一会话 | Hub 另起大脑、无投影 |
