## 1. 问题出在哪（不是波次没做完）

现核是：

```text
听写终稿 → 一次 chat.start（文本 LLM）→ 文本切句 → TTS 整段/首包 → 喇叭
```

三张卡只换「听 / 说」供应商，**想永远走文本 LLM**。慢的是这条轴，不是缺一张云卡。

### 1.1 级联的物理下限（做完美也跨不过）

闲聊、无工具、闪模型、流式 TTS、完整句 220+280 都做完之后，账仍是 **相加**：

| 段 | 再抠也要留 | 为什么去不掉 |
|---|---|---|
| 收句 | 250–400ms | 必须先判断「这句说完了」。再短就会切「打开网」 |
| 文本 LLM 首 token | 150–400ms | 模型看到的是字，不是声波 |
| TTS 首包 | 80–200ms | 字变成喇叭，即使 W4 流式也有首块 |
| 回声门 | ≥300ms | 再短会把她的话当用户（R-CUT-5） |

合计 **约 500–1000ms** 才是第一声正经回答。  
业界把这种调好的级联标成电话感下限（500–800ms），对应本尺 **4.3**。  
人类轮换中位约 **200ms**。级联 **听不见用户还在吸气时就开始出声**，所以到不了 4.6。

上一份方案已经禁止了能再抠 100–200ms、但会炸准度的三件事：

- 投机对 **同一句 partial** 开第二路 `chat.start`（R-STORM-2）
- 硬顶收到 &lt;1.6s（R-CUT-2）
- 回声门收到 &lt;300ms（R-CUT-5）

再抠这些，分数假涨、对打中断。不是漏做，是墙。

### 1.2 为什么「满分 5」设计上就不在这份方案里

5 分在这把尺上的含义是：像电话、三张卡都像、工具轮也像、几乎不切错句。

| 卡 | 级联顶 | 为何永远不是 5 |
|---|---|---|
| 火山 | 4.3 | 文本 LLM + 单向 TTS，即使 seed-asr 流式 |
| 云端 | 3.8 | Web Speech 无 mute、不能插话。不换听写引擎就停在这 |
| 本地 | 3.3 | SoVITS CPU、非流、启动墙。冻结不改 bat/9880 |

综合对打按日常该用的卡加权，不是三卡平均再假装 5。  
**本地卡、云端卡带着走，综合到不了 4.8，更到不了 5.0。**

4.6–4.8 来自 **音频进、音频出** 的通话核：用户还在说，模型已经在出声；插话是会话能力，不是「取消文本流 + 清 WAV 队列」。

上一份写明：那条路要把对话挂到音频通道，**违反「不在 openspeech 上挂对话 LLM」**，桌面工具也会变瞎。所以当时封顶 4.3。

### 1.3 和主尺 4.80 的误会

主尺看的是这台 PC 助手能不能活着、点得准、做完才停。语音对打再快，也不自动变成主尺加权 4.80。  
对打 4.8 **不等于** 主尺 4.80，也不等于正式发布。

## 2. 要到 4.8 必须换的核（裁定）

**留下现级联，加第四核：通话核。**  
级联继续服务：工具轮、无 Realtime 密钥、云端兜底、本地克隆。  
闲聊对打走通话核。

```text
闲聊（无桌面意图）
  麦 PCM ──► 通话核（Realtime / 豆包实时通话 / Gemini Live）
              音频进、音频出；原生插话
              字幕只是旁路，不是主轴

工具意图（打开 / 填写 / 播放 / 点）
  通话核 function call 或文本意图
      ──► 现有 chat.start + 工具运行时（级联）
      ──► 执行完一句口语回灌通话核或级联 TTS
```

这不是把 `chat.start` 接到现有 `volc_speech` 的 seed-asr / 单向 TTS 上。  
现卡的 openspeech **听写、朗读** 计划保持原样。  
通话核是 **新的会话 API**（新 provider kind，或现有供应商上已暴露的 realtime 模型 id）。

| 诱惑 | 裁定 |
|---|---|
| 再抠 FORCE_COMMIT / 12s stall 冒充 4.8 | 拒绝 |
| 投机同一句 partial 双开 `chat.start` | 仍拒绝（级联风暴） |
| 把对话 LLM 挂到现有 SAUC / unidirectional TTS | 仍拒绝（旧冻结） |
| 复活 MiniCPM-o 当 4.8 | 拒绝（已折云端；本机 GPU 不是本波） |
| 改 SoVITS bat / 9880 | 拒绝 |
| 重写 `useCompanionMachine` 整表 | 拒绝。通话核另开细会话，工具轮仍走现表 |
| 三卡都承诺 4.8 | 拒绝。只承诺 **火山/通话核闲聊** |
| 报 5.0 | 拒绝。5.0 要三卡 + 工具 + 200ms，是另一个产品 |

**到 4.8 的唯一门闩：书面批准第四核。** 未批则继续 4.3 顶。
