## 2. 月汐产品解读（全产品面，避免只谈网关）

月汐是 **这台 Windows PC 的本机助手 + 工作台**。内核是 Go 引擎；UI 是可关的 WebView2；托盘与工作台同 PE（`Lunitide.exe --tray`）。

## 6. 四家拆解（现码对照）

### 6.1 OpenClaw — 该偷寿命，不该偷网关

GitHub `openclaw/openclaw`。Gateway 默认 `:18789`。工具组：exec / fs / browser / computer / memory / cron / message / subagents。可绑远程节点；浏览器默认可隔离，也可挂用户 Chrome；通道是全球集。

| OpenClaw 有 | 月汐现码 | 差距类型 |
|---|---|---|
| 关窗不断 Gateway / launchd systemd | 关窗留 Go 引擎，托盘退出才停 | 已对齐形态 |
| `computer` + frame / 节点广告 | `computer.act` + `frameId` + 本地点击阶梯 | 合同接近，无远程节点 |
| `tools.profile` + `alsoAllow` | `minimal` / `coding` / `同事` | 已对齐思想 |
| `sessions_spawn` / 子代理绑频道 | 评议会 + 同事 `@` 两跳 + 只读 spawn | 不完整 |
| ClawHub / 插件装通道 | 技能目录 + MCP stdio，无商店 | 规格不做 |
| 用户 Chrome / 远程节点 | 隔离 WebView2 + Playwright；禁引擎劫持 Chrome | 故意不做（MCP 预置需人装） |
| 20 通道 + iOS 节点 | 飞书/企微/钉钉入站，微信 QQ 只代发 | 规格不做 |

### 6.2 Codex — 该挂脑，不该换核

GitHub `openai/codex`。沙箱、`apply_patch`、`spawn_agent` / wait / close、CSV 扇出、`AGENTS.md`。

| Codex 有 | 月汐现码 | 差距类型 |
|---|---|---|
| 沙箱 + 读写盘策略 | 审批 + Job Object（stdio MCP）；对话命令跑在引擎权限 | 不健全 |
| `spawn_agent` 路径树 | 只读 subagent spawn/join，无路径寻址 | 不完整 |
| `AGENTS.md` 委派 | 专家六段 + `skill.invoke` | 部分 |
| 当月汐的一个脑 | `local_brain.go` 90s CLI + `.last-reply.txt` | 能用但薄；超时回落月汐 |

### 6.3 DeepSeek Harness — 思想可学，运行时禁止搬

GitHub `deepseek-ai/DeepSeek-Harness`（开发者预览）。Everything is a plugin；轨迹只追加。官方 Python SDK 示例写明持久 PTY **不支持 Windows agent**。

| DSH 有 | 月汐现码 | 差距类型 |
|---|---|---|
| 插件热替换不改内核 | Go 编译进引擎 | 故意不对齐 |
| 只追加轨迹 / 回放 / fork | SQLite 会话 + 检查点，无完整轨迹视图 | 不完整 |
| 组合 YAML 换循环/沙箱 | `executionMode` + tool profile + 能力包 | 部分 |
| Windows 上跑 agent | 月汐反而完整 | 月汐强 |

### 6.4 Hermes — 该偷「内核可单跑」，不该偷自进化

GitHub `NousResearch/hermes-agent`。用完造技能、FTS、Honcho、cron 送到任意平台、七种终端后端。

| Hermes 有 | 月汐现码 | 差距类型 |
|---|---|---|
| 无窗口也能当助手 | Go 引擎 + 托盘 | 已对齐 |
| 技能用完自己改 | 人装才上架 | 故意不对齐 |
| 可插拔记忆后端 | SQLite + FTS + 确认箱 | 部分，够本机 |
| 子代理 + RPC 脚本 | 同事交接两跳 | 不完整 |
| Docker/SSH/Modal | 只本机 Windows | 不做 |
