月伴对话（Moon Companion）与本地语音闭环 PRD

在普通聊天空间提供品牌一体的全屏月亮对话形象：点击按钮进入黑夜星空舞台，语音说话、月亮聆听旋转、开口说话时停转并随语音波动发光；语音合成走 Windows 本地 SAPI，零云端依赖、零新增权限、零新增数据表。

目标、角色与边界

目标：把已有的语音输入（Web Speech API）与流式聊天（ChatBridge）闭环成"听 → 想 → 说"的完整语音对话体验，并用月汐品牌视觉（SVG/CSS 月亮 + 星空 + 光晕）承载；TTS 为本里程碑唯一新建后端能力（Windows SAPI 本地封装）。

角色：单用户（个人桌面使用者）。无组织、无多角色。

边界（非目标）：

  • 不改会话数据模型：月伴会话仍是 scope=personal/unscoped 且 project_id=NULL 的普通聊天，遵守 03 一级信息架构"普通聊天与项目空间分离"不变量；项目空间内不提供月伴。
  • 不引入云端 TTS（Edge-TTS 非官方接口风险、ChatTTS 需 Python 环境与 GB 级模型分发），不引入视频/3D 形象，不引入 PNG 精灵图（与明暗主题 CSS 变量体系脱节）。
  • 不做实时语音打断识别（barge-in ASR）；打断采用显式点击/按键。
  • 不新增麦克风之外的任何系统权限；音频数据不出本机（SAPI 进程内合成，Analyser 仅读本地播放频谱）。

功能需求与 GWT

ID需求规则Given / When / Then
FR-01全屏月亮舞台普通聊天 SessionPage 内的模式切换，非新增一级路由；入口为 composer 月亮按钮；Esc/右上按钮退出；进入/退出保持会话与消息上下文；入口受设置 companion.enabled 控制且默认开启，关闭即完全隐藏。给定用户正在普通聊天；当点击月亮按钮；则以模式切换进入全屏月伴舞台且消息历史保持；当按 Esc；则返回原对话视图且焦点落回入口按钮。
FR-02月亮状态机与视觉四态：idle（缓慢旋转 + 呼吸微光）、listening（旋转维持 + 环绕音量柱可视化）、thinking（旋转加速，等待感）、speaking（停止旋转，光晕与月面随播放音量波动发光）；状态迁移由会话/语音事件驱动且 Guard 严格（非法迁移拒绝 M95-005）；reduce-motion 下旋转全部静止，改用静态光强差表达状态。给定月亮处于 speaking；当 TTS 播放中 Analyser 输出音量波动；则光晕强度与月面径向渐变随之波动且旋转角冻结；当播放结束；则回 idle 并恢复缓慢旋转。
FR-03语音输入闭环复用既有 Web Speech API 语音输入（zh-CN、final 结果上屏）与麦克风设备选择/音量可视化/错误码体系；月伴模式下 final 文本直接发送（不落 composer 手动确认），识别中可再按话筒取消。给定用户在月伴舞台点击话筒；当月亮进入 listening 且用户说完一句话；则 final 文本作为用户消息直发 ChatBridge，月亮转 thinking；识别失败沿用既有麦克风错误码提示且不发送。
FR-04本地 TTS（Windows SAPI）Go 侧封装 SAPI ISpVoice 进程内合成 WAV（离线、无网络）；bridge 暴露 tts.voices / tts.synthesize / tts.cancel；支持音色枚举与选择、语速/音量设置，设置持久化于既有设置域（零新表）；超过单段上限的回复按句分段顺序合成连续播放；SAPI 不可用时降级纯字幕模式（M95-001，对话不中断）。给定助手回复完成；当 TTS 开启；则回复文字经 SAPI 合成为音频并在前端播放，字幕同步显示；当合成失败；则该段字幕照常展示并提示一次性降级，会话不中断。
FR-05说话打断speaking 状态下点击月亮或按 Esc 触发打断：前端立即停播 + tts.cancel 通知引擎丢弃未完成合成段（M95-003 notice 回执）；已播字幕保留；打断后回到 idle 可立即说话；打断不得影响流式回复的已完成内容。给定月亮正在 speaking；当用户点击月亮；则音频在 100ms 内停止、未完成合成段被丢弃、字幕停留在已播内容、状态回 idle。
FR-06字幕同步与无障碍TTS 播放时逐段字幕上屏并随分段高亮；舞台状态以 aria-live 播报；全流程键盘可达（空格/回车=话筒，Esc=打断/退出，Tab 顺序固定）；读屏可获取字幕全文；reduce-motion 与 200% 缩放无阻断。给定读屏用户在月伴舞台；当助手开始说话；则字幕以 aria-live 逐段播报且无旋转动效依赖；给定开启 reduce-motion；则月亮静止但状态可通过光强与文字标签区分。

前置依赖与开工条件

无 ADR 决策阻断（区别于 M9）：不新建隔离根、不涉组织身份与策略代数。唯一外部依赖为既有能力：M2 流式聊天与语音输入（ChatBridge + Web Speech API）、M2 设置域（设置持久化通道）、Windows SAPI（Vista+ 系统自带，Windows N/精简版缺失时走 FR-04 降级链）。可与 M8/M9 并行开工，互不阻塞。

优先级FR判定理由
P0 发布阻断FR-01、FR-02、FR-04全屏舞台、月亮状态机、本地 TTS——月伴可用性底线，缺任一项即"语音对话机器人"不成立
P1 首期必须FR-03、FR-05、FR-06语音输入直发、说话打断、字幕与 a11y——语音对话体验完整性；a11y 为全局不变量不允许延期
P2 可延期无6 项全部首期交付，无延期项
