月伴舞台 UI 与交互契约

黑夜星空 + 放大月亮的全屏对话舞台：对话时月亮旋转（聆听/思考），开口说话时停转并随语音波动发光；纯 SVG/CSS 实现，颜色全部引用月汐设计变量。

信息架构裁决：模式切换，非新路由

冻结裁决：月伴舞台是 SessionPage 内的全屏模式（composer 月亮按钮切换），不新增一级路由、不新增侧栏入口。会话与消息上下文在进入/退出间保持不变；此设计对齐 03 一级信息架构（全局侧栏冻结、普通聊天与项目空间分离）。视觉原型见 06 · 06C 月伴全屏对话画板。

关键旅程

旅程步骤与断言
召唤月伴普通聊天 composer 月亮按钮 → 全屏舞台（消息历史保持）→ 月亮 idle 旋转呼吸；再按 Esc → 返回原视图，焦点回入口按钮
语音对话闭环点击话筒（或空格）→ listening（旋转 + 音量环）→ 说完 → final 文本直发 → thinking（加速旋转）→ 回复完成 → speaking（停转 + 波动发光 + 字幕逐段高亮）→ 播完回 idle
打断speaking 中点击月亮或 Esc → 100ms 内静音 → 字幕停留已播内容 → 回 idle 可继续说话
降级无 SAPI 环境 → 舞台顶部一次性提示 + TTS 控件禁用 → 字幕模式对话完整可用

月亮四态视觉规范

态旋转光与色附加元素
idle缓慢（60s/圈）呼吸微光：光晕强度 0.3↔0.5，4s 周期右上标签「待机」
listening维持缓慢光晕稳定 0.4；月亮外圈 12 柱音量环（tide1→tide2 渐变，复用 speech-wave 语言）标签「聆听中」+ 识别计时
thinking加速（8s/圈）光晕收拢至 0.25，月面略暗（等待感）标签「思考中」
speaking冻结（角度锁存）光晕强度 0.4~1.0 随 --moon-gain 波动；月面径向渐变同步缩放；色温向 --glow 偏移标签「说话中」+ 当前字幕段高亮（tide3 描边）
reduce-motion（任意态）全部静止仅静态光强差（idle 0.3 / listening 0.45 / thinking 0.25 / speaking 随 gain）标签与音量环数值替代动效

状态不得仅靠动效或颜色表达：每个态必须有右上文字标签 + aria-live 播报（对齐 03 状态与无障碍基线）。

状态矩阵（页面级）

状态标题/说明主动作次动作
ready月伴舞台就绪点击话筒开始说话打字输入（字幕区上方折叠输入框）
blocked（SAPI 缺失）「本机无语音合成引擎，已切换字幕模式」一次性提示继续语音/文字对话查看降级说明
error-retryable（合成连续失败）「语音朗读暂时不可用，字幕不受影响」重试本段朗读忽略（继续字幕模式）
offline/stale沿用既有会话离线提示（LLM 不可达与月伴无关）重试发送退出舞台

无障碍验收点

  • 键盘全流程：召唤（按钮）→ 说话（Space）→ 打断（Esc）→ 退出（Esc）→ 焦点归还，无鼠标依赖。
  • 字幕 aria-live=polite 逐段播报；同段不重复播报；字幕区可滚动且焦点可达。
  • reduce-motion：旋转全部静止；状态靠光强 + 标签；音量环改为数值（如「音量 62%」）。
  • 200% 缩放与小屏：月亮按视口短边百分比缩放，字幕与控制条不遮挡不溢出；对比度满足既有基线。
  • 焦点环在星空背景上仍清晰可见（描边用 --glow）。
