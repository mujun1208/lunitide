Secret 数据流与边界

Renderer configured/ref → Host 编辑容器 → Host-owned 原生安全控件 → OS Credential Store。API Key 不序列化到 DOM、WebMessage、Bridge DTO、Engine、SQLite、日志或遥测。失焦、切页、锁屏、超时、取消和迟到响应均清零。Gateway 清洗鉴权/限流错误。非法迁移来源返回 MIGRATION_SOURCE_INVALID 且无部分写入。

ConsentSnapshot 与 Gateway 门禁

Gateway 解析 SecretRef 前复核 provider/model、system prompt digest、记忆/附件/工具范围、用户确认、expiry、version 与 digest；不一致返回 CONSENT_SNAPSHOT_MISMATCH，过期返回 CONSENT_EXPIRED，且不得建立外部连接。

Secret Lease 租约合同（Legacy 基线继承）

来源：旧版架构 CH.12.4 与旧 S5 凭据底座 7.3。SecretService 仅位于 Host 内部（Put / WithSecret / Delete）；Engine 与 Connector 不得调用通用 Resolve 或取得可长期持有的 Secret 对象，只能通过经认证 Named Pipe 请求短时、单次的 Secret Lease。lease 是 Host 私有宿主能力（Go 侧 secretlease.Client.WithLease），不提升为 Bridge method、不向 Renderer 暴露。

生命周期强制契约
发放（acquire）Engine 调用 secretLease.acquire RPC（Engine → Host，经认证 Named Pipe，不是 Renderer Bridge API），请求包含 providerId、credentialRef、credentialVersion、normalized origin、operation、deadline、requestNonce。Host 复用 IPC 握手的 HMAC 认证会话，校验 Engine 映像身份（PID/SID）与 Provider-origin 绑定后发放
租约属性TTL ≤ 5 秒、单次消费、明文 lease frame ≤ 64 KiB、完整性保护；lease 绑定 Engine session / requestNonce / origin / credentialVersion，重放或换绑一律拒绝
使用范围Engine 只在 connector 出口调用栈内持有 []byte，禁止转换为 Go string；设置 Authorization 头后立即覆盖清零。明文不得被序列化到配置、缓存或持久化存储；任何日志、错误消息、trace span 中不得出现明文。Host 内部可用 WithSecret，作用域仅限 Host
续约无续约语义——lease 不可延长、不可复用；每次外部调用都以新 requestNonce 重新 acquire 新租约
到期与撤销lease 过期、二次消费、PID/SID 或 origin 换绑一律拒绝；Engine 或 Host 崩溃时租约自动失效，不落盘、不残留
审计日志审计只记录租约发放/拒绝/到期的元数据（providerId、credentialVersion、origin、operation、requestNonce、时间、结果与 correlationId），不记录明文或密文；凭据展示类事件另由全局安全审计链追踪
与新版对齐：新版第 02 篇已把"短期 lease、生命周期清零、API Key 明文禁止跨 Renderer/Bridge/Engine 边界"列为密钥泄漏威胁控制，本合同是其 Engine 侧细化。M1 三分口径（主体代码/内部验证/外验）不变：本节为设计基线，不表示已实现或门禁已通过。

Legacy superseded 映射

旧 saveProvider(config,key)、saved/masked key、宽松 Gateway JSON、Provider 原文错误及“configured 即外发”均为 legacy superseded；分别由 provider/Host secret 分轨、独立 schema + AppError、ConsentSnapshot 逐次门禁取代。旧 DTO 只允许离线导入安全元数据。
