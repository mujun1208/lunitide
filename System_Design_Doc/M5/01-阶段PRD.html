M5 / PRD / 已实现（2026-08-16）

统一对话 Agent 与本地执行

M5 是待开发增量：让普通聊天也成为可恢复、可审计的 durable Root Run，并在临时工作区内安全完成文件、Git、Artifact、内建 Skill、受限浏览器与只读远程 MCP 操作。

状态：已实现（2026-08-16）· durable Root Run、AdHocWorkspace、文件/Git/Artifact、Skill、MCP 与浏览器链路经全链路审计与全量回归（docs/evidence/fullchain-review）；本文保留为权威设计。
M5 权威边界：本阶段只交付 durable 普通聊天 Root Run、AdHocWorkspace、文件/Git/Artifact、产品签名命令、受限独立 Browser、HTTPS 远程 HTTP MCP 只读子集、产品签名内建 Skill、后台任务和用户显式转项目。这不等于 M6：不包含第三方生态、stdio、完整 MCP 或强隔离 Worker。
边界功能需求验收指标

1. 范围与原则

目标

  • 统一聊天 Agent 和本地执行入口，不再区分“问答会话”与“执行会话”。
  • 每条普通聊天创建或续接 durable Root Run；进程退出后可恢复。
  • 无项目时使用 AdHocWorkspace，经用户显式确认才转项目。
  • 操作面覆盖文件、Git、Artifact、产品签名 CommandSpec 与后台任务。
  • 独立低权限 Browser；HTTPS Remote HTTP MCP 仅开放只读最小子集。
  • 仅运行产品签名内建 Skill。

明确非目标

  • 不引入九阶段编排，不创建 Child Run，不做 fanout。
  • 不支持第三方 Skill、stdio MCP、任意 shell。
  • 不允许数据库写入，不自动形成长期记忆。
  • 不静默将临时会话转为项目，不扩大网络权限。

3. GWT 验收场景

普通聊天可恢复

Given 用户未选择项目；When 发送“整理这段文本”；Then 先创建 Root Run 与 AdHocWorkspace，重启后可从最后事件续接。

路径逃逸

Given Agent 请求写入 ..\outside.txt；When Bridge 解析规范路径；Then 拒绝操作、工作区无变化并记录错误码。

后台任务

Given 合法签名 CommandSpec 预计超过前台阈值；When 启动；Then 返回任务卡、流式日志与取消按钮，重启后可重连。

只读 MCP

Given allowlist 内 HTTPS MCP；When 服务声明写工具；Then 客户端不注册该工具，仅显示允许的只读子集。

显式转项目

Given 临时空间有未提交 ChangeSet；When 用户点击转项目并确认目标；Then 校验冲突后原子复制，成功前不清理源空间。

无长期记忆

Given 对话包含偏好；When Root Run 成功结束；Then 不生成任何长期记忆记录，后续新 Run 不自动获知该偏好。

完整产品合同：统一对话 Agent 与本地执行

角色与端到端旅程

  1. 用户从普通聊天发起复杂任务；系统创建 durable Run，但不自动创建项目。
  2. 用户按需选择本地目录或 Git 仓库形成 AdHocWorkspace；授权只覆盖明确根目录、操作和期限。
  3. Agent 先分析并生成可审查计划，按依赖执行；只读动作可按策略自动，写入、命令、联网和外部副作用逐级审批。
  4. 变更先生成 ChangeSet 预览；Apply、commit、push 是三个独立动作，后两者不能由前者隐式触发。
  5. 结果可保存为 Artifact；需要长期项目管理时走显式“转为项目”预览/确认，保留来源范围、digest 和权限裁剪。

功能与数据合同

ID需求
FR-M5-16所有普通聊天任务统一使用冻结 M4 durable Run；Run 的 scope 为 personal 或 ad_hoc，不因本机存在项目自动变 project。
FR-M5-17AdHocWorkspace 保存 id、canonical root identity、display path、grant、lease、base digest、Git metadata 与 expiry；路径越界或根身份变化立即阻断。
FR-M5-18本地能力包含 tree/stat/read/readMany/glob/grep、ChangeSet preview/apply/revert、签名 CommandSpec、结构化 Browser 与 Artifact；完整输出留在工作面板，聊天只显示摘要和引用。
FR-M5-19内建 Skill 必须由产品签名并有固定 manifest/version/digest；Skill 匹配只选择候选流程，不授予文件、命令、网络或 Secret 权限。
FR-M5-20远程 HTTP MCP 仅开放 HTTPS、主机 allowlist、逐跳 SSRF 重验、响应上限、超时、SecretRef 和只读 schema 子集；写操作与 stdio 不属于 M5。
FR-M5-21Browser 使用结构化 navigate/read/click/type 等动作和可引用元素；下载、上传、登录、支付、发布等敏感动作由 Policy/Review 单独裁决，不允许注入任意浏览器脚本绕过。
FR-M5-22后台任务可最小化、恢复、取消和通知；应用重启后依据 Run/Step/EffectJournal 恢复，不创建影子任务状态。
FR-M5-23“转为项目”必须 preview/commit：选择消息/Artifact 范围、目标项目或新项目、敏感分类和裁剪结果；默认排除 Secret 与原始工具敏感输出，普通会话仍保持原域且不被改写。

风险与审批

级别示例最低控制
低已授权根内读取、搜索、解析策略允许并审计
中可回退文件写入ChangeSet+checkpoint+CAS
高命令、安装依赖、联网、删除、凭据使用参数化 Review、预算、超时、receipt

异常与验收

  • 文件在预览后变化返回 CHANGESET_BASE_CONFLICT，展示三方差异，不静默覆盖。
  • 命令超时终止完整进程树；取消 P95≤2s；输出超限截断展示但原始证据按策略保存。
  • Browser/MCP 遭遇重定向换址、schema drift 或凭据 origin 变化时撤销旧授权。
  • 普通聊天完成本地复杂任务不依赖项目；显式转项目后来源和 digest 可反向追踪，原会话不变。

Artifact-first 单 Agent 产品增量

  • M5-REQ-HARNESS-001：复杂任务必须形成可审查 PlanVersion，按“选择动作→Policy/Review→执行→结构化观察→验证→纠错或终止”循环；简单问答可跳过显式计划但仍创建 durable Root Run。
  • M5-REQ-ARTIFACT-001：文本回答、工具状态与 Artifact 分流；文件、Diff、测试、截图、报告和后台结果用稳定 artifactId 引用，聊天文本不得冒充执行证据。
  • M5-REQ-CONTEXT-001：在 M3 Context Engine 上叠加 Repo Map、符号/文本/可选语义混合检索与任务工作集；原消息、来源和 Handoff 继续可回查。
  • 停止/接管：达成验收、取消、Policy 拒绝、硬预算、重复失败或 outcome_unknown 时确定停止；保存检查点、当前假设、未完成项和建议动作后交给用户，不无限循环。
  • 边界：仍是单 Root；只允许产品签名 CommandSpec/内建 Skill/HTTPS 只读 MCP。不得据外部蓝图开放 Bash、第三方代码、stdio 或隐式项目绑定。

Dev-Ready 补充：用户故事与 FR 规范化

核心用户故事（As X, I want Y, so that Z）

US-1 普通聊天用户

作为普通聊天用户，我想要在聊天里直接让 Agent 整理文件并生成结果，以便不用先建项目就能完成一次性任务。

→ FR-01/03/04/07；GWT「普通聊天可恢复」

US-2 崩溃后恢复

作为用户，我想要应用崩溃或重启后聊天任务自动恢复且不重复执行写入，以便放心让 Agent 做长任务。

→ FR-13/22；GWT「后台任务」；指标「崩溃恢复成功率≥99%」

US-3 安全敏感用户

作为安全敏感用户，我想要 Agent 的任何越界路径、任意命令和写操作都被拒绝或先经我审批，以便本机数据不被破坏。

→ FR-04/08/14；GWT「路径逃逸」；指标「权限逃逸 0」

US-4 隐私用户

作为注重隐私的用户，我想要聊天内容不自动成为长期记忆、日志不落明文正文，以便保持对个人数据的控制。

→ FR-14/15；GWT「无长期记忆」

US-5 项目负责人

作为项目负责人，我想要把临时工作区里的成果显式转为项目资产，以便后续用九阶段正式管理。

→ FR-12/23；GWT「显式转项目」
