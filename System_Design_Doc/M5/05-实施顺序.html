1. 全局 DoR / DoD

Definition of Ready

  • PRD 的 M5-FR、GWT、错误码和实体字段已评审且版本冻结。
  • M4 执行核复用接口、事件兼容策略、开发 owner 和测试 owner 明确。
  • 威胁建模覆盖工作区、命令、Browser、MCP、签名供应链。
  • Windows 非管理员 CI、故障注入、签名测试证书与 MCP mock 可用。
  • 遥测字段完成隐私审查；无提示词、文件正文、凭据。

Definition of Done

  • 对应 FR/GWT、Unit、Integration、Security、Recovery、Windows E2E 全通过。
  • 错误码、审计、Runbook、迁移/回滚和用户文案同步完成。
  • 无严重/高危漏洞，无任意 shell、业务 DB 写、自动记忆路径。
  • 性能与恢复指标达到 PRD 门槛；feature flag 默认关闭并可即时回退。
  • 产品、架构、安全、测试、可访问性共同验收。

2. 实施切片

Slice 1 / Durable Conversation

Root Run 与 AdHocWorkspace

目标：普通聊天先落盘为单一 durable Root Run，复用 M4 状态机/事件/租约/恢复，自动建立隔离临时空间。

  • 实现 ChatRootRunAdapter、事件 schema、生命周期、幂等发送、恢复扫描、空间配额/到期。
  • UI 提供 Run 顶栏、临时空间徽标、恢复中心最小闭环。
  • 限制：仅消息和空工作区；不开文件写、命令和网络。

切片 DoR：M4 接口与事件迁移演练完成。 切片 DoD：重启/强杀矩阵无重复消息，Root Run 创建率与 P95 达标。

Slice 2 / Local Changes

文件、Git、Artifact 与 ChangeSet

目标：建立工作区内可审阅、可回滚的本地事实链。

  • 实现 FileBridge 的句柄相对访问、原子写；Git allowlist 且禁 hooks；Artifact hash/MIME；ChangeSet 快照、diff、回滚。
  • 交付工作区、diff 审阅、产物页及冲突状态。
  • 专项阻断 junction/symlink/ADS/UNC/设备路径和 TOCTOU。

切片 DoR：路径威胁用例和配额策略冻结。 切片 DoD：越界写为 0，随机 ChangeSet 100% 可回放/回滚。

Slice 3 / Controlled Execution

产品签名 CommandSpec、后台任务与内建 Skill

目标：只通过签名结构化规格执行产品允许动作。

  • 完成签名链、argv schema、环境 allowlist、cwd policy、Job Object、日志/取消/重连。
  • 内建 Skill 随产品包发布并校验签名/能力；无安装第三方 Skill 的入口。
  • 交付动作卡和后台任务页；不接受 shell 字符串或 stdio MCP。

切片 DoR：密钥轮换/撤销与 CommandSpec 清单评审通过。 切片 DoD：注入测试无法生成额外进程，取消 P95≤2s，篡改包全部拒绝。

Slice 4 / Isolated Read-only Network

低权限 Browser 与 HTTPS Remote HTTP MCP

目标：以物理隔离和最小工具集提供只读外部信息。

  • Browser 使用独立低权限进程和临时 profile；协议、下载、内网、本机、重绑定全面阻断。
  • MCP 强制 HTTPS/证书/主机 allowlist/大小和超时，只注册产品声明的只读最小子集。
  • 网页与 MCP 内容均按不可信数据处理，不得改变策略。

切片 DoR：allowlist 所有者、只读语义和 SSRF 测试语料确定。 切片 DoD：网络逃逸与写工具暴露为 0，TLS 负例全部不降级。

Slice 5 / Productization

显式转项目、恢复收口与灰度

目标：完成从临时成果到正式项目的明确交接，并达到发布质量。

  • 实现选择→预检→明确确认→staging copy→原子发布→校验 journal；成功前保留源空间。
  • 补齐响应式、WCAG 2.2 AA、全错误文案、隐私遥测、运维 Runbook、升级/回滚。
  • 以 feature flag 分内部、1%、10%、50%、100% 灰度；安全事件或恢复率跌破门槛自动关闭。

切片 DoR：冲突策略与项目目录 ACL 评审完成。 切片 DoD：转换故障注入全收敛、Windows E2E 连续 20 次通过、联合签字。

质量Windows E2E 需每切片形成增量基线。故障注入框架与 MCP mock 可从第一切片并行建设。

4. 风险、退出与回滚

  • M4 事件不兼容：使用版本化 adapter 和只增字段迁移；不能无损读取即阻断切片 1。
  • Windows 文件语义逃逸：禁止纯字符串校验，使用最终句柄路径复核；安全套件失败即不发布。
  • 签名供应链：离线根、短期签名证书、撤销清单和双人发布；撤销后能力不可启动。
  • Browser/MCP SSRF：每次重定向及连接前重查 DNS/IP；异常率触发远程能力熔断。
  • 灰度回滚：关闭入口并停止新动作；已运行任务按策略安全取消，Run/ChangeSet/Artifact 保持只读可导出。
