M5 / UI · UX / 待实现

统一对话执行界面

用户始终停留在一条对话中，以 Run 状态、动作卡和 ChangeSet 看见执行事实；高风险边界不靠隐式推断。

概览详细状态
M5 权威边界：本阶段只交付 durable 普通聊天 Root Run、AdHocWorkspace、文件/Git/Artifact、产品签名命令、受限独立 Browser、HTTPS 远程 HTTP MCP 只读子集、产品签名内建 Skill、后台任务和用户显式转项目。这不等于 M6：不包含第三方生态、stdio、完整 MCP 或强隔离 Worker。

1. 信息架构与逐页规格

页面主要区域关键操作与反馈
对话首页会话列表、空状态、输入框、能力说明首次发送即建 Root Run；未选项目显示“临时工作区”徽标，不弹模式选择。
对话执行页消息流、Run 顶栏、动作时间线、输入框顶栏显示 Running/等待确认/已恢复；动作卡展示能力、目标、结果码，可取消后台任务。
工作区页文件树、预览/编辑器、Git 摘要、配额路径始终相对根；二进制只读；越界操作就地解释；显示临时空间到期日。
ChangeSet 审阅页文件列表、并排/统一 diff、摘要、回滚入口逐文件接受仅改变审阅状态；回滚前显示受影响文件和当前内容冲突。
后台任务页任务列表、结构化 CommandSpec、日志筛选运行/完成/失败；日志可暂停自动滚动、复制脱敏片段；取消需二次确认。
Artifact 页产物卡、预览、校验信息展示 MIME/大小/SHA-256；危险类型禁内联运行，仅下载。
Browser 页隔离标识、地址、内容视图、访问记录明确“低权限浏览”；阻断地址显示原因；不展示或复用主浏览器登录态。
连接与 Skill 页HTTPS MCP allowlist、只读工具清单、内建 Skill 签名状态无第三方安装入口、无 stdio 配置；签名异常整项禁用。
转为项目向导目标选择、变更预览、冲突策略、确认三步：选择→预检→明确确认；默认不覆盖，完成后提供打开项目与保留源空间选项。
恢复中心可恢复 Run、孤儿任务、损坏记录续接、只读导出、放弃；每项显示最后安全事件和后果。

2. 组件状态

Run 顶栏

  • Created：月牙脉冲，“正在建立可恢复会话”。
  • Running：潮汐进度线，不使用虚假百分比。
  • WaitingUser：琥珀边框，焦点移至确认卡标题。
  • Suspended：显示原因、最后事件时间和“继续”。
  • Succeeded/Failed/Cancelled：稳定图标、摘要、产物/重试入口。

动作卡

  • Proposed → Validating → Running → Succeeded/Failed/Denied。
  • 始终显示动作名称、相对资源、来源（Agent/用户）、持续时间。
  • Denied 不只用红色：盾牌图标+错误码+修复建议。
  • 同一幂等动作重放合并展示“已恢复”，不重复刷卡。

空/载入/离线

  • 空状态说明临时工作区和无自动记忆。
  • 骨架屏保留消息结构，超过 2 秒给文字状态。
  • 离线允许输入草稿但不承诺已发送；恢复网络后由用户确认发送。

冲突与恢复

  • 文件已变化：提供查看当前、重新生成、保留两份，不默认覆盖。
  • 恢复失败：冻结输入，允许导出消息/ChangeSet/Artifact。
  • 空间超限：禁止新写入但保留读取、清理和转项目。

3. 核心交互细则

  1. 执行前：普通低风险文件动作以内联卡提示；需要用户决定的转换、取消、冲突覆盖必须显式确认。
  2. 执行中：消息可以继续查看；输入是否可用由 Run 状态决定。后台化后输入恢复，不将“后台”误写成“完成”。
  3. 执行后：Agent 总结必须链接到 ChangeSet/Artifact 事实；失败摘要保留错误码与重试边界。
  4. 转项目：确认按钮文案为“将 12 个文件复制到 …”，不能只写“确定”；用户确认事件写入审计。
  5. 无记忆：会话信息面板常驻“不会自动写入长期记忆”，不得用深色模式弱化。

4. 响应式布局

断点布局
≥1200 px左 280 px 会话栏 + 中间对话 + 右 360 px 执行详情；详情可折叠。
768–1199 px会话栏收起；对话主栏；执行详情为右侧抽屉，不遮输入框。
<768 px单列；底部“对话/文件/变更/任务”导航；diff 默认统一视图；确认卡全宽。
<360 px / 200% 缩放不横向滚动正文；表格转卡片；代码与日志允许内部横向滚动。

5. 可访问性

  • 目标 WCAG 2.2 AA；正文/背景对比 ≥4.5:1，大字 ≥3:1，焦点环 ≥3:1。
  • 完整键盘顺序：跳到主内容→Run 状态→消息→动作→输入；抽屉关闭后焦点返回触发器。
  • 状态变化用 aria-live="polite"，失败与确认用 role="alert"；流日志不逐行读屏，改为可请求摘要。
  • 颜色之外使用图标、文本和形状；支持减少动画，星空闪烁与月亮漂浮在 prefers-reduced-motion 下停用。
  • diff 行有“新增/删除/上下文”读屏标签；触控目标至少 44×44 CSS px；所有时间显示绝对值与相对值。

页面、组件和交互均为待实现规格，不是现有截图；实现不得加入第三方 Skill、任意 shell 或自动记忆入口。

统一 Run、scope 与实施前冻结参数

语义澄清：“统一 Run 体验”只统一状态、恢复、动作卡和证据体验，不合并普通聊天与项目 scope。普通聊天始终为 scope=personal/unscoped 并绑定 AdHocWorkspace；项目会话始终显式绑定 scope=project + projectId。两者不得静默互借 Workspace、授权、记忆、凭据或项目上下文；转项目只能经用户明确确认和审计。
参数当前设计默认冻结要求页面状态
AdHocWorkspace 配额/清理v1：软限额 2 GiB、硬限额 4 GiB；最后活动后 7 天到期，清理前 24 小时宽限版本化 config 可在安全评审后调整；达到软限额告警，硬限额后只读；保留 Artifact 或转项目会取消对应内容清理正常、接近配额、只读超限、即将到期、清理中、清理失败、已保留/已删除
前台转后台阈值v1：预计或实际运行超过 10 秒，或累计输出超过 1 MiB达到任一条件转后台；用户可提前转后台，不可强制长任务留在前台；事件记录触发原因前台运行、正在后台化、后台运行、重连、取消中、孤儿/失败、完成
HTTP MCP 超时v1：连接 10 秒、首字节 15 秒、总时限 30 秒；只读幂等调用最多重试 1 次连续 5 次失败后熔断 60 秒；验收绑定 config 版本，禁止运行中静默扩大连接中、就绪、超时、熔断、重试等待、撤销
HTTP MCP 响应上限v1：解压后及流式累计均不超过 4 MiB超限立即停止读取并返回 M5-MCP-002，不把截断内容当成功结果；审计实际字节和限制版本接收中、已截断（若策略允许）、超限拒绝、解析失败、成功

在 ADR/config 版本冻结前不得开工依赖这些阈值的实现，也不得事后按实现表现倒推验收线。按 DR-20260814-01，M5 可开发并受控集成；Scope Seal 未解除前必须保持默认关闭且不得对外发布，M6 Child/fan-out 不得启用；本文能力均为待实现。

对话内 Harness 与 Artifact 交互

  • 消息主区只显示结论、当前计划、关键观察与下一动作；工具细节、完整日志和 Artifact 在右侧工作区按需展开。
  • 统一卡片状态：proposed / waiting-approval / running / observed / verifying / succeeded / failed / blocked / cancelled / outcome-unknown；显示 tool、scope、耗时、截断、来源和 correlationId。
  • Artifact 卡显示类型、相对路径、大小、SHA-256 短摘要、生成 Run/Turn、来源、预览/下载/加入上下文；绝对路径不是业务标识。
  • 变更页必须先展示 staged Diff、base 是否漂移、测试建议；逐文件/全部接受与拒绝可键盘完成。Apply、commit、push、转项目仍是独立动作。
  • 上下文检查器展示常驻规则、Repo Map 版本、选中文件、检索命中原因、摘要/Handoff 版本和剩余预算；不展示私有思维链。
  • 达到预算或重复失败阈值时显示“需要你接管”，列出已完成、未完成、失败分类、检查点与安全可选动作。
