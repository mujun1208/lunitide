M7 / TEST PLAN

可追踪发行的质量门禁

覆盖九阶段、追踪、不可变包、同 digest 晋级、数据库迁移、客户端更新分轨、审计和灾备，以及只读子代理（FR-23）的能力白名单、并发预算、级联取消与 TOCTOU 防护；工具分级补齐（FR-24）的 SSRF 合同、只读 SQL 白名单与解析器隔离，MCP 客户端运行时（FR-25）的来源确认、能力漂移 fail-closed 与凭据零回显；定义 48 个稳定错误码。

状态：待实现自动化优先生产门禁
阶段口径：唯一固定九阶段为“立项与边界、调研与证据、需求定义、方案与体验、架构与计划、开发与变更、验证与验收、发布与交付、运营与复盘”。integration、security、package、deployment 只测试其在阶段 6—8 内的门禁/子流程归属，不得注册为独立阶段。

测试层级与数据
