03 · Connections

MCP 与 Connector

HTTP MCP 向导

  1. 基本信息：名称、HTTPS URL、所属项目。
  2. 认证：OAuth 或 Secret 引用选择器；界面永不回显值。
  3. 能力探测：McpServer/McpTool 稳定身份、serverIdentityDigest、schemaDigest、权威 capabilityHash 与风险；schema/hash 漂移显示 grant 已失效并禁用运行。
  4. 策略：超时、重试、网络 allowlist、调用上限。
  5. 健康检查通过后启用；失败可查看脱敏诊断。

stdio MCP 门禁卡

当前：已实现（强隔离 POC 三段证据同 digest，docs/evidence/stdio-5c）/ 按合同管控。展示强隔离 POC 六项证据：进程、网络、文件系统、环境变量、资源、回收。POC 全部通过只允许进入受控实现开发；仅 5C 通过、三段证据绑定同一 digest 且 Security Owner 签字后，生产“创建 stdio Endpoint”才可用。

Connector/DB 元数据浏览器

树

Connector → Catalog → Schema → Table/View → Column/Index/Constraint。支持名称搜索、快照版本和刷新；无数据行预览入口。

只读检查器

显示类型、nullable、键关系、索引、注释、抓取时间与来源。页头固定“元数据只读”，任何写意图显示 M6-DB-001。

04 · Cloud & Delegation

云任务与委派树

创建任务

表单字段：目标、输入摘要、执行区域、HTTP MCP/扩展能力、截止时间、幂等键、总预算、最大深度、单层 fan-out、Child 总数、Barrier 策略。预算实时显示“总额 = Root 保留 + 已划拨 + 可用”。

  • 节点环显示 Token/CPU/费用/墙钟消耗；颜色与图标并用，不只依赖颜色。
  • 点击节点检查 DelegationEnvelope，但 signature、输入仅显示摘要；Secret 区明确“未继承”。
  • 操作：取消、重试、收回未用预算、打开 worktree diff；不提供 Child 直接合并按钮。
  • Barrier 面板展示期望数、到达数、去重记录、迟到结果和封闭原因。

05 · Single Writer

合并队列与最终验证

列内容
序号Root 内严格全序，不可拖拽并行
Child/补丁来源、patchDigest、文件数、测试证据
基线expectedHead 与 currentHead；不一致突出 STALE
状态校验、排队、CAS、应用、已合并、冲突、拒绝
操作查看、请求重新基化、拒绝；写入只由 Root Writer 执行

队列完成后自动进入“最终树验证”全屏步骤：锁定依赖恢复、构建、单元、集成、安全扫描、策略检查。任一失败显示失败测试、相关 MergeIntent 与证据下载；完成按钮保持禁用。

07 · Accessibility

响应式、键盘与文案

  • 1440px 双栏+检查器；1024px 检查器抽屉；≤768px 单栏，树切换为缩进列表。
  • 全键盘访问；焦点可见；树节点使用 role=tree/treeitem；状态变化用 aria-live 宣告。
  • 风险、状态、预算同时用文字、图标和颜色表达；对比度达到 WCAG AA。
  • 破坏性操作先说明影响对象和不可逆部分；错误文案格式为“发生了什么—未发生什么—下一步—错误码”。
  • 时间同时显示本地时间与 UTC；预算数值带单位，费用使用整数微单位计算、界面格式化。

Scope、stdio 交付门禁与 M7 交接

能力上下文显式 scope 合同
personal个人安装/连接与凭据引用；不得读取项目资源。
ad_hoc绑定 AdHocWorkspace 的临时能力；不得因存在项目而升级权限。
project必须携带 projectId、成员鉴权与项目策略；项目只是资源/授权边界，不是能力开关，不能仅凭“在项目中”启用扩展、委派、DB 或网络能力。
stdio 唯一路径：POC → 受控实现 → 生产逃逸验收，三段均需独立证据和安全签字。POC 通过只允许进入受控实现，不代表生产可用；生产逃逸验收须覆盖宿主文件、网络、Secret、进程树、资源耗尽、协议欺骗与恢复。任一段失败或证据缺失即关闭 stdio 能力，M6 不得宣称“stdio 完整交付”，也不得用 HTTP 能力替代该声明。

MCP 继承：M6 必须继承并扩展 M5 的 HTTPS Remote HTTP MCP 安全子集（TLS/证书、主机 allowlist、SSRF 重查、超时、响应上限、SecretRef、只读过滤基线），复用同一 Gateway、策略与审计链；不得建设第二套 MCP Gateway。

交付 M7 的不可缺失输出

  • rootId 与 final-tree digest，证明 Root 唯一 Writer 后的最终树身份。
  • 全序 MergeIntent 清单（expectedHead/currentHead、patch digest、结果、冲突/重基记录）。
  • 最终树 test evidence（不是 Child 局部测试替代品），绑定 build、rootId 与 final-tree digest。
  • extension SBOM、签名/撤销状态、组件 digest 与许可证/漏洞结论。

以上合同均已实现并通过 2026-08-16 全量回归（收口证据 docs/evidence/m6-closure）；诚实边界：S5C 服务（openapi.parse/complexity.decide/skill.import.*）与 CloudRunner 生产装配仍按披露保持关闭（bridge 返回可重试 STORAGE_UNAVAILABLE），stdio Gate 未开放。

08 · S5 Contract UI

数据接口与 Skill 治理界面补充

界面必须呈现阻断/空态
OpenAPI 导入文件/URL、大小进度、$ref 深度、paths 数、解析告警、operation 勾选预览。>5 MB、深度>10、paths>500 立即阻断并显示错误码；ETL/OData 标“legacy deferred / 非目标”。
Integration 详情版本、baseUrl、direction、role、environmentBindings、state、CredentialRef；ApiOperation 的 PaginationSpec/RetrySpec/IdempotencySpec；FieldMapping、权限与审计。只显示凭据别名/末四位与撤销态，绝不回显 Secret。
健康与调用unknown/healthy/degraded/unhealthy/paused 文本+图标；成功率阈值 ≥99%、90%～<99%、<90%；HealthSample 时间线；CallLog 展示 actor/environment/grant/attempt/bytes/statusClass/cost/retry/idempotency/policyDecision 并标注 append-only。paused 禁止调用；unknown 不伪装 healthy；撤销后清空可执行入口。
Skill 安装/升级Manifest 必备字段完整性（含 triggers/dependencies/timeout/resourceLimits）、签名、digest、SBOM、license、权限增量 diff；旧七态映射说明。匹配只显示“候选”，不显示“已授权”；新增权限必须逐项重新确认。

FieldMapping 编辑器须显示 source、target、direction、required、transform（仅 allowlist）、defaultValue 与 schema 版本；预览只用脱敏样例。撤销 CredentialRef 或 Skill 签名后，运行按钮立即禁用并给出受影响 Integration/任务列表。

并行 Agent 可理解性增量

  • 委派树按“目标—输入—能力—预算—状态—结果”展示，默认折叠低价值轨迹；Root 汇总页显示采用/拒绝的 Child 结论及理由。
  • 冲突视图并列来源、base、patch、测试和风险，不提供“AI 自动覆盖全部”动作。
  • 复杂度路由显示为何保持单 Agent或升级多 Agent；用户可降级为单 Agent，不能用 UI 强制绕过安全门禁。
  • 最终树证据卡必须与 Child 局部证据视觉区分，缺 final-tree 验证时禁止显示“已完成”。
