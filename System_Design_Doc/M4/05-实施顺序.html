切换与回滚纪律

  1. 先部署向前兼容 migration 和双读，再启 Engine canonical writer，随后切 Bridge/React；最后停 legacy writer。

  3. 每个 effect adapter 在接入 ToolRegistry 前必须先具备 operation digest、幂等/对账分类和 receipt schema。
  4. Review 必须在 ChangeSet/Command/Web effect 之前接入，不能以 UI 弹窗替代 Engine policy gate。
  5. 回滚不得删除 prepared/unknown journal；旧版本若无法理解新 journal，只能进入只读恢复。
