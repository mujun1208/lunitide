关键流程

  1. 开始：用户发送任务；若需工具且未绑定 Workspace，弹出系统目录选择器，展示规范化根与读写范围后注册。
  2. 计划：可选计划只展示当前 Root 的有序 Step；更新显示版本差异，不提供 spawn/并行按钮。
  3. 工具：对话内 ToolCall 卡显示 16 工具之一、参数摘要、资源、风险、耗时、输出摘要及完整证据入口。
  4. Review：先显示对象、影响、参数、范围、回退、预算、有效期和批准 digest；“批准摘要”与“开始执行”分离，拒绝/要求修改语义分开。
  5. 变更：ChangeSet 按文件 diff 审查；base 改变显示具体 digest diff 并禁用旧批准；应用不等于 commit。
  6. 恢复：启动后显示“发现未完成运行”，列出 checkpoint、最后 receipt、待对账 effect；用户选择恢复/结束/查看诊断，绝不自动重放。
  7. 预算：显示 turns/tool/tokens/cost/time/output/retries；软限额暂停并允许调整，hard ceiling 只允许结束或另起运行。

状态稿合同

状态UI 反馈允许动作
paused_review高风险摘要、策略原因、批准有效期批准、拒绝、要求修改、取消。
changed_after_approval参数/资源/base/policy digest 差异重新审查，不可复用旧批准。
paused_budget各预算使用与触发项在策略允许下增加软预算或结束。
outcome_unknown不确定 effect、已知 receipt/对账建议人工对账、标记外部结果、结束；无“重试”快捷键。
workspace_conflict用户版本与 base diff刷新、重基、另存 patch；禁止覆盖。
cancelled进程树停止、最后安全 checkpoint查看证据或新建运行，不原地复活终态。

React 与可访问性

  • 复用现有 RunCard、ToolCard、ReviewDialog、WorkPanel、DiffViewer 与 EvidenceList 组件风格；状态来自 Engine event projection，不由前端猜测。
  • 流式事件按 seq 去重/ACK；断线显示恢复游标。token delta 可合并，但终态、Review、receipt 不可丢。
  • 键盘可停止运行、打开 Review、遍历 diff；危险按钮有可访问名称和文本状态；dialog 焦点返回触发器。
  • 窄屏右栏转全屏 route；命令输出/diff 局部滚动；400% zoom 保留停止、Review 和证据入口。
文案红线：不得显示“多 Agent 协作中”“MCP 已调用”“Browser 正在操作页面”；这些不属于 M4。

Scope Seal 未完成与解除合同

当前事实：Scope Seal 尚未完成；plan.run.spawn/join/tree 及任何 Child、parent、delegation、fan-out/fan-in 能力在 M4 的 Bridge、Renderer 与 DB 调用链中必须不可达。在以下条件全部具备可复核证据前，按 DR-20260814-01 不阻断 M5 开工和受控集成；但必须阻断 M4 冻结退出、M5 对外发布及 M6 Child/fan-out 启用，不得以 feature flag、隐藏 UI 或“未被正常流程调用”替代隔离。
解除条件（全部 AND）必需证据
handler 不注册生产注册表/路由枚举证明 spawn、join、tree 不存在；直接调用返回稳定拒绝码。
Renderer 零引用构建产物与源码扫描均为零引用，且无动态字符串/兼容分支可调用。

DB 拒绝 parent/delegation约束与事务层同时拒绝非 NULL parentRunId/delegationId，迁移回放和并发写负测通过。
直接 IPC 负测绕过 Renderer 直接向 IPC/Bridge 注入 spawn/join/tree/parent/delegation，全部不可达、无 DB 写入、无 effect，并留审计证据。
