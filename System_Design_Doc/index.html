Architecture Model

三轴融合模型

3 dimensions · unified design

Lunitide 的设计以三轴正交模型组织：纵轴定义智能内核，横轴串联业务流程，斜轴贯穿平台能力。三者交叉形成完整的产品矩阵。

纵轴
五大智能内核
Ontology 本体 Memory 记忆 Skills 技能 Planning 规划 Governance 治理
定义系统的“大脑”能力 — 负责知识表示、上下文保持、能力扩展、任务编排与合规约束。
横轴
九阶段业务主链
1 需求调研 2 架构 3 方案 4 UI 5 DB / 接口 6 开发 7 系统测试 8 集成验收 9 CR / 发布部署
从需求到发布部署的端到端业务流水线 — 每个阶段有明确的输入、产物与门禁规则。S5–S9 是专项文档编号，不等同于阶段编号。
斜轴
横向平台能力
模板引擎 Provider 管理 DAG 编排 审批流 审计日志 诊断与受控恢复
跨阶段复用的平台级能力 — 为所有业务阶段提供统一的底层支撑与治理手段。
融合原则：每个业务阶段（横轴）在执行时调用对应的智能内核（纵轴），同时受到横向平台能力（斜轴）的约束与增强。三轴交叉点即为系统的核心功能单元。
