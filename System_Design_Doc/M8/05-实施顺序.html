推荐顺序与门禁

  1. 先完成 O1/O2，冻结图模型、15 类型和 provenance 契约。
  2. 完成 O3 后只开放影子查询；O4 删除与恢复演练通过前不得成为主读。
  3. 执行 L1 盘点，再做 L2 小批量幂等迁移；迁移器不提供 confirmed 晋升入口。
  4. 按 scope 执行 L3 canary，核对四层计数、降级原因、KB 原文与 Ontology 投影。
  5. L4 必须通过“迁移→删除→备份恢复→图/索引重建→查询”回活测试，再进入 General/Cleanup。
