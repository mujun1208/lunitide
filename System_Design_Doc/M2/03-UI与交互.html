设置页 Save / Apply / 恢复交互

状态呈现动作
inherited显示默认/全局/个人/项目/会话来源当前 scope 覆盖或恢复继承

applying步骤和 correlationId，不误报成功仅安全时可取消
applied/restart-required权威值、来源、待重启项重启或 Revert
conflict/failed版本差异；明确未部分应用刷新重做、导出草稿、Revert
recoveryjournal phase、backup、校验和关联号重试、上一安全版本、只读导出

普通聊天不提供项目 scope。Save 与 Apply 必须可区分；不得把草稿已保存称为已生效。状态用文本与 aria-live；键盘可完成预览、Save、Apply、Revert。

AppError 与离线反馈

UI 只消费统一 AppError，展示安全 message、fieldErrors、correlationId；未知 code 重读权威 scope。离线只允许内存草稿，重连后重新 preview/version check；草稿不写 localStorage，secret 不进入 DOM 持久状态。

Legacy superseded UI 映射

旧“切换即保存”“单字段成功 toast”“隐藏项目设置”“页面自行合并默认值”均为 legacy superseded；新版使用草稿→预览→Save→Apply、整组原子结果、显式 scope 和 Engine 返回的 effective source。
