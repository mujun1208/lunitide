IMPLEMENTATION CONTRACT

UI 实施与验收合同

本文件中的画板是视觉与信息架构意图，不代表功能已经公开或静态按钮已经可运行。正式实现必须满足下列合同；静态 Mockup 自身不算阶段四完成。

Capability 与权威状态

  • Renderer 启动后从 Engine 获取版本化 capability manifest；每个动作必须映射到 Bridge schema、生成 SDK、Engine handler、Policy、状态机和测试。没有公开 RPC 的功能只显示“概念预览/规划中”，主操作禁用，禁止硬编码伪能力。
  • 突变 DTO 返回 status/version/capabilities/reason/updatedAt；请求携带 expectedVersion 和 idempotencyKey。前端 optimistic state 不得放行副作用，事件到达后重新读取权威聚合。
  • 首期 UI 只展示本机 Owner 与逻辑 Agent；多人头像、QA/数据负责人、双人审批和远端 Presence 仅在 ADR-011 capability 启用后出现。

统一状态合同

首页、项目、五视图、接口、DAG、审批、CR、记忆、技能、设置均 MUST 设计并实现 initial / loading / refreshing / empty / error / partial / stale / offline / permission-denied；流式任务还必须覆盖 cancelling、interrupted、reconnecting、retry-exhausted 和 outcome-unknown。每态定义保留旧数据策略、可用动作、重试、错误码/traceId 与 aria-live。

键盘、焦点与组件语义

  • 使用原生 button/link/input/textarea/select；tabs 遵循 WAI-ARIA tablist/tab/tabpanel 和 roving tabindex，支持方向键/Home/End；文件树使用 tree/treeitem 或等价语义列表。
  • 初始焦点仅在无迁移/恢复/错误对话框时进入新对话 textarea；dialog/drawer 使用焦点陷阱、Esc 关闭并把焦点返回触发器。发送处理 Enter/Shift+Enter/Ctrl+Enter 与 IME composition，发送中显示停止而非重复发送。
  • switch 优先使用 checkbox + label；危险确认必须有可访问名称、影响/证据/回退、当前身份、过期与不可逆提示，不仅靠颜色表达状态。

响应式与溢出

  • ≤960px 隐藏侧栏时必须提供同构 menu/drawer、当前项目/分类标题与返回路径，不能让导航消失；平板工作面板使用可调 bottom sheet，手机使用全屏 route，支持关闭/轻览/聚焦三态。
  • 禁止用 body/global overflow-x:hidden 掩盖问题；表格、代码、终端和 tab strip 局部滚动，聊天/代码区域 min-height:0; overflow:auto。在 320px、Windows 200% scaling、400% zoom、键盘-only 和 forced-colors 下不得丢失功能。

高风险交互不变量

  • Review 的“批准摘要”与“开始执行”分离；批准后 Engine 重算参数、资源、计划和策略，成功才执行。拒绝与要求修改为两个动作，理由必填；changed_after_approval 显示具体 digest diff 并禁用旧批准。
  • 模型生成内容只能形成 short_term 记忆候选；用户确认内容、来源、作用域后才可升级 long_term。删除提交墓碑后 UI 立即移出可召回结果，并显示 pending/propagating/failed；失败时内容仍不可读。
  • 五视图必须各有默认/加载/空/错/运行/不可用稿；文件、终端、浏览器、变更不能只以“代码”画板代替。设置作用域显示继承/覆盖/恢复继承，并统一即时保存或草稿保存语义。
