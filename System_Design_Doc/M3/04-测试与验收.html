性能、安全与证据

  • 参考机固定为 Windows 11 x64、4 个逻辑核、16 GiB RAM、NVMe SSD；冷缓存消息 append P95 ≤100 ms、200 条分页 P95 ≤200 ms、1M canonical token 全量 rebuild ≤30 s、单次 compact ≤60 s、峰值工作集 ≤1.5 GiB、临时磁盘放大 ≤2.5×。更低配置可降级提示但不得破坏正确性；RC 必须记录 P50/P95/P99、WAL checkpoint 与参考机指纹，不能用 RC 结果反向修改门槛。
  • 故障注入覆盖事务提交前后、blob 已写 DB 未写、outbox 重投、压缩 checkpoint 中断、墓碑传播部分失败。
  • 安全覆盖伪造 cursor、跨项目 IDOR、附件路径穿越、恶意 MIME、压缩炸弹、缓存残留和已删来源导入。
  • 摘要 deterministic verifier 检查 schema、claim type、source span、quote digest、覆盖率；语义保真使用人工标注 benchmark，不以模型自评。
RC 退出包：build digest、migration checksum/journal、tokenizer artifact、golden corpus、窗口矩阵、故障注入、无障碍、安全扫描和墓碑对账报告必须由外部执行环境签名并互相引用。
