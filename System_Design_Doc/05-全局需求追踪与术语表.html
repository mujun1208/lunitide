3. 追踪键与术语

规范需求键使用 M{n}-REQ-{领域}-{序号}，架构决策使用 ADR-{序号}，威胁使用 THR-{序号}，验收使用 AC-M{n}-{序号}。现有文档 ID 不原地重编号：建立“现有 ID → 规范 ID”映射并保留原 ID 为 alias；一对多时拆分规范 ID 并记录共同来源，多对一时保留全部 alias；映射经 owner 评审后才替换引用。当前尚未逐需求补齐全链。

术语权威定义边界
Root Run用户意图对应的权威 Agent 执行根M4/M5 仅单 Root
Child RunM6 起由 Delegation Envelope 约束的子执行不得直写主工作区
受限 BrowserM5 独立低权限、阻断本机/内网/file/下载执行的浏览能力不是通用浏览器自动化
Remote HTTP MCPM5 仅 HTTPS allowlist 与产品声明的只读最小子集stdio 和完整生态归 M6
强隔离经威胁模型和逃逸测试验证的 OS 安全边界Job Object 本身不充分
正式外部验收独立验收方在指定环境按用例验证并签署证据内部演示不能替代
