关键流程

  1. 策略发布：选择层级→编辑→父级差异→模拟请求→证明只收紧→独立审批→发布版本；无法证明不可提交。
  2. 受控执行：风险/预算→N-of-M→SoD→Runner 路由预览→执行→证据与结算。
  3. 市场安装：签名/权限/审核记录→选择空间→策略模拟→审批→安装钉住版本；撤回展示影响资产。
  4. Legal Hold：权威依据→范围→双人审批→命中预览→激活→访问复核→到期/解除独立审批。

企业可用性

  • 宽屏表格固定首列/表头；保存视图不可跨组织复用。
  • 策略图、审批进度、运营图表提供文本等价；键盘可完成审批。
  • 时间同时标时区；金额显示币种、单位、周期和估算标识。
  • 停用组织、隔离 Runner、撤回包、激活保全须复述对象名，并受 SoD/N-of-M 约束。

实施前冻结的页面契约

页面组路由状态权限边界
目录/身份/策略/org/:orgId/directory、/org/:orgId/identity、/org/:orgId/policiesloading/stale/conflict/blocked/published按 org/space/role；无上下文 fail closed
审批/预算/org/:orgId/approvals、/org/:orgId/budgetswaiting/approved/revoked/expired/reserved/exceededSoD 与 N-of-M；正文另行授权

审计/Hold/运营/org/:orgId/audit、/org/:orgId/holds、/org/:orgId/operationsredacted/held/released/low-sample/error不得读取或推断 M8 私人思维过程、聊天正文、未发布记忆

路由约定：组织控制台全部页面固定携带 /org/:orgId 路径段，与 02 组织隔离不变量一致——org 上下文仅来自已验证会话或签名能力票据，路由段本身不是授权依据，服务端仍强制注入 org_id = :verified_org_id 谓词。组织切换器切换时整棵页面树重建并清空搜索与缓存上下文；缺 org 上下文的裸路径（如 /identity）一律 fail closed 跳转组织选择器，不支持跨组织书签直达。运营页低样本一律显示「样本不足」，对应 FR-12 的 k 阈值口径。

实现前必须冻结路由、全状态枚举、权限矩阵、a11y 与关键阈值（焦点/读屏文本等价、200% 缩放、指标 P95≤15 分钟、低样本阈值、审批/预算/驻留超时）；产品、设计、安全、a11y 与合规共同签字。ADR 未 accepted 时所有动作仅显示“概念/原型”，不得出现可启用生产控件。

组织 Harness 治理 UI

  • 策略包发布向导展示相对父策略的收紧/冲突、受影响工具/Runner/数据和模拟结果；不能提交不可证明单调的策略。
  • 评测中心显示数据集用途/许可/保留、基线、签章和样本阈值；管理员只看聚合趋势与失败类别，不看私人正文。
  • 自动化运行页显示责任人、审批 quorum、预算、驻留、当前 M6 投影和 outcome_unknown 对账入口，不提供第二套重试按钮。
  • 个人→组织导入必须预览脱敏内容、目标组织版本、撤回传播和组织权限；默认取消。
