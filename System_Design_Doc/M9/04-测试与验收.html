专项故障注入

  • 伪造 org_id、缓存键、索引命名空间：全层拒绝。
  • 父策略发布竞态和 PolicyCenter 超时：旧证明失效，失败关闭。
  • 撤票、身份过期、重复投票、时钟偏移：阈值重算且审计完整。
  • 签名根轮换、包撤回、Runner 离线缓存：旧包不再派发。
  • Runner 断网、回执丢失、重复派发：UNKNOWN 安全恢复，副作用不重复。
  • 预算消息乱序重复：双分录守恒且不超硬限额。
  • 备份早于 Hold：恢复先加载保全，禁止物理清除。

组织 Harness / Evaluation 治理验收

  • 跨 org 读取、搜索、计数、缓存、队列、blob、评测和审计的内容及存在性泄漏均为 0。
  • 策略包随机组合属性测试证明 allow 只取交集、deny/required 只取并集、上限只减；不可证明时拒绝发布。
  • EvaluationAttestation 任一 digest 变化即失效；旧签章不得证明新 Prompt/Skill/Policy 组合。
  • 低样本、私人失败轨迹、敏感文件名和提示正文不得从聚合指标侧信道泄漏。
  • Runner 断网、receipt 丢失和 outcome_unknown 只通过 M6 对账恢复；M9 重复派发/第二账本事件为 0。
