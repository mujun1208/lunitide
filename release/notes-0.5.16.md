# Lunitide 0.5.16

装上 0.5.15 之后：一件事经常被拆成好几轮，做到一半要你再发「继续」；媒体中心随口说播一部电影时，公版片直链打不开；模型强度滑块拉不到最右一档；火山语音在月伴正在说话或执行时，下一句被记下等这轮结束。0.5.16 把这几处收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.5.15 可直接覆盖安装。不要覆盖 `v0.5.15` 及更早 tag 的 digest。不要重打 `v0.5.15`。本包挂 GitHub Latest，应用内更新读 `latest.json` 下这一版。

## 1. 一次把正在做的事做完

- 「继续」「好继续」「把没做完的做完」接着上一件实事做，带上完整工具，不再停在只读这一步。
- 只念了计划、文件还没写时，这一轮自己接着写，不用再发一句。
- 写一篇提到「没做完」或「媒体中心」的文章，仍按写文章处理。
- 「请确认是否继续安装」这类批量确认仍会接着做。

## 2. 媒体中心

- 随口说找一部电影在媒体中心播放，改播已核对可打开的公版《Nosferatu (1922)》480p。
- 点名《大都会》按英文片名 Metropolis 去公版片库查。片库没有可直接打开的文件时，仍说明没找到，不拿别的网页顶上。
- 不再对你说「步数达到上限，再发一句」。

## 3. 模型强度

- 低、高、极高三档。拉到极高时圆点贴在最右，旁边是大脑图标。

## 4. 火山语音打断

- 月伴正在对答或执行时，你用火山语音说出下一句，这一句马上送出。
- 云端和本地语音仍先记下，等这轮说完再送。

## 5. 屏幕点选

- 点到已经不在当前画面里的编号时，先重新看一眼屏幕再继续，不再拿旧编号连点。

## 6. 不做

- 不重打 `v0.5.15` 及更早。
- 不改月伴音色、月亮外观和星尘配方。
- 不接入会员片、加密流，也不提供盗版影视站。
- 汽水里搜不到同名歌曲时，不会假装已经在播。
- 不把「任务一定成功」写成承诺。
