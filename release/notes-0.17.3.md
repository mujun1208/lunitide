# Lunitide 0.17.3

上一版装好后，如果你带着手机出门（关 WiFi 用流量），APP 基本没法用：扫二维码打不开配对页，打开 APP 也停在白屏或报错上。这一版把"在外面也能用"彻底打通了。

## 远程访问：任何网络都能用

- **配对二维码首选地址升级**：电脑装了 Tailscale（或同类尾网工具）时，二维码里的地址自动换成尾网地址——它不依赖局域网、不碰光猫防火墙，**手机用流量扫码也能直接加载配对页**。没装尾网工具时行为和以前一样。
- **手机不在 WiFi 下打开 APP 不再白屏**：所有已知地址都连不上时，显示"连不上电脑"页面，可一键**重新扫码配对**或**重试连接**。
- **候选地址并行探测**：启动时同时测全部地址（尾网 / 局域网 IPv4 / 公网 IPv6），先通先用；某个地址卡住时探明可用地址立即切换。此前串行轮换每个坏地址要白等 8 秒，现在通常 1-3 秒内连上。

## 手机端使用方法（一次性设置）

1. 电脑和手机各装一次 Tailscale（免费），用同一账号登录，手机端保持 VPN 开关开启。
2. 手机装本版 APK 后，无论 WiFi 还是流量，打开 APP 扫码即可配对使用。
3. 之后在任何网络打开 APP 都自动直连，无需再扫码。

## 不改什么

- 不改 OCR 识别链路顺序（供应商 OCR → 本地 OCR → Windows OCR 兜底，不用大语言模型看图）。
- 不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。
- 不改既有界面布局与交互习惯。

## 兼容与覆盖安装

- Windows 端直接覆盖安装即可，配置、会话与数据全部保留。
- 手机端覆盖安装新 APK；已配对过的设备无需重新扫码。
- 更新源只认最新版本；本版安装包不得覆盖更早 tag 的 digest。
