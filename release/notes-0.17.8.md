# Lunitide 0.17.8

先说 0.17.7 实测问题的根因：当天实测时**电脑端还是 0.17.6 的旧进程**（0.17.7 在实测后 4 分钟才被自动更新装上），所以扫码横屏（旧 APP）、蜂窝打不开配对页（旧二维码局域网地址置顶）、配对后系统不可用（旧服务端没有新连接协议）全部复现。这一版在 0.17.7 的修复之上，把实测暴露出的两个真实缺口收口。

## 二维码永远可扫：自动换新

- 配对码 5 分钟有效且只能用一次。之前电脑端二维码生成后不会自己更新：配对用掉一次、或放超过 5 分钟，你再扫屏幕上那张码必然报「配对码无效或已过期」，而且不知道去哪换新。
- 现在：「移动伴侣」面板打开期间，二维码**临期自动换新**（剩余不到 1 分钟即重新生成），**配对成功后也立即自动换新**。屏幕上的二维码始终是可扫的，重扫直接配对，不再报过期。

## 电脑端版本过旧时，直接告诉你

- 之前手机端连接验证失败只显示「远程网关错误（404）」，看不出问题出在电脑端没升级。
- 现在手机端会明确提示：「电脑端 Lunitide 版本过旧，不支持新版连接协议。请先将电脑端升级到最新版本，再重新扫码配对。」

## 「进入系统就必须可用」再加固

- 进入系统前的连接验证从「链路探活」升级为「链路探活 + 模型列表读取」双查：两项都真实通过才放行进入，任何一项失败都给出原因和「重新扫码配对」出口，不会把你放进一个不可用的系统。

## 0.17.7 已修复（本版继承）

- 扫码真正竖屏（扫描线横着，不自动转横屏）
- 桥连接搬到 HTTPS：配对能通，系统就能用
- 蜂窝流量（不连 Wi-Fi）可扫码、可下载、可配对：二维码首选公网 IPv6，防火墙已放行
- 进入系统前的可用性闸门：不可用就退回重新扫码配对

## 升级顺序（重要）

1. **先升级电脑端**：Windows 端覆盖安装 0.17.8（或等自动更新），配置数据全部保留。
2. **再升级手机端**：用电脑端 0.17.8 的二维码页面重新下载 APK 覆盖安装——文件名带版本号（Lunitide-Android-0.17.8.apk），一眼可分辨新旧。
3. 打开 APP 重新扫码配对即可。电脑端与手机端版本不一致时，手机端会明确提示升级。

## 不改什么

- 不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。
- 不改既有界面布局与交互习惯。

## 兼容与覆盖安装

- Windows 端与安卓端均直接覆盖安装，配置、会话、已配对信息全部保留。
- 更新源只认最新版本；本版安装包不得覆盖更早 tag 的 digest。
