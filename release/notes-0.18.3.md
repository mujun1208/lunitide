# Lunitide 0.18.3

0.18.2 把联网搜索本身修通了，但还剩一道门没开对：直接输入一个公司名（比如「北京支点互动科技有限公司」），助手不认得这是要查询，回一句「现在实际查一下」就结束；再催一句「查询啊」，它又绕去试被封的第三方搜索通道，几分钟下来一个结果都没有。这一版把「听懂你要查什么」这条路修通。

## 一个词也能听懂要查询

- **根源一**：意图识别此前只认带动词的说法（查询/搜索/查一下……）。光秃秃的公司名、机构名、知识点没有任何动词，就被当成普通闲聊——这一档不挂联网搜索工具，步数预算也只有 1 步，助手刚发现工具就没机会用了。
- **修复**：新增裸实体识别。公司/集团/银行/大学/研究所等机构后缀，以及「是什么/什么意思/是谁」这类知识问法，现在直接按查询意图处理：挂上联网搜索、给足 4 步预算。打开文件、生成图片、写文章这类明确任务不会被误伤。
- 你现在可以直接输入「北京支点互动科技有限公司」或「量子计算是什么」，不用再补一句「帮我查询」。

## 催一句「查询啊」也能走对通道

- **根源二**：追问「查询啊」时，语义分类器把它误判成桌面操作类任务，按那条链路的工具白名单把联网搜索剥掉了。助手只能去试第三方 MCP 搜索——而那些通道在没有密钥的网络环境下是被反爬拦截的，于是 4 分钟、4 万 token 全部空转。
- **修复**：查询意图的追问不再被降级到桌面链路（真正点名要操作某个应用的除外）；0.18.2 修好的内置搜索全程在场。

## 兜底：说完「找到工具了」必须真的查

- 此前助手如果先翻了工具目录（能力发现/MCP 检索），这会被当成「已经查过了」，自动补搜的兜底被解除，而且它拿不到内置搜索工具。现在发现类调用不再算「查过」；如果这一轮真的需要联网搜索而工具被剥掉了，会自动把搜索工具补挂回来、补偿步数并直接注入一次搜索，不再停在「我现在去查」。
- 催查类的短指令（「查询啊」「搜一下」）注入搜索时，会自动沿用上一条消息里的查询对象（比如那家公司名），不会拿「查询啊」三个字去搜索。

## 不改什么

- 不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。
- 不改搜索源顺序与三级回退、审批模式语义、已连接 MCP 配置、工具面（精简/默认）设置。
- 0.18.2 的浏览器标识抓取与标题解析保持不变。

## 兼容与覆盖安装

- Windows 端直接覆盖安装，配置、会话、记忆、已配对信息全部保留。
