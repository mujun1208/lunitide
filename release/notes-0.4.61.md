# Lunitide 0.4.61

四专家机务工作台从「能建卡」走到「能日常录入、追溯、协同」：六域一级导航、全写路径闭环、低空履历 / AOG / PO，以及复盘后堵住的三处卡壳。所有机务输出仍是辅助建议，不构成放行。

## 1. 六域工作台

- 一级左导航：手册 / 排故 / 到期与履历 / 工具化工品 / 航材 / 计划；检查单、审计、机队收入工具组。
- 域头 + 子页签 + 录入对话框；空态主按钮直接打开表单。
- 机尾与 as-of 日期真正过滤列表；批次有效期与工具校准相对 as-of 打徽章。
- 间隔规则表露出版本列；C1–C7 约束徽章化。

## 2. 写路径闭环

- Bridge 写方法覆盖到期、利用率重算、工具借还、批次发放、套件待办、库存 / 替代件、工作包、间隔、窗口 / 机位、部件履历、PIREP、AOG、PO。
- 写动作幂等 + 人审；台账写动作落入审计轨（KB ∪ MRO ops）。
- 利用率写入后重算到期；缺利用率仍显示「未录入」，绝不为 0。
- 日历类到期（CAL / CHECK / AD / MEL）按 due_at 判态，不再被 UsedMissing 误标成「未录入」。

## 3. 低空 / AOG / PO

- 部件履历、谱系、五类触发器、PIREP 草稿。
- PIREP「确认转缺陷」在同机尾写入一条咨询性 CHECK 到期项（`source=pirep:<id>`），不写生产缺陷库。
- AOG 粘贴同时认标签行与自然语言（`B-1234 AOG 需要 PN 3G2000-1 数量2`）；对话框先预览机尾 / PN / 数量再确认入案。
- PO 草稿由库存 / AOG 生成，确认 / 驳回仍由人工完成。

## 4. 四张运营同事卡

- 维修计划 / 航材供应 / 工具化工品 / 低空适航四张卡走专家中心既有 KB、图谱、记忆与引用门。
- 质量通报串查按当前批次挂载 ≤2 张卡并预填批次。
