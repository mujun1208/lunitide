# Lunitide 0.18.2

0.18.1 修好了搜索结果的标题粘连，但还有一层更隐蔽的问题：有些网络环境下（典型是开着代理的机器），中文搜索会返回完全不相关的结果——搜一家公司，回来的却是小红书、知乎热帖、世界杯直播这类内容。这一版把根源修掉。

## 搜索返回真实相关结果

- **根源**：搜索页此前用固定的工具标识（User-Agent）去抓取。无密钥的搜索前端会区别对待这类"非浏览器"访问——DuckDuckGo Lite 直接超时不给结果；必应则在判定访问来自海外时，回一份与查询完全无关的"罐头"热门页（小红书/知乎/世界杯等）。开着系统代理时出口 IP 在海外，正好同时踩中这两条。
- **修复**：搜索页抓取改用真实浏览器标识，其余网络策略（SSRF 固定传输、代理跟随）完全不变。DuckDuckGo Lite 立刻恢复给出正常结果；普通网页抓取仍保持诚实的本地代理身份。
- 三级搜索回退顺序（DuckDuckGo Lite → 必应（中国） → 必应）不变；会话内 `web.search` 工具与后台取证搜索两条链路同步生效。

## 不改什么

- 不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。
- 不改搜索源顺序、审批模式语义、已连接 MCP 配置。
- 0.18.1 的标题解析与时间戳显示保持不变。

## 兼容与覆盖安装

- Windows 端直接覆盖安装，配置、会话、记忆、已配对信息全部保留。
- 更新源只认最新版本；本版安装包不得覆盖更早 tag 的 digest。
