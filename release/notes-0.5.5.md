# Lunitide 0.5.5

0.5.4 装上之后：官方 `@modelcontextprotocol` 那批 MCP 一律卡在握手，超时才报错；对话生成的 HTML 产物预览看着像做好了，点菜单却全无反应；技能中心同名技能仍会两张卡并存，其中一张永远点不动；深度思考模型没干活就报「本轮已达到生成总预算」，到了预算上限只丢一句限额提示，不交代已经做完的部分；同一件事用说的比打字的更早被掐断；组合包里一个装不上的 MCP 会把整包判失败；从快捷方式或 `bin\lunitide.exe` 启动会丢标题栏和托盘图标；把 `web/dist` 整个目录拷进 `web/dist` 会让窗口开在几个月前的旧包上，每个修复都像没发出去。0.5.5 把这些收口进同一版，并把「产品知识中枢」按前台页面落地。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。**本职 9.5 要装上本包后再跑场验清单，本说明不报 9.5。10 分仍要 14 天 soak。**

已装 0.5.4 可直接覆盖安装。不要覆盖 `v0.5.4` 及更早 tag 的 digest。不要重打 `v0.5.4`。本包挂 GitHub Latest，应用内更新读 `latest.json` 下这一版。

## 1. MCP 能握手了

- stdio 通道改回逐行 JSON。此前写的是 LSP 的 `Content-Length` 头，官方 server 按行读，永远等不到一行完整 JSON，握手只能死在客户端超时上。
- 一条消息一行：带内嵌换行的负载直接拒绝，不让它在对端裂成两条。

## 2. HTML 产物真的能点

- 对话产出的 HTML 在独立来源（`preview.lunitide.local`）里当真实网页跑：菜单能切换，`localStorage` 能存。此前是脚本全禁的静态渲染，看着完整、点哪都没用。
- 该来源与应用文档跨源，`connect-src` 为 `none`：页面能跑自己的脚本，但发不出任何请求，也读不到应用的存储和桥。
- 一张票据只授权被预览文档所在的那一个目录，30 分钟过期；票据换文件的路径仍走会话根的原有包含校验。

## 3. 技能中心

- `tpl-grill-me` 和 `grill-me`按同一个技能算。此前当成两个，市场里两张卡，落败那张永远到不了「已安装」，点它等于没点。
- 市场安装是「替换」：装新版会退掉它取代的旧行；库里已有更新版本时明确拒绝，不再静默无操作。启动时的补齐仍然只增不删——正在用的版本必须能活过一次启动。
- 技能列表不再截断到 100 条。列表按最新在前排序，截断砍掉的正好是首次启动装的那批：它们在对话里匹配不到，市场卡也永远停在「＋」。

## 4. 生成预算

- 思考单独计账。思考是丢弃内容，既不朗读也不入库；此前和交付内容共用一个额度，一次深度思考就能在开工前把整轮预算花光，同样的活非思考模型做得完、思考模型报预算满。
- 真在调工具的轮次可以续额，逼近上限的那一项才涨，封顶仍然存在。
- 预算用完不再只留一句限额。会用预留额度做一次不带工具的收尾：已经完成了什么、文件在哪、还剩什么没做，并注明发「继续」可以接着做。

## 5. 语音和打字同权

- 用说的驱动桌面时，步数上限和打字一致。「语音回复要短」管的是说多少话，不是这件事要几步；此前按语音压低步数，等于同一个任务问出口就半途而废。盘点类问句仍然钉在两步。
- `desktop.open` 启动成功、只是窗口探测超时的，算软成功。此前报失败，会把模型赶去爬方法梯子，去开一个已经在屏幕上的东西。

## 6. 能力包

- 包里每个 MCP 单独限时，超时只记一个组件「已跳过」，不再让一个装不上的 MCP 把整包判失败；安装整体上限提到 180 秒（一次冷启动握手本身就可能要 80 秒）。
- 跳过的组件会持久化，卸载时不再被当成别人还在占用。
- 安装成功但有跳过项时，说清是哪个组件、可以稍后在 MCP 页单独修。

## 7. 会议纪要

- 边写边出：模型还在写，已完成的段落就先进文档，不再让人对着转圈等到收尾的那个花括号。
- 每个议题可带「思考」小节，和转写事实分开排版。
- 议题可带流程图：模型只给有序步骤和分支，mermaid 由我们自己生成，导出的 HTML 里画成静态方块箭头，不往导出文件里塞脚本。

## 8. 专家中心

- 清单每行显示这位专家真正会带进一轮对话的技能数和 MCP 数。没配过的专家显示工厂包的数量，因为那正是组合时会给它的。

## 9. 产品知识中枢（管理员）

- 办公组新增「产品总览」，管理员解锁后可见。按前台 17 个页面摊开：每页一张卡，点开是该页卷宗——入口、相关设置、本页功能、本页动态、本页诊断。
- 本轮变更按前台页面分组。跨页的动词（例如「放歌」）会同时出现在主页和媒体中心。
- 功能卡新增「前台页面」一节：这张卡在哪几个页面出现、那些页面之间怎么交接。
- 页面、设置分类、办公菜单开关、媒体动作都从产品自己的前端源生成，不是另抄一份清单；CI 有漂移闸门。

## 10. 图标与部署

- 标题栏和托盘图标从可执行文件内嵌的资源取。此前只找工作目录旁的 `.ico`，从快捷方式、`bin\lunitide.exe` 或看守进程重启起来就没有图标。
- 托盘按小图标尺寸取，不再拿 32px 缩出一个毛边。
- 启动时若发现 `web/dist/dist/index.html`，直接拒绝启动并说明怎么改。这是把整个 `web/dist` 目录拷进已有 `web/dist` 造成的：窗口会开在上一版的包上，每个修复都像没发出去。

## 11. 不做

- 不重打 `v0.5.4` 及更早。
- 不加公网 Gateway，不加无人批准的 `skill_manage`。
- 预览来源不放 `connect-src`，不给它反向进桥的路。
- 不把综合尺 10 分说成本职完成。装上后按场验清单打勾。
