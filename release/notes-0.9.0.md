# Lunitide 0.9.0

装上 0.8.0 之后：代码还停在文件列表里，没法在当前目录里改、看诊断、接受差异；查进程或启动程序仍要先截图猜坐标；说「这里的天气」没有本机位置；给用户看的对比写不进工作区画布。0.9.0 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.8.0 可直接覆盖安装。不要覆盖 `v0.8.0` 及更早 tag 的 digest。不要重签 `v0.8.0`。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 当前打开的代码目录

- 工作区「代码」页打开当前项目。能跳到定义、看诊断、在编辑器里接受或还原差异。
- 写入只落在当前打开的代码目录。绑定了项目、开了全盘完全访问，或打开了代码目录时，可以跑 `go test`、`go fmt`、`npm test`。没有绑定的会话沙箱仍然拒绝。`go test -exec` 仍然拒绝。
- 补全是一行。失败的测试会把文件名和行号带回下一轮，再改那一处。
- Git 只走白名单：`status`、`diff`、`log`、`add`、`commit`、`stash`，并且必须带 `--no-pager`。禁止 `push`、`reset`、`clean`。

## 2. 能用命令完成的电脑操作

- 查进程、列目录、启动已知程序走 `system.run`，参数是程序和参数，不再先截图猜坐标。
- 需要先在设置里打开电脑控制，或打开全盘完全访问。自动编辑模式下仍要你确认这一次。
- `git push`、`reset`、`clean` 在这条路上也禁止。看屏幕、点按钮仍走电脑控制。

## 3. 这里的天气，和一份能看的报告

- 说「这里」「本地」或「当前位置」时，先读本机位置（纬度和时区，没有街道地址），再交给天气预报。没有打开系统定位时会说明原因。
- 对比、说明、分析用工作区「画布」。标题、段落和数字条写在画布上，关掉对话后仍能从这一轮的画布页打开。

## 4. 识图、预览、本机模型

- 对话里的图片先按你配置的供应商识别，再走本机 RapidOCR，再走 Windows OCR。读出文字后直接回答，不再顺手执行命令或操作电脑。没有文字、而当前模型能看图时，图片仍留给模型。
- 工作区里的网页可以点、可以记住本页存储。需要登录的官方页面仍用旁边的应用浏览器。
- 设置里可以选本机 Ollama（`http://127.0.0.1:11434/v1`）。本机没启动 Ollama 时这条不会通。
- 点名的电影仍打开爱奇艺和优酷官方搜索。没点名时仍播放公版《Night of the Living Dead (1968)》。

## 5. 不做

- 不重签 `v0.8.0` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不把 SenseVoice 换成默认听写，也不安装 FunASR、Codex 插件、AnySearch 或仓颉工具链。
- 不把应用内的 browser.close 接上，也不把每一次对话都升到最高执行档。
- 不从爱奇艺、优酷、网易云抓取播放地址。
