# Lunitide 0.13.0

装上 0.12.0 之后：产品中枢的竞品对照没有资料来源，升级建议只能靠印象手填；网页 POC 做出来只有 index.html 进交付卡片，旁边的代码和数据文件不出卡片也导不出去；附件想用电脑上本来装的程序打开，没有入口；屏幕自动化做完只听模型自己说成功，没有人复核。0.13.0 把这几条收口，并把开发机的绝对路径清出仓库文档。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.12.0 可直接覆盖安装。不要覆盖 `v0.12.0` 及更早 tag 的 digest。不要重签 `v0.12.0` 及更早版。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 产品中枢 · 竞品对照（新）

- 自带 Cursor、Copilot、ChatGPT 桌面版、Claude 桌面版、Windsurf、Trae 六个登记源，也可以自己往名单里加。
- 点「采集」只读抓取登记过的公开页；摘录必须与原文逐字一致才入库，来源网址和采集日期由程序盖章，不由模型编。
- 草稿经人工确认后才写进诊断报告的竞品对照，全程不改健康分；一条都没确认时，升级对照退化为一条说明，不编造。
- 对照按四个固定轴分组：本机优先、媒体核验、技能 / MCP、知识自描述。

## 2. 代码也是交付物

- 网页 POC 旁边的代码和数据文件（.js / .ts / .py / .go / .json / .yaml 等 30 多种）现在和 html 一样进对话卡片：能预览、能在交付面板查看、能导出到你的磁盘。
- 图片交付物认 jpg / jpeg / gif。

## 3. 附件用原程序打开

- 对话里的附件条和预览窗新增「原程序打开」：按原始文件类型调系统默认程序；打不开自动退回内置预览，不卡住。

## 4. 屏幕自动化更可信

- 绑定 GUI 型模型（Qwen gui-plus 这类）时，屏幕循环改说模型原生的操作协议：点击、双击、右键、拖拽、按键、滚轮、等待整套动作都按模型训练过的格式来，不再硬翻译。
- 模型报告「做完了」不算数：另一个视觉模型看最后一张截图独立核对目标是否真的达成，核验意见写进结果；连续两次核验不通过就如实停下，不自证成功。
- 同一动作对着同一位置连打三次没有进展，循环自动熔断，不再空烧时间和配额。
- 单轮步数上限从 8 步提到 10 步：这是「桌面集成测试」计划承诺的硬顶。

## 5. 桌面集成测试（agentic-test，新技能）

- 技能库新增「桌面集成测试」：给一份场景清单，它在真实桌面上逐场景「截图看清现状 → 驱动界面 → 再截图验证」，关键节点截图自动留证。
- 每个场景记录编号、前置、步骤、预期、实际、结论（通过 / 失败 / 阻塞）；遇到登录墙或系统对话框标记「阻塞」跳下一个，不代替用户输密码。
- 全部跑完生成「集成测试报告」交付物：汇总计数 + 逐场景明细 + 遗留风险，报告里的截图引用真实存在。只报告事实，没跑的场景不会标成通过。
- 项目推进到测试阶段时，对话会自动提示优先用它做集成测试。

## 6. 仓库不带开发机路径

- 文档、脚本和示例里不再出现开发机的绝对盘符路径，仓库对外更干净。

## 7. 不做

- 不重签 `v0.12.0` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不改媒体中心的歌曲和视频来源。
- 不合并办公流水线。
