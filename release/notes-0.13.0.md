# Lunitide 0.13.0

装上 0.12.0 之后：产品中枢的竞品对照没有资料来源，升级建议只能靠印象手填；网页 POC 做出来只有 index.html 进交付卡片，旁边的代码和数据文件不出卡片也导不出去；附件想用电脑上本来装的程序打开，没有入口。0.13.0 把这三条收口，并把开发机的绝对路径清出仓库文档。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.12.0 可直接覆盖安装。不要覆盖 `v0.12.0` 及更早 tag 的 digest。不要重签 `v0.12.0` 及更早版。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 产品中枢 · 竞品对照（新）

- 自带 Cursor、Copilot、ChatGPT 桌面版、Claude 桌面版、Windsurf、Trae 六个登记源，也可以自己往名单里加。
- 点「采集」只读抓取登记过的公开页；摘录必须与原文逐字一致才入库，来源网址和采集日期由程序盖章，不由模型编。
- 草稿经人工确认后才写进诊断报告的竞品对照，全程不改健康分；一条都没确认时，升级对照退化为一条说明，不编造。
- 对照按四个固定轴分组：本机优先、媒体核验、技能 / MCP、知识自描述。

## 2. 代码也是交付物

- 网页 POC 旁边的代码和数据文件（.js / .ts / .py / .go / .json / .yaml 等 30 多种）现在和 html 一样进对话卡片：能预览、能在交付面板查看、能导出到你的磁盘。
- 图片交付物认 jpg / jpeg / gif。

## 3. 附件用原程序打开

- 对话里的附件条和预览窗新增「原程序打开」：按原始文件类型调系统默认程序；打不开自动退回内置预览，不卡住。

## 4. 仓库不带开发机路径

- 文档、脚本和示例里不再出现开发机的绝对盘符路径，仓库对外更干净。

## 5. 不做

- 不重签 `v0.12.0` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不改媒体中心的歌曲和视频来源。
- 不提高单轮步数上限，不合并办公流水线。
