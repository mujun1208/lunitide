# Lunitide 0.5.10

装上 0.5.9 之后，参考文件夹挂得上却发不出去、Python POC 被误投成办公文档、完全访问下写盘/跑命令失败却说不清原因——这一版把这些问题收口。

## 参考文件夹能发出去

- 拖入或选择一整个参考文件夹后，短文件整篇保留，超长正文只放入开头，并标明完整文件仍在本对话附件里。
- 不再用「最终上下文超过模型输入预算」整轮拦死发送；模型可按文件名继续用工具读全文。

## 源码 / POC 真的落盘、真的跑

- 「开始干 / 落盘」跟在 Python POC 后面时，不再误走 `office.generate`；改为 `workspace.write` + `command.run`。
- 试用技能提示明确：只有 PPT/Word/Excel/PDF 走办公生成；源码与脚本走写盘再运行。
- 「完全访问」但未开「全盘完全访问」时，拒绝写工作区外路径或跑白名单外命令，并直接说明要开哪一项设置，而不是谎称没有终端。

## PDF 正文更靠谱

- 抽不出可读 Unicode 的 PDF 文字层会标为不可读，避免把控制字符乱码塞进对话。
- 带日期与数字的日程类正文仍会当作可读文本保留。

## 不改什么

- 不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。
- 不改执行预算账本设计；本次只收口模型输入上下文装配与落盘路径。

## 安装

从上一版覆盖安装即可。不得覆盖更早 tag 的 digest。
