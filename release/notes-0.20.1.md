# Lunitide 0.20.1

0.20.0 里你可能遇到过：在办公工作台「资产模版」下拉里选中一份较大的模版（原始文件超过约 12 MB），页面顶部弹出红色报错「这项响应有 X 字节，超过单帧上限 16777216 字节」，模版选不上、用不了。根因是模版「读取」链路把整个文件 base64 后塞进单个桥响应帧（上限 16 MiB），而模版「上传」链路早就支持分片——存得进、取不出。这一版把读取链路对称补齐，选大模版不再报错。

## 资产模版分片读取

- **以前**：模版文件超过约 12 MB（base64 膨胀后逼近 16 MiB 单帧上限）时，`template.open` 的响应超帧被丢弃，办公工作台只能弹笼统报错。
- **现在**：新增 `template.readChunk` 分片通道——大模版按 4 MB 分片取回、前端装配成完整文件后照常导入，12 MB 到 128 MB（办公引擎导入上限）之间的模版都能正常选用；小模版仍走单帧内联，不多花一次往返。
- 选中模版前先按模版大小预检：超过 128 MB 引擎上限的会在下载前直接提示「有 X MB，超过办公引擎导入上限 128 MB，无法作为底稿导入。请先压缩文件」，不再白等整份下载后失败。
- 分片读取带完整性校验：逐片核对文件名、总大小、读取进度与结束标记，装配完成后复核总字节数，任一环节不一致立即报「请重试」，绝不静默拼出坏文件。

## 安全边界不变

分片通道执行与原路径完全相同的校验：模版必须属于当前组织、已启用、类型为 PPT/Word/Excel、文件名安全；草稿、其他组织、不安全文件名一律拒绝。

## 不改什么

- 不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。
- 不改资产库上传链路、模板管理界面与 500 MiB 存储上限；9 套品牌主题、图表与 0.20.0 的四项新能力全部保持原样。
- 不引入 CGO 和新的外部依赖。

## 兼容与覆盖安装

- Windows 端直接覆盖安装，配置、会话、记忆、已配对信息全部保留；已存的大模版无需重新上传，升级后即可选用。
- 更新源只认最新版本；本版安装包不得覆盖更早 tag 的 digest。
