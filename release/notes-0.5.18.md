# Lunitide 0.5.18

装上 0.5.17 之后：技能修到 2.0，技能中心仍显示 1.0；点名一部电影时媒体中心播不起来；窗口图标和首页月亮不是同一枚；模型请求超时就结束这一轮；说「继续」对不上未做完的步骤；计划里某一步失败就停；聊天侧栏「办公」标题和条目之间空出一大块；超过 180KB 的截图读不出文字，附件预览也打不开。0.5.18 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。诊断环仍是入口覆盖，表示说明书和活源对齐。

已装 0.5.17 可直接覆盖安装。不要覆盖 `v0.5.17` 及更早 tag 的 digest。不要重签 `v0.5.17`。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 技能中心显示修好的版本

- 生成并发布 2.0 时，同一条技能的版本号换成清单里的新版本，不再另开一行把 1.0 留在列表里。
- 补丁里写明的更高版本同样写回这一行。
- 更低的版本不会把已经更高的标签降回去。
- 这个名字和版本已经被另一条技能占用时，这一条保持草稿，不会发布成旧版本。

## 2. 媒体中心能打开一部公版片

- 点名的电影在公版片库里没有可直接打开的文件时，媒体中心改为播放《Nosferatu》(1922)，回复里写的是实际在播的这一部。
- 歌曲和汽水仍说明没有可直接播放的文件。
- 不接入会员片、加密流，也不提供盗版影视站。

## 3. 同一枚月亮

- 窗口图标、首页「今天想聊什么」和关于页月汐旁边，用同一枚实心满月。

## 4. 超时和「继续」留在这一轮

- 模型请求超时后，同一轮里再试，最多三次，不把这一轮收成无法执行。
- 连接失败，或响应已经写出半段又中断，仍结束这一轮，避免把同一段文字重复写进结果。
- 身份验证失败仍停下来。
- 「继续」「好，继续」接着上一件未做完的事，带上已经完成的工具结果，从下一步往下做。
- 计划里的每一步单独算一轮；这一步的模型调用失败时，同一条步骤再试最多三次，然后进入下一步。

## 5. 侧栏和截图

- 聊天侧栏「办公」的条目贴着标题往下排。
- 大于 180KB 的截图不再塞进模型像素。本机按文字识别读出画面，结果标成「本机文字识别」。附件预览仍能打开这张图。
- 文字识别仍在设置的智能能力里打开。顺序仍是：已绑定的视觉模型，然后 RapidOCR，然后 Windows OCR。

## 6. 不做

- 不重签 `v0.5.17` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不把 SenseVoice 换成默认听写，也不安装 FunASR、Codex 插件、AnySearch 或仓颉工具链。
- 不把诊断环改成语音、播放或任务的实测分。
