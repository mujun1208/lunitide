已装 0.10.2 可直接覆盖安装。不要覆盖 `v0.10.2` 及更早 tag 的 digest。不要重签 `v0.10.2` 及更早版。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

- 项目目录里的网页，用相对路径或完整路径打开，都会进到可点击的预览。
- Windows 把同一文件夹写成短名时，仍然打开那一份文件。
