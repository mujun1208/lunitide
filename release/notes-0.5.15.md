# Lunitide 0.5.15

装上 0.5.14 之后：在媒体中心点名播放时，经常找不到可直接打开的公版文件；同一轮里第二次截图会被供应商拒绝，任务停在无法执行。0.5.15 把这两处收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.5.14 可直接覆盖安装。不要覆盖 `v0.5.14` 及更早 tag 的 digest。不要重打 `v0.5.14`。本包挂 GitHub Latest，应用内更新读 `latest.json` 下这一版。

## 1. 媒体中心播放公版片名

- 在对话里说在媒体中心播放某个片名，会到维基共享资源、NASA、Internet Archive 查找标明公有领域或知识共享、并且地址本身是 mp4、webm、mp3 的文件。
- 找到后直接在媒体中心播放。只说播一部电影、没有片名时，仍播放公版片《Night of the Living Dead》。
- 点了片名但这三个片库没有对应直链时，说明没找到，不再拿网页搜索到的其它文件顶上。

## 2. 同一轮里的下一张截图

- 模型拒绝一张新截图时，去掉这张图片后继续做。下一张新截图若再被拒绝，同样去掉后继续。
- 图片已经不在请求里、供应商仍然拒绝时，这一轮停止。

## 3. 不做

- 不重打 `v0.5.14` 及更早。
- 不改月伴音色、月亮外观和星尘配方。
- 不改 0.5.14 的关窗口、打字发送和下一句发出。
- 不接入会员片、加密流，也不提供盗版影视站。
- 不把「任务一定成功」写成承诺。
