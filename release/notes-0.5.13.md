# Lunitide 0.5.13

装上 0.5.11 之后：周报、表格和演示文稿仍可能被写到桌面，写不进去就停在「无法落盘」；工具步数或回复长度一到上限，文件还没写完这一轮就结束；上下文一满就报无法执行。打字对话里工具轨迹又占住回复上方，当前历史对话看不出选中的是哪一行。已经生成的文件，下一轮修改时又只能复制。0.5.13 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.5.11 可直接覆盖安装。不要覆盖 `v0.5.12` 及更早 tag 的 digest。不要重打 `v0.5.12`。本包挂 GitHub Latest，应用内更新读 `latest.json` 下这一版。

## 1. 文件落在这一次对话里

- 周报、Word、Excel、PPT、PDF 和页面默认写入当前对话文件夹。只有你明确说放到桌面，才会去桌面。
- 桌面暂时写不进去时，文件改落到对话文件夹，这一轮继续做完，不再停在无法落盘。
- 你明确要在桌面新建的文件夹，仍按你的原话放在桌面。
- 第一次写出页面、源码、说明、周报、Word、Excel、PPT 和 PDF，以及之后在原文件上覆盖、升级、改版，都会直接写入文件。后一句即使只说「继续完成输出产物」或「把按钮改成蓝色」，也不会改成让你复制粘贴。

## 2. 写到一半会接着写

- 工具步数用完、或回复被长度截断时，已经写出的正文保留，下一波接着把文件写完。截断的半截工具调用不会拿去执行。
- 上下文超出窗口时，先压缩再重试，不再直接停在无法执行。
- 内容被安全策略拦住时不会自动再写一轮。

## 3. 打字协助

- 多步任务会列出步骤；只有必须你拍板、而且选项会改变交付时，才出现决策卡。语音回合不出现这张卡。
- 打字对话不再展开「工具轨迹」。需要你批准的写入，仍会在回复里写出等待确认的那一句。
- 点到哪一行历史对话，这一行会有选中框。

## 4. 接着问、强度和播放

- 这一轮还在想时，后一句先排在等待区，做完合适的一步再并进同一轮。也可以立即发送，或撤回。
- 模型强度在输入框旁，点开是从更快到更稳的一档。选择会记住。月伴语音不带这一档。
- 媒体进度和音量在松手后才生效，播放可以继续。

## 5. 不做

- 不重打 `v0.5.12` 及更早。
- 不改月伴音色、月亮外观和星尘配方。
- 不提供盗版影视或商业曲库下载。
- 不把「任务一定成功」写成承诺。
