# Lunitide 0.14.1

装上 0.14.0 之后：让写长篇小说、长篇分析报告或论文时，模型经常先深度思考几分钟才肯出第一个字——有些任务 8、9 分钟停在「正在思考…（等待响应…）」，正文一个字没动。两个叠加原因：输入框的思考档位选择器默认就是「高」且永远非空，被当成「你显式要求思考」；而「长篇分析报告论文」这类任务被归为报告类，不在 9 月底那次「小说直出」改造的范围内。0.14.1 把这两路都收口：长篇创作文（小说、故事、长篇报告、分析论文）一律直接流式输出正文，第一秒就能看到字往下写。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.12.0 及以上版本可直接覆盖安装。不要覆盖 `v0.14.0` 及更早 tag 的 digest。不要重签 `v0.14.0` 及更早版。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 长文创作不再空等思考

- 长篇小说、故事、长篇报告、分析论文这类连续成文任务，模型直接流式写正文，不再先烧几分钟推理预算；截断后自动续写的轮次同样保持直出，不会中途又切回思考。
- 真实账号实测（同一长文任务、同一模型）：先思考再动笔要 35.5 秒才出第一个正文、总耗时约 75 秒；直出后 0.5 秒出第一个字、总耗时约 24 秒，正文质量不受影响。
- 长会话的跨轮前缀缓存（9 月底 0.13.2 落地）继续生效：第二轮起不再整段重算历史。

## 2. 思考档位的边界更清楚

- 你明说「深度思考」「认真想」、开启专家议会、或任务本身要求先联网调研时，思考照常保留——档位选择器对这些场景仍然生效。
- 普通工作汇报（周报、测试报告等）不属于长篇创作，行为不变。
- 开发、改代码、排查问题等工程任务不走本分支，档位照旧，完全不受影响。

## 3. 回归锁定

- 新增测试锁定三种行为：默认档位（高）不再杀死直出、星座长篇报告案例必须直出、普通工作报告保持原行为；原有「深度思考字样保留思考」的测试继续通过。
