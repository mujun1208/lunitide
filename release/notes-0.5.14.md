# Lunitide 0.5.14

装上 0.5.13 之后：语音里关掉已经打开的网页或文档，窗口关了仍会说无法执行；关掉浏览器时会去启动新的浏览操作然后失败；这一轮还没说完时下一句卡住，后面再说也没有回复；打开桌面上的软件后，让它在输入框里打字并发送，会停在电脑操作失败。0.5.14 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.5.13 可直接覆盖安装。不要覆盖 `v0.5.13` 及更早 tag 的 digest。不要重打 `v0.5.13`。本包挂 GitHub Latest，应用内更新读 `latest.json` 下这一版。

## 1. 关掉已经打开的窗口

- 说关掉当前浏览器网页，会关掉已经打开的 Chrome、Edge 或 Firefox 窗口，不再另起一轮浏览。
- 说关掉这个文档，会关掉已经打开的文档窗口，不再把文档名当成要退出的软件。
- 窗口已经关掉时，回复说已经关掉了，不再接着报无法执行。

## 2. 在刚打开的软件里打字并发送

- 先打开桌面上的软件，再说在输入框里输入并发送，文字会打进那个软件并发送。
- 「你好发，然后发送」按「你好」发出去，说完会告诉你已经发出去了。

## 3. 下一句会发出去

- 这一轮还在说或还在做时，后一句先记下。这轮结束后会发出去，不再停在「下一句已记下」。

## 4. 不做

- 不重打 `v0.5.13` 及更早。
- 不改月伴音色、月亮外观和星尘配方。
- 不改文件落盘、覆盖改版、工具步数续写和打字协助。那些仍按 0.5.13。
- 不提供盗版影视或商业曲库下载。
- 不把「任务一定成功」写成承诺。
