# Lunitide 0.10.2

装上 0.10.1 之后：对话里选了 Word 和提示词，点发送没有发出去。文件类型也被旧名单拦住，传完到发出去要等很久。0.10.2 把这条收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.10.1 可直接覆盖安装。不要覆盖 `v0.10.1` 及更早 tag 的 digest。不要重签 `v0.10.1` 及更早版。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 对话附件

- 文件框按所有文件打开。文档、表格、幻灯片、WPS、没有扩展名的文件都可以带上。程序文件只保存进当前对话，不会被运行。
- 单个文件可以到 500MB。再大时输入框会说明超过大小。
- 上传按 160KB 一块走，同一份文件的往返次数少了。从文件夹读入也用同样的块。
- 图片处理失败时改为上传原文件，上传不会停在这一步。

## 2. 发送和解读

- 附件已经传完、提示词还在时，一点发送就进入发送，并带着附件和提示词出去。
- 上一句还在发送时会提示稍后再说，不会再出现点了没有反应。
- 发出去之后，抽出的正文和你的提示词放在同一轮里。doc、docx、rtf、odt、wps、pdf、xlsx、pptx 会抽出正文；xls、ppt 会抽出里面能读到的文字。
- 图片放进这一轮的画面。读不出画面时，这一轮仍按文件名和提示词继续。
- 超过 32MB 的文件会保存下来。这一轮若抽不出正文，会说明文件已保存、正文没有放进来。

## 3. 不做

- 不重签 `v0.10.1` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不改媒体中心里已经接上的播放方式。
