# Lunitide 0.16.2

上一版（0.16.1）装上后，手机扫码暴露出一个致命问题：扫码后直接打开的是普通网页界面，完全没有出现配对页——配对码没起任何作用，于是手机上模型列表空、界面英文切不过来、也看不到安装引导。根因在 Windows 端网关的一个路径清洗缺陷：服务静态页时用了操作系统文件路径的清洗规则，在 Windows 上 `/pair` 被清洗成 `\pair`，配对页回退判断永远不成立，所有路由一律回落到主界面。这一版把它修复并钉上回归测试。

## 手机伴侣：扫码真的进入配对页

- **扫二维码出现配对界面。** Windows 下 `/pair` 路由现在正确落到配对落地页：确认电脑指纹、输入配对码、完成配对——0.16.1 及之前在 Windows 上这整条链路实际从未出现。
- **配对之后的三个连锁症状一并消失。** 之前「模型无法使用」「中文无法设置」「无法安装 APP」全部是配对页没加载的下游后果：配对完成后，手机凭据正常保存、语言随二维码同步、安装引导正常展示，无需逐个排查。
- **静态资源缓存头恢复生效。** 同一缺陷还导致带哈希的静态资源长缓存头在 Windows 上从未生效（不影响功能，仅影响加载效率），一并修复。

## 不改什么

- 配对安全模型完全不变：一次性配对码（5 分钟有效、只能用一次、错误 5 次锁定）、设备令牌 180 天、默认 scope 不含设置面、全程审计。
- 月伴 TTS 音色、玉盘像素、星尘配方均不动。

## 兼容与覆盖安装

- 直接覆盖安装即可，配对关系与本地数据全部保留。
- 已配对的手机无需重新配对；但之前扫码直接进了网页界面的手机，请重新扫一次新二维码完成配对。
