# Lunitide 0.5.2

0.5.1 装上之后，月伴「打开汽水音乐随机播放」失败会卡在同一把工具上；媒体中心选了本地文件点播放没声音；MCP「检查并修复」会误解封能力摘要漂移，DuckDuckGo 旧 npm 包也握不上手。0.5.2 把桌面 1-2-3、自有播放器和 MCP 修复收口进 Host。写周报、打开浏览器搜新闻不再被拖去看屏点按钮。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。**本职 9.5 要装上本包后再跑场验清单，本说明不报 9.5。10 分仍要 14 天 soak。**

已装 0.5.1 可直接覆盖安装。不要覆盖 `v0.5.1` 及更早 tag 的 digest。不要重打 `v0.5.1`。本包挂 GitHub Latest，应用内更新读 `latest.json` 下这一版。

## 1. 桌面 1-2-3

- 电脑任务只走专用工具/技能/MCP → observe 后按名字点一次 → 屏幕读号。每步一次，成功即停，中途不报失败。
- 未核验的 `media.play` 先 observe；树上已有「暂停 / 正在播放」就报成功，不要再点播放。
- 电脑控制未开时只说去设置打开，不再改口「未能确认开始播放」。
- 写周报 / 打开 Word 做 PPT 不进梯子，继续 `docx.gen` / `pptx.gen`。打开浏览器搜新闻只检索摘要，不要 observe、不要点页面。

## 2. 媒体中心

- 选本地音频/视频后点播放，走自有会话：`media.session.create` → 打开资源 → 隐藏 `<audio>` / `<video>` 真正出声出画。
- 播放中的进度上报只改位置，不把命令收成暂停或未确认。
- 同一首歌正在播或已暂停时不重开 ticket，避免 src 被换掉静音。

## 3. MCP

- 人点「检查并修复」仍对照市场版本重装握手失败的包。能力摘要漂移的检疫不自动解封。
- DuckDuckGo 目录和修复都走 `uvx duckduckgo-mcp-server`（PyPI），不再用坏掉的 npm 包名。
- `mcp.health` 在漂移/检疫/降级时回健康快照，不再把一次摘要不一致打成 409。

## 4. 不做

- 不重打 `v0.5.1` 及更早。
- 不加公网 Gateway，不加无人批准的 `skill_manage`。
- 不把综合尺 10 分说成本职完成。装上后按场验清单打勾。
