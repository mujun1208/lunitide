# Lunitide 0.9.1

装上 0.9.0 之后：点名电影会连着打开优酷，没点名的片子会进网易云；网页嵌在工作区里会被网站拦住；话说到一半就开了一轮；诊断报告把入口覆盖写成了实测分，点净化只打一个待修复标签。0.9.1 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.9.0 可直接覆盖安装。不要覆盖 `v0.9.0` 及更早 tag 的 digest。不要重签 `v0.9.0`。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 电影、音乐、做完就停

- 点了片名的电影只打开爱奇艺官方搜索。不打开优酷，也不打开网易云。
- 没点片名、只说找一部电影时，在媒体中心播放公版《Night of the Living Dead (1968)》。音乐仍走网易云。
- 播放器已经打开时，回答是「完成。」失败时回答是「失败。」加上原因。
- 搜索有了结果，或第一条新闻已经打开，这一轮就停，不再继续点别的。
- 「帮我打开」「上第一个新闻」这种没说完的口令不会单独开一轮。

## 2. 浏览器和预览

- 网站地址在独立浏览器窗口打开，和系统浏览器同一层，不再嵌进会被网站拒绝的框里。
- 媒体中心里正在播的片子不会再被当成网页打开一次。
- 工作区里生成的页面可以加载自己的脚本、样式和本页存储。选中的文字可以放进对话框。

## 3. 项目目录

- 项目目录只在项目管理里选定。没选目录时进不了工作台，也不再提示再生成一遍目录。
- 选定之后，八个阶段都用这一个目录。

## 4. 诊断净化

- 导出的健康分按本轮实测计算。听写、播放、下载、识图和今天的日志各算一项。图景对照不进这个分。
- 点「执行净化」会把失败的那一项再测一次。复查通过才记已修复，实测分跟着上升。复查仍失败就留在待处理，方案和证据换成这一次的原文。
- 目录里缺的入口方法仍由净化直接补上。精识别运行时没装、周摘要失败，要等同一项检查通过才会从报告里消失。

## 5. 不做

- 不重签 `v0.9.0` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不把 SenseVoice 换成默认听写，也不安装 FunASR、Codex 插件、AnySearch 或仓颉工具链。
- 不从爱奇艺、优酷、网易云抓取播放地址。
