# Lunitide 0.20.0

用 0.19.3 生成 PPT 的时候你可能遇到过：选了品牌主题，可 PowerPoint 里打开母版视图，看到的还是一套默认深蓝色的母版和孤零零一个版式；让 AI 画组织架构、流程关系，出来的却是一堆要点列表；想在页面上放个图标，只能自己去找图；生成完想确认每页长得对不对，只能靠肉眼一页页翻。这一版把 PPT 生成链的四块架构短板一次补齐：品牌真正写进母版层、关系图原生可编辑、图标库内置、渲染像素级自检。

## 品牌母版：换主题，一处生效

- **以前**：品牌色只涂在幻灯片表面，母版和版式层是硬编码的默认色；整份文件只有一个版式，在 PowerPoint 里换版式、改母版都会露馅。
- **现在**：9 套品牌主题的全部 16 种语义版式（封面、目录、章节页、时间线、对比、指标、引用……）真实写进 PPT 的母版与版式层。在 PowerPoint 里打开「视图 → 幻灯片母版」，能看到完整的品牌版式族；在「开始 → 版式」菜单里能直接选用，每一页都认得出自己的品牌。
- 生成时换 brandId，母版、版式、主题色、页面四层全链一致，不会出现上半截是新主题、母版还是旧颜色的撕裂感。

## 关系图：结构内容不再退化成要点

- **以前**：组织架构、流程、依赖关系这类内容，只能被压扁成 bullet 列表，关系全靠读者脑补。
- **现在**：新增关系图版式——节点和连线经确定性分层布局自动排布，用 PowerPoint 原生形状和连接符绘制，不用 SmartArt。生成后在 PowerPoint 里每个框、每条线都可以单独选中、拖动、改字、换色，全是可编辑对象。
- 同一组节点和连线，每次生成排布完全一致（确定性布局），不会因随机布局导致同一份文稿两次导出长得不一样。

## 内置图标库：48 个矢量图标，随主题染色

- 内置 48 个 MIT 许可的 Bootstrap Icons 常用图标（对勾、警告、齿轮、图表、文档、团队等），生成 PPT 时按语义直接引用。
- 图标自动染成当前品牌主题色，栅格化为高清 PNG 注入既有的图片管线——和照片、插图走同一条校验与引用链，不引入新的文件类型。
- 图标引用 ID 由内容确定性派生：同名同内容的图标在任何一次生成中引用 ID 完全一致，保证产物字节可复现。

## 视觉 QA：渲染到像素，自动挑毛病

- **以前**：生成后的自检停在文件结构层，页面渲出来长什么样没有机器检查。
- **现在**：接通 PDF→PNG 逐页渲染管线，生成后自动把每一页渲成位图做像素级检查——页数是否一致、有没有空白页（渲染丢失）、内容有没有顶到页面边缘被裁切（边框溢墨）。发现问题会在质检报告里逐页列出，空白页直接判失败，边框溢墨给出警告。
- 没有安装 LibreOffice 的机器上自动优雅降级为结构级检查，不报错、不阻塞生成；配置了视觉模型时会叠加 AI 视觉审阅。

## 质量闸门

- 全量本地闸门全绿：Go 覆盖率 62.6%（阈值 51%），其中应用主包 75.5%；前端 2900 项测试全过；golangci-lint 0 问题、govulncheck 0 可达漏洞、npm audit 0 告警；生成物零漂移。

## 不改什么

- 不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。
- 不改 9 套品牌主题的色值，不动图表 XML 的字节稳定性约束，UI 界面不变。
- 不引入 CGO 和任何新的外部 Go 依赖；SmartArt 数据文件保持不写。

## 兼容与覆盖安装

- Windows 端直接覆盖安装，配置、会话、记忆、已配对信息全部保留；旧版本生成的 PPT 文件不受影响。
- 更新源只认最新版本；本版安装包不得覆盖更早 tag 的 digest。
