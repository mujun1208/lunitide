# Lunitide 0.13.2

装上 0.13.0 / 0.13.1 之后：如果 Edge 是装在系统目录（C:\Program Files 或 C:\Program Files (x86)，Windows 默认就是这里），对话里让模型用 Playwright 驱动浏览器会失败，模型会说「msedge 内核不可用」，然后绕道别的工具——其实 Edge 一直好好的；多轮对话每一轮都要把整段历史重新算一遍首字才出来，越聊越慢；让模型写长篇小说，它先「思考」好几分钟才吐第一个字。0.13.2 把这三处收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.12.0 及以上版本可直接覆盖安装。不要覆盖 `v0.13.1` 及更早 tag 的 digest。不要重签 `v0.13.1` 及更早版。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. Playwright 找回系统级 Edge

- 月汐给浏览器自动化（Playwright）子进程的环境变量名单里缺了 Windows 的程序安装位置变量（PROGRAMFILES、PROGRAMFILES(X86)、HOMEDRIVE 等）。Playwright 探测系统浏览器路径全靠这几个变量，拿不到就 5 个候选位置全部落空，误报「Edge 未安装」。
- 现在名单补齐 8 个系统位置与解析变量，并对齐主流 CLI（Codex）的 Windows 核心集：含 WOW64 场景的 PROGRAMW6432、命令解析用的 COMSPEC / PATHEXT。这些都是系统位置信息，不是密钥；密钥、令牌仍然一个都不会进子进程，原有安全边界不变。
- 修复后有回归测试锁定：名单里任何一个变量再被删掉，发布前测试就会红。

## 2. 多轮对话提速：前缀缓存命中

- 之前每一轮对话，月汐都会把「本轮时间、本轮任务说明、按轮裁剪的工作流、技能目录」等每轮都变的内容拼进开头的大段系统指令。供应商的前缀缓存认的是开头字节——开头每轮都变，整段历史每轮都作废重算，多轮越聊首字越慢。
- 现在指令拆成两段：开头一段跨轮一字节不变（身份、模式、固定规则），每轮变化的内容改放在你这条消息之后的小段系统提示里。开头字节稳定后，前缀缓存可以复用整段对话历史，多轮对话的首字延迟和 token 消耗都明显下降。
- 修复后有回归测试锁定：同一会话设置下两轮对话的开头系统指令必须字节级一致，谁把每轮内容拼回头部，发布前测试就会红。

## 3. 小说长文直接开写

- 之前让模型写长篇小说、长篇故事，即使你没选深度思考，它也会先「思考」几分钟才写出第一个字。长文创作从推理里得不到好处，等的全是白等。
- 现在这类创作请求在未选推理档、未要求深度思考时自动跳过思考阶段，直接流式出文；你显式选择「深度思考」或推理档位时，原样保留思考。

## 4. 渲染层依赖安全更新
