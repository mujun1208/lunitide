# Lunitide 0.16.0

装上 0.15.2 之后：桌面就是桌面，人一离开电脑，对话、项目、技能都留在那台机器上。0.16.0 给你「移动伴侣」——设置里开一次远程访问，手机扫二维码完成配对，手机上就多出一个可安装的 App（PWA），在同一局域网里随时接着用本机的对话与全部工具，会话双向同步。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.15.2 可直接覆盖安装。不要覆盖 `v0.15.2` 及更早 tag 的 digest。不要重签 `v0.15.2`。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 手机配对，一次完成

- 设置 → 移动伴侣 → 打开「远程访问」：桌面在本机局域网地址上提供加密（WSS）入口，默认端口 47651，页面上能看到监听端口、本机地址和当前在线设备数。
- 点「生成配对二维码」：配对码 5 分钟内有效且只能使用一次。手机浏览器扫码打开配对页，确认页面显示的指纹与桌面一致，输入配对码完成绑定。
- 绑定后按浏览器提示「添加到主屏幕」，手机上就有了一个独立图标的 App；设备令牌 180 天有效，随时可在桌面吊销。
- 首次开启时 Windows 可能弹一次 UAC，那是帮你放行防火墙端口；之后开机自动恢复监听，不再打扰。

## 2. 手机上能做什么

- 打开就是熟悉的对话界面：选会话、发消息、看回复，与桌面实时同步——移动端走的就是桌面同一套加密桥协议，本机的模型配置、技能与工具能力原样可用。
- 支持后台通知：把手机上的 Lunitide 切到后台，桌面有新回复时手机会收到系统通知（权限在配对成功页申请，拒绝不影响使用）。

## 3. 桌面上的管理与审计

- 「移动伴侣」设置页集中管理：远程开关、配对二维码、已配对设备列表（名称、系统、最近地址、最近活跃）、一键吊销。
- 吊销即刻生效：该设备的现有连接立即断开，令牌作废，重新配对前无法再连。
- 「在线会话与审计」分组实时展示当前在线设备，以及最近的安全事件——配对成功/失败/锁定、鉴权失败、越权拦截、方法调用、吊销都有据可查。
- 远程访问开启期间本机不休眠（系统防休眠），关闭即恢复原状。

## 4. 安全口径

- 手机与电脑需在同一局域网；本版不含外网中继。
- 自签证书在本机生成并以 Windows DPAPI 封存，私钥不出机器；设备令牌只存哈希，不存明文。
- 配对码一次性短时效；连续配对失败会触发锁定（防爆破）。
- 桌面端行为不变：不开启远程访问，网关不监听、防火墙不放行，和 0.15.2 完全一样。

## 5. 不做

- 不重签 `v0.15.2` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不改对话界面布局与交互习惯。
- 不改 poison 自愈机制。
