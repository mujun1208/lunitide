# Lunitide 0.5.17

装上 0.5.16 之后：说到「好，继续」有时对不上上一件事；清单写完就停，同一段计划要你再发一句；关于页月亮发虚、数据一格是空的；诊断环上的 100% 看起来像产品满分。0.5.17 把这些收口，并加上可选的第二套本地听写，以及更稳的电脑操作。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.5.16 可直接覆盖安装。不要覆盖 `v0.5.16` 及更早 tag 的 digest。不要重签 `v0.5.16`。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 一件事做到有结果

- 「继续」「好，继续」「嗯，继续」「继续啊」接着上一件实事做，带上完整工具。
- 只写了任务清单、文件还没落盘时，这一轮自己接着写，不再把同一段计划停给你。
- 接着做未完成的事时，不再另开一轮计划。新的复杂任务仍可以按步骤做完。
- 写一篇文章里提到「没做完」，仍按写文章处理。

## 2. 关于页和诊断环

- 关于页使用月伴的月亮图，并写明数据留在这台电脑：会话、记忆和文件。
- 诊断环的名称是入口覆盖。100% 表示说明书和活源对齐，不是语音、播放、文件或任务完成的实测分。

## 3. 第二套本地听写

- 现在这套中文精确听写保持默认，第一次安装不下载新模型，字幕模型也不变。
- 设置里的「听写模型」可以改选 SenseVoice。选中后单独下载，约 228 MB，装好后才用于说完一句后的识别。
- 以后换听写模型也在这里换。这不是另装一套 FunASR 工具。

## 4. 电脑操作

- 目标点名了一个窗口时，先切到那一个再操作。同时对上多个窗口就停下来，请你指定一个。
- 刚刚失败的屏幕编号作废，不会连着再点同一个。
- 焦点明确不在输入框时不打字、不粘贴。读不到焦点的软件仍可以打字。

## 5. 不做

- 不重签 `v0.5.16` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不接入会员片、加密流，也不提供盗版影视站。
- 不把 SenseVoice 换成默认，也不安装 FunASR、Codex 插件、AnySearch 或仓颉工具链。
- 汽水里搜不到同名歌曲时，不会假装已经在播。点名《大都会》时，片库没有可直接打开的文件仍说明没找到。
