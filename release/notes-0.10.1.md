# Lunitide 0.10.1

装上 0.9.1 之后：点名的电影还会去会员网站，没点名的报告会生成一份 Word，一轮任务做到大约十分钟会停下来。0.10.1 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.9.1 可直接覆盖安装。不要覆盖 `v0.9.1` 及更早 tag 的 digest。不要重签 `v0.9.1` 及更早版。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 媒体中心

- 在媒体中心点名电影或歌时，先找可直接播放的公版文件。
- 公版库没有时，电影和歌曲改在媒体中心里播放对接库里的直链。
- 对接库上也没有时，会说明没有这部片子或这首歌，不会改去打开爱奇艺或优酷，也不会拿另一部片子顶上。
- 只说「播放电影」、没有片名时，仍会说明没说出是哪一部。

## 2. 报告和画布

- 没有点名 Word、桌面或网上资料时，调研报告写在工作区画布上。
- 点了 Word、放到桌面，或写明根据网上公开资料，仍生成原来的文档。
- 报告写完画布后，这一轮会停，不再自动另做一份 Word。

## 3. 一轮任务做到完

- 上一轮没做完时接着已写的内容做，不把提纲从头再列一遍。
- 会话摘要只计算上次成功摘要之后新出现的内容。
- 这一轮的模型调用跟着任务时钟走，最长三小时。取凭证的短时限不再把整轮停在十分钟。
- 正在改的页面会保留开头和结尾。这一处还没写进去时会继续改，不要求用户把要求再说一遍。
- 有步骤的任务会划掉已完成的步骤。需要选择时给出一个推荐。做完之后给出两条下一步。一步就能写完的，不先列计划。
- 技能全文留在这一轮里，尾部约束不会被收成摘要。
- 打开桌面上的文件时，仍然带着打开文件的工具。

## 4. 代码和诊断

- 在代码里转到定义，会停在目标那一行。从文件树另开文件时，不再留着上一行。
- 产品版本变了之后，中枢按新版本重新汇编，并保留上一轮实测结果。
- 净化复查仍失败的项继续算未修好，不会被写成已经通过。

## 5. 不做

- 不重签 `v0.9.1` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不打开爱奇艺、优酷页面。
