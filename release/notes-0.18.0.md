# Lunitide 0.18.0

0.17.9 及之前，让月汐用上新能力有几处不顺：问它「能不能抓网页转成 Markdown」，它并不知道自己手上有哪些 MCP、哪些内置工具、还能一键装哪些；让它装一个 MCP 服务器，手动审批模式下要么一句「本轮不执行」把你挡回去、要么在别的模式下悄悄就装了，没有一张写清楚权限的审批卡；搜索引擎一抽风整轮联网检索就失败；说「打开 baidu.com」它偏偏跑去搜索列表。这一版把这些从「碰运气」收口成一条正经的能力链路：查目录、征得同意、审批卡放行、记住你的偏好。

## 月汐能查自己的能力目录了

- 现在月汐有一个 `capability.discover` 工具：你用中文说需求，它会把四类来源一次查全——**已连接的 MCP 工具、内置工具、可用技能、一键可装的 MCP 预置**，并告诉你每一项是现成可用的还是要装/要配密钥。
- 中文需求能直接匹配英文工具描述（比如「抓取网页转成 Markdown」能匹配到 fetch 预置），不需要你翻译成工具名再问。
- 找不到匹配时它会明确说「没有找到匹配能力」，而不是硬凑一个工具交差。

## 安装 MCP 服务器有正式审批卡了

- 「帮我装一个 fetch MCP」现在走和文件写入、命令执行同一条**标准审批流**：审批卡上写清楚装的是哪个服务器、做什么用、会在本机以什么命令启动第三方服务端、要不要 API 密钥、密钥不进对话。
- 授权粒度和其他工具一致：**本次允许 / 本会话允许 / 始终允许**。
- 自动审批和完全访问模式保持原有语义直接执行；语音月伴轮次**不会**自动装（安装属于信任决策，永远弹卡）；来自外部同事的无人值守消息一律不装。
- 装过的预置不会装第二份：已安装并在线的预置再次安装会直接返回「已装好」；目录里也会标注「此前已安装过，重新连接对应端点即可」。
- 新装的工具**从下一轮对话开始生效**，本轮月汐会向你报告安装结果，不会自说自话连着用。

## 月汐记住你的能力偏好

- 你批准安装过的 MCP 预置会记进**项目记忆**：下次在同一个项目里提同类任务，月汐直接用对应工具，不用你再指导一遍。
- 需要配密钥的预置，记忆里也会记下「待配置」状态，月汐会提醒你去设置页补密钥并连接。

## 项目级 LUNITIDE.md 偏好声明

- 在仓库根目录或子目录放一个 `LUNITIDE.md`，写上这个项目的工具与能力偏好（比如「网页抓取优先用已连接的 Fetch MCP」「检索一律先用 web.search」），月汐在每次对话里都会带上它。
- 与 `AGENTS.md` 并列生效、就近覆盖，文件体例和读取规则也一致；没有 `AGENTS.md` 的项目可以只用 `LUNITIDE.md`。

## 联网搜索三级回退，不再一源失败整轮报废

- 一个搜索源返回挑战页、报错或零结果时，自动换下一个源重试：**DuckDuckGo Lite → 必应（中国）→ 必应**。
- 之前内置搜索和 webfetch 各自为战的挑战页识别逻辑已合并成一套共享判定，两边的回退行为一致。

## 「打开 xxx.com」直接开浏览器面板

- 带网址的打开请求（「打开 baidu.com」「打开百度」）现在**直接弹出内置浏览器面板**开始浏览，不再绕道搜索结果页。
- 说「查一下」「搜一下」这类检索意图仍走搜索，不弹面板；浏览器面板已开着时，跟随链接的行为不变。

## 不改什么

- 不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。
- 不改既有审批模式语义：手动审批弹卡、自动审批直行、完全访问直行。
- 不改已连接 MCP 的配置；本版升级后无需重新配置任何端点或密钥。

## 兼容与覆盖安装

- Windows 端直接覆盖安装，配置、会话、记忆、已配对信息全部保留。
- 更新源只认最新版本；本版安装包不得覆盖更早 tag 的 digest。
