# Lunitide 0.17.1

上一版（0.17.0）手机装上了真正的 APP，但顺手的路还没铺完：配对要在浏览器里扫码、再把授权转进 APP；APP 里偶尔弹「远程请求过于频繁」「补充输入状态暂时无法读取」这类提示，打断正常使用。这一版把最后一段路铺平：**装好 APP 直接扫码配对即用，不再有任何频率限制与报错打扰**。

## APP 内扫码配对（改进）

- 打开 APP 首屏就是「扫码配对」按钮，对准电脑端「设置 → 远程访问」的二维码，配对直接在 APP 内完成——不再需要「浏览器扫码 → 下载 → 转授权」的绕行路径。
- 浏览器扫码后转入 APP 的老路径仍然可用，两条路都通。

## 去掉远程限流与报错打扰（改进）

- 删除远程连接的每分钟请求上限（原 120 次/分钟）：手机端与电脑端使用体验完全一致，不限频率、不限速度、不限调用次数。
- 「远程请求过于频繁，请稍后重试」（REMOTE_RATE_LIMITED）不再存在。
- 「补充输入状态暂时无法读取，请重试核对」不再弹出：网关瞬断时静默自动重试，界面不打扰。
- 连接可靠性不变：WebSocket 断线自动重连、指纹校验、设备授权与吊销等安全模型全部保持。

## 蜂窝流量直连家里电脑（不变，再确认一次口径）

- 家里电脑开机并开启「远程访问」，人在外面手机关掉 Wi-Fi 用流量，APP 自动从局域网地址切换到公网 IPv6 直连家里电脑。
- 前提：光猫/路由器开启 IPv6 并放行入站。电脑端「设置 → 远程访问 → 外网可达性」可检测当前状态并给出路由器设置指引。

## 安装与升级口径

- 桌面端安装包（`Lunitide-Setup-0.17.1-x64.exe`）覆盖安装 0.17.0，配置与已配对设备全部保留。
- Android APK（`Lunitide-Android-0.17.1.apk`）与 0.17.0 同签名，直接覆盖安装即升级；已配对信息保留，无需重新配对。
- 不改动更早 tag 的任何产物。

## 不改什么

- 月伴对话、月伴 TTS 音色、玉盘像素、星尘配方均未改动。
- 桌面端界面与功能、既有配对凭据、网页版（PWA/快捷方式）路径保持 0.17.0 口径。
