# Lunitide 0.16.3

上一版（0.16.2）装上后，手机扫码终于出现配对页、配对成功、界面变中文、模型也能选了——但实际聊天时又撞上新问题：第一次发消息提示没配置模型、再发提示「远程请求过于频繁」、偶尔有回复但带报错、点安装又显示「无法安装此应用」。这一版把这几件事一次收口。

## 手机伴侣：聊天不再被限流卡住

- **正常聊天不再触发「远程请求过于频繁」。** 根因是远程网关的每分钟请求数上限（30 次/连接）定得太紧：手机打开页面时就会并发预取模型、会话、专家等列表（15-25 个请求），再发一轮对话立即触顶，后续请求被拒——「没配置模型」「无法发送」「补充输入状态无法读取」全是被限流误伤的连锁反应。上限放宽到 120 次/分钟（持续每秒 2 次以上才会拦截），防滥用语义不变，并有回归测试钉住：模拟一次冷启动加一轮对话的 50 个请求必须全部通过，超量滥用仍然拦截。

## 安装引导：说清「无法安装」的原因和正确做法

- **配对成功页的安装指引按 Chrome 当前菜单重写。** 在内网自签证书下，Android Chrome 的「安装」选项显示「无法安装此应用」——这是 Chrome 的安全模型（不允许此类网站安装成应用，任何网站都无法绕过），不是故障。指引现在逐步说明：点浏览器右上角 ⋮ 菜单 →「安装并创建快捷方式」→ 选「创建快捷方式」，并明确告知快捷方式功能完整可用、图标与名称同应用一致。看到「无法安装此应用」属正常现象，直接选「创建快捷方式」即可。
- 应用清单补全稳定标识（id），避免将来安装出现重复图标。

## 不改什么

- 配对安全模型完全不变：一次性配对码、设备令牌 180 天、scope 控制、全程审计；限流仍在，只是不再误伤正常使用。
- 月伴 TTS 音色、玉盘像素、星尘配方均不动。

## 兼容与覆盖安装

- 直接覆盖安装即可，配对关系与本地数据全部保留。
- 已配对的手机无需重新配对；如仍遇到「远程请求过于频繁」，等待一分钟后再发即可（不会在正常使用中出现）。
