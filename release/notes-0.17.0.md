# Lunitide 0.17.0

上一版（0.16.4）的手机端是网页快捷方式：自签证书下 Chrome 拒绝把站点安装成应用，你只能「创建快捷方式」；更实际的落差是——出家门切到蜂窝流量后，局域网地址全部不可达，手机与家里电脑彻底断联。这一版把它收口：现在有一个真正的 Android APP 可安装，配对页扫码即提示下载安装，装好后在家走 Wi-Fi、在外走蜂窝流量（IPv6 直连）都能连回你的电脑。

## Android APP（新增）

- 手机扫电脑端「设置 → 远程访问」二维码，配对页会提示「安装 Lunitide APP（推荐）」，安装包直接从你的电脑下载（`/app/lunitide.apk`），无需应用商店、无需外网。
- APP 安装后无需重新配对：在浏览器完成配对的页面点「已在 APP 中打开（带入授权）」，授权自动转入 APP；或装好 APP 后重新扫码，用 Lunitide 打开即可。
- APP 是零业务逻辑的壳：界面每次从电脑端现拉，电脑端升级改版后 APP 自动使用最新界面，**APP 本身不需要跟着更新**。
- 已在浏览器配对过的老设备不受影响：网页版与快捷方式照常可用，APP 只是新增一条更完整的路径。

## 蜂窝流量直连家里电脑（新增）

- 配对时网关会下发多候选地址（局域网 IPv4 + 公网 IPv6）。APP 在家优先走 Wi-Fi 局域网；出门后 Wi-Fi 地址连不上会自动轮换到公网 IPv6 直连家里电脑，全程无需手动切换。
- 前提条件：光猫/路由器开启 IPv6 并放行入站（电脑端「设置 → 远程访问 → 外网可达性」新增了检测与路由器设置指引）。未放行时 APP 在外网依旧不可达，这是网络层限制。
- 安全模型不变：连接始终校验电脑证书指纹（配对时锚定，变更即拒绝），设备授权 180 天、可随时在电脑端吊销。

## 安装与升级口径

- 桌面端安装包（`Lunitide-Setup-0.17.0-x64.exe`）可直接覆盖安装 0.16.x，配置与已配对设备全部保留。
- Android APK（`Lunitide-Android-0.17.0.apk`）为独立附件，首次安装需允许「未知来源/安装未知应用」；后续版本同签名可直接覆盖升级。
- GitHub Latest 的 `latest.json` 与 `SHA256SUMS.txt` 覆盖全部附件；不改动更早 tag 的任何产物。

## 不改什么

- 月伴对话、月伴 TTS 音色、玉盘像素、星尘配方均未改动。
- 网页版（PWA/快捷方式）路径、既有配对凭据、限流策略（120 请求/分钟）保持 0.16.4 口径。
