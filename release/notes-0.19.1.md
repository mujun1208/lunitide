# Lunitide 0.19.1

0.19.0 把「误判不再丢能力」修好了，但留下一个新的口子：当环境本身出问题（比如系统代理挂了、断网）时，助手拿到的是完整工具面和充足预算——结果就是拿 24 步预算反复重试一条已经死掉的通道，十几轮循环、二十多万 token 烧完，一个结果都没有。这一版补上最后一道闸：通道坏了就止损，把实情告诉你。

## 同一通道连续失败 2 次，第 3 次重试直接拦下

- 以前：联网搜索失败后，助手会一次又一次原地重试 web.search，每轮重试都把全部上下文重发一遍，几分钟、几十万 token 全部空转。
- 现在：同一工具连续失败 2 次后，第 3 次盲目重试会被闸口拦下，并明确提示「该通道疑似故障，换通道或基于已有信息回答」。
- 被拦的重试不会再偷偷在后台执行——并行执行通道同样遵守止损，一次都不多烧。

## 整轮失败超限，全面止损并告知实情

- 以前：助手还会换着花样绕路——联网搜索不行就抓网页、写脚本跑 curl，每条路都撞死在同一堵墙上，预算烧光才停。
- 现在：一轮内累计失败 4 次后，所有工具调用全部拦停（只剩向用户提问的通道），助手基于已有信息收尾，并明确告诉你「疑似环境故障（系统代理不可用、断网），请检查网络或代理设置」。
- 你会看到哪条通道坏了、该怎么办，而不是几分钟的全程叙述加零结果。
- 预算升级也联动止损：失败超限的轮次不再自动升档续跑，不再给死通道追加预算。

## 偶发失败不受影响

- 失败一次就成功的正常波动（网络抖动、暂时超时）不会触发止损：只有「连续」失败才计数，一次成功就清零。
- 联网搜索失败的结果不再被误当成「已核实材料」，报告类交付的核实标准更严了。

## 不改什么

- 不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。
- 不改 0.19.0 的工具面、三档预算、闸口提示与升级机制；止损只在「通道确实坏了」时介入。
- 会话恢复与历史记录兼容，旧版本数据直接继续用。

## 兼容与覆盖安装

- Windows 端直接覆盖安装，配置、会话、记忆、已配对信息全部保留。
- 更新源只认最新版本；本版安装包不得覆盖更早 tag 的 digest。
