# Lunitide 0.5.9

0.5.8 装上之后：做周报或演示文稿时，模型漏了版本号，文件写不下去。打开桌面浏览器去搜索，后面的电脑操作会被记成失败。汽水音乐只发出了播放键、还没确认在播，语音却说已经在放。Agent Hub 连着发两条会撞上同一条序号，Codex 中途断开也没有失败说明。语音听写有时会把你刚说的前半句吃掉。打字做多步任务时，没有推荐选项，步骤也收在折叠面板里。0.5.9 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.5.8 可直接覆盖安装。不要覆盖 `v0.5.8` 及更早 tag 的 digest。不要重打 `v0.5.8`。本包挂 GitHub Latest，应用内更新读 `latest.json` 下这一版。

## 1. 办公文件能落盘

- 生成 Word、Excel、PPT、PDF 时，补上缺的版本号、标题和类型，并丢掉规范里写不进文件的多余字段。内容齐了就会写出文件，不再停在「参数无效」。
- 周报仍只写会话里已有的事实，不编造完成率或节省百分比。

## 2. 播放和桌面搜索按真实结果收口

- 没点名的电影，仍在产品自己的媒体中心播放公有领域的《活死人之夜》。点了片名但没有可播放文件时，会说明没找到，不假装在播。
- 播放键已经送到播放器、但还没确认开始播放时，会说「已发送，尚未确认」，不会说已经在放。确认到正在播放，才说已经开始。
- 桌面浏览器已经打开搜索页之后，不再把后续的点击记成这一轮失败。语音会说搜索页已经打开。

## 3. Agent Hub 一轮只记一条，断线会说明

- 同一条对话里连着发送，序号不再撞车。上一轮还在跑时，第二条会被告知正在忙。
- Codex 连接在回复到达前断开，这一轮会留下可见的失败，而不是一直停在进行中。

## 4. 打字时有推荐选项和步骤，语音不要卡片

- 打字对话里，必须你拍板时会给出选项，其中一项标成推荐并预先选中，也可以选「其他」。多步任务会在回复上方列出步骤，做完的会划掉。
- 语音对话不弹这些卡片，也不念步骤清单。听写不再把同一次识别里、结果从后半句开始的前半句丢掉。

## 5. 不做

- 不重打 `v0.5.8` 及更早。
- 不改月伴音色、月亮外观和星尘配方。
- 不提供盗版影视或商业曲库下载。
- 不把「任务一定成功」写成承诺。
