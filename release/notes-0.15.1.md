# Lunitide 0.15.1

装上 0.15.0 之后：模型把活干完了却不给你一句交代，只回一句「这一轮没有回答。」；排队发出去的内容已经接着上一轮说了，输入框上却还挂着「已排队，将在当前步继续…」的旧提示；个别桥接调用偶发报 INVALID_BRIDGE_RESULT，长对话的流式回答出错后重试会丢上下文。0.15.1 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.15.0 可直接覆盖安装。不要覆盖 `v0.15.0` 及更早 tag 的 digest。不要重签 `v0.15.0`。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 干完活必有交代

- 对话中途补充一句新要求（比如让报告加个评分），模型调用完工具后现在会做一次收尾总结：说清这轮完成了什么、哪些还没做完、为什么没做完，不再只用「这一轮没有回答。」顶替。
- 收尾总结真的一个字都拿不回来时，才保留「这一轮没有回答。」这句兜底提示。
- 已经落地的结果（写进文件、放上画布、改了页面）仍然第一时间告诉你，不等总结。

## 2. 排队提示即时收口

- 排队的内容一旦随当前轮发出，输入框上的「已排队，将在当前步继续…」提示立即消失，不再残留误导。
- 停止回答后队列提示的清理路径同步修正，停止和排队两个动作叠加时状态不再互相卡住。

## 3. 桥接与流式更稳

- 前端桥接调用的结果校验放宽到真实返回形状，偶发的 INVALID_BRIDGE_RESULT 报错消除。
- 流式回答中途出错时，已收到的内容和轮次状态完整保留，重试从断点续上，不再丢上下文重头再来。
- 推理模型的思考内容与交付内容分开计量，深度思考不再挤占交付额度。

## 4. 不做

- 不重签 `v0.15.0` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不改对话界面布局与交互习惯。
