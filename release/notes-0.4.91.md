# Lunitide 0.4.91

0.4.90 装上之后，桌面任务仍会点错设置页、长文本一个字一个字打、屏幕操作做完也不知道成没成。个人 Work 里生成 Excel/Word 还会撞上组织隔离。对话里的「生成音频」听起来像作曲，实际只是朗读。技能中心从 GitHub 导入要点提交 SHA，按钮等于坏了。0.4.91 把这些未提交的产品补丁一次收进安装包。覆盖升级仍走 GitHub `latest.json`。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。不把 AgentHub 焊进 SessionPage。不重做办公 PPT 视觉稿。不把本机 OCR 换成 PaddleOCR-VL-1.6。

已装 0.4.90 可直接覆盖安装。`v0.4.91` 的 Setup + `latest.json` 挂到 GitHub Latest。不要覆盖 `v0.4.90` / `v0.4.89` / `v0.4.88` / `v0.4.87` / `v0.4.86` / `v0.4.85` / `v0.4.84` 的 digest。不要重打 `v0.4.90`。

## 1. 桌面控制

- 应用名 + 动作（打开 / 进入 / 关掉）走桌面任务路由，不再把「打开蓝牙设置」当成闲聊。否定句（不要打开）不会误触发。
- 系统设置页优先走 `ms-settings:` / `shell:`，不再在设置窗口里一层层点。
- `computer.act` 一次可跑 2–8 个具名动作。长中文或超过 16 字改粘贴，不逐字敲。
- 命名点击失败或连两次空控件树会进入 GUI 视觉循环：看屏幕 → 点 → 核验，最多 8 步、每轮 2 次。走现有 `cc.*` 闸门。
- 回合结束用最终截图判定 done / not_done / blocked / unclear。没做完会再试；失败轨迹不会写成技能草稿。
- 成功的 GUI / 桌面轨迹可以存成草稿技能，不自动发布。
- 前台是浏览器时提示改用 `browser.act`。observe 节点截短、去无名重复；settle 按界面是否还在变自适应等待。
- 供应商 GUI 预设用能看屏幕的模型（Doubao UI-TARS / GLM-4.xV / Qwen3-VL），不要把纯文本模型填进 GUI 槽。

## 2. 个人办公

- 个人 Work 会话生成 Excel / Word / PPT 固定走 personal 分区。绑定了组织也不能把个人文件写进 org 空间（M9-003 只拦跨组织，不拦个人会话）。
- 读 Excel 不再走会在畸形共享字符串上崩溃的 `GetRows`。坏文件会失败返回，不会把引擎打掉。

## 3. 对话音频

- `audio.generate` 是对话里可点播放的朗读合成，不是作曲。产品没有作曲引擎，不会假装已经生成可听歌曲。下一步建议也不会改成「改歌词」。

## 4. 技能导入

- GitHub 导入不再显示、也不要求填写提交 SHA。「读取技能」有仓库地址即可点。读取时自动锁定当前提交。导入过程也不再展示源文件校验 SHA。
- 远程检索「导入审批」会带上技能子目录（例如 `review`、`skills/docx`、`weekly-report`），不再只填仓库根地址导致按钮无反应。在线 GitHub 目录名也会套上本地中文标题，搜「周报」仍能命中。
- 粘贴 `github.com/...`、`www.github.com`、带查询串或 `SKILL.md` 文件地址也能识别。
- 上传 `.zip` / `.skill` / JSON 仍导入为草稿，可查看目录、在对话中试用，再安装并正式发布。

## 5. MCP 市场

- 市场只留一键安装的免费服务：点加号即可，Filesystem 自动用本机沙箱目录，不再弹出参数框。
- 需要 Token、付费 API、OAuth 或自备连接串的条目已下架（含聚合数据、Tushare、高德、Notion、飞书、Postgres 等）。已装的仍可在「已安装」里删或配凭据。
- 某一个 MCP 连不上时，不再把整页说成「Node.js / npx 不可用」。npx 服务正常时，Fetch 这类 uvx 服务会单独提示缺少 uv。
- 对话里的 `mcp.install` 与市场一样一键装：Filesystem 自动用沙箱目录，不再向用户要路径或密钥。
- 已安装卡片没有名字时显示「未命名 MCP」，重新连接失败会带上服务名。
