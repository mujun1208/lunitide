# Lunitide 0.5.8

0.5.7 装上之后：Agent Hub 里上一轮的回答会整段带进下一轮气泡。让它找一部电影或一首歌，播不进产品自己的媒体中心。网页里能播的片子也不会转过来。技能目录、安装和发布对不上真实工具，任务会停在「没有这个工具」。读不出来的附件或图片会把整轮对话打断。做演示文稿会停下来问你选风格。0.5.8 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.5.7 可直接覆盖安装。不要覆盖 `v0.5.7` 及更早 tag 的 digest。不要重打 `v0.5.7`。本包挂 GitHub Latest，应用内更新读 `latest.json` 下这一版。

## 1. Agent Hub 不再把上一轮答案带进下一句

- 新的一轮只记录这一轮的问题。上一轮助手正文不再整段贴进下一个气泡。

## 2. 媒体中心播放你要的片子和网页里的媒体

- 说找一部电影或一首歌，会在产品自己的媒体中心里播。没有点名时，用公有领域的《活死人之夜》片段，不下载商业片库。
- 网页里能直接播放的音视频，转到媒体中心播放。对话里合成的朗读仍留在对话里听，月伴说话的音色不变。

## 3. 技能、知识和办公能往下做

- 可以按产品自带目录列出、安装、发布技能，也可以直接按随产品发布的正文来做，不必先写进技能库。已经发布的技能再发布一次，不会报状态错误。
- 知识检索没有材料时会说明缺了什么，不会停在「没有这个工具」，也不会编造图谱邻居或章节号。
- 做演示文稿不再问风格或品牌。没有合适模板时，按封面、章节、议程、正文、数字、对照、引用、时间线和结尾来排。跨组织生成会用中文说明先切换组织。
- 周报只写会话里已有的事实，不编造完成率或节省百分比。

## 4. 附件读不出来时，这一轮仍然继续

- 文件夹里的文件会递归带上。正文抽不出来，或图片读不出画面，对话会记下文件名并继续，不会整轮中断。
- 当前对话模型没有视觉时，会改走 OCR。打开网页或搜索之后，如果只要打开，就不再接着用电脑去点页面。

## 5. 不做

- 不重打 `v0.5.7` 及更早。
- 不改月伴音色、月亮外观和星尘配方。
- 不提供盗版影视或商业曲库下载。
- 不把「任务一定成功」写成承诺。
