# Lunitide 0.7.0

装上 0.6.0 之后：分好几步的任务会在文件刚写出来时停住，或者按续轮拆开，做不完就要你再说一次「继续」；任务过程文字很多时，过程和对话转圈会有一边卡住，离开页面再回来才一起动；生成的网页在应用里是静态的，按钮和本地保存点了没反应；上一轮放歌失败的话会串到下一轮打开浏览器；在已经打开的软件里打字，焦点不在输入框就失败；听写有时把一整句收成最后几个字；播放成功过一次，下次仍从别的播放器重新试。0.7.0 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.6.0 可直接覆盖安装。不要覆盖 `v0.6.0` 及更早 tag 的 digest。不要重签 `v0.6.0`。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 多步任务一次做完

- 清单还没做完时，同一轮里继续调用工具把剩下的步骤做完，做完一步就更新整份清单。
- 允许停下来再被推着做的次数等于清单的步数。四步就是四次，不会按每步三次拆成十二轮。
- 工具一直在调用时，不消耗这些次数。整轮最多 72 步，没有新进展就停。
- 清单还有未完成步骤时，模型超时不会因为已经写了文件就结束这一轮。清单都完成之后，超时只说明文件已经在，可以直接打开。

## 2. 过程和转圈一起动

- 任务过程很长时，生成中只显示最新一段，并和对话状态同一帧刷新。
- 不用离开对话再回来，过程和转圈才会重新对齐。

## 3. 生成的页面可以操作

- 对话里打开的 HTML 在独立预览地址里运行脚本。菜单、按钮和这一页自己的本地保存会响应。
- 用本机绝对路径打开时，也会进这个可操作预览，不再退成静态页。
- 在页面里选中文字，会作为引用放进输入框，发送前可以改。
- 这个预览不连外网，也不读应用自己的数据。网页搜索摘录仍是静态的。

## 4. 浏览器、打字、听写、播放

- 这一轮是打开浏览器或搜新闻时，不再把上一轮放歌失败的话再说一遍。搜索页已经在系统浏览器里时，点第一条用电脑操作，不再另开一个空白的受控浏览器。
- 往已经打开的软件里打字时，会先点开发消息框再输入、再发送。
- 听写先听到的长句还在，后面补上的短尾不会把它盖掉。
- 用电脑操作播放、话里没有歌名时，不会把操作说明当成歌名。播放器已经在放，就记成成功，并记住这个播放器，下次优先用它。没确认在放的具名歌曲不会被记住。
- 媒体中心的控制条在几秒后收起，音量可以拖，进度可以拖，也可以关掉这一条。

## 5. 不做

- 不重签 `v0.6.0` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不把 SenseVoice 换成默认听写，也不安装 FunASR、Codex 插件、AnySearch 或仓颉工具链。
- 不把应用内的 browser.close 接上，也不把每一次对话都升到最高执行档。
