# Lunitide 0.4.97

0.4.96 装上之后，月伴「打开记事本 / 打开网页」仍会报「模型请求失败」；MCP「检查并修复 / 重新连接」会被一次握手失败钉成红卡；长聊 Length 截断不重试当前句；Chat 侧栏「项目」和 `@` 专家串台。0.4.97 把这些合同收口进 Host。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。**本职 9.5 要装上本包后再跑场验清单，本说明不报 9.5。10 分仍要 14 天 soak。**

已装 0.4.96 可直接覆盖安装。不要覆盖 `v0.4.96` 及更早 tag 的 digest。不要重打 `v0.4.96`。GitHub Latest 除非再次点名，否则不自动改挂。

## 1. 月伴打开

- 目标进程或可见窗口在，即使被月汐挡住，也算打开；没有进程才说未确认。
- 「打开网页…」走 `desktop.browse`，不再被「只许 desktop.open」挡住。
- 工具目标空答（打开记事本 / 打开网页 / 把报告弄好）会放宽工具面再试一次。天气、问候不放宽。

## 2. MCP

- 人点「检查 / 重连」不再把一次失败写成降级或检疫。成功仍写 ready。
- 检疫不自动解封。「检查并修复」仍对照市场版本重装。

## 3. 长聊超窗

- `FinishReasonLength` 按检查点收面后，**同一句用户消息重试一次**。内容过滤仍只打一轮。
- 源用户句不删。

## 4. 表面

- Chat 和 Agent Hub 侧栏都能折「项目」。
- `@` 只出联系人和本会话消息；专家走「选专家」。
- 项目管理去掉 hero 装饰。

## 5. 不做

- 不重打 `v0.4.96` 及更早。
- 不加公网 Gateway，不加无人批准的 `skill_manage`。
- 不把综合尺 10 分说成本职完成。装上后按场验 7 行打勾。
