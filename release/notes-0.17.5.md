# Lunitide 0.17.5

上一版装好后，移动伴侣走了"电脑和手机都装 Tailscale 组虚拟网"的路——结果国内环境下手机端登录不上、中继被阻断，装了反而更糟：手机半连接的尾网地址被排到候选第一位，二维码首选地址永远不可达，连本来好好的同一个 Wi-Fi 都打不开配对页、识别不出电脑。这一版彻底放弃 Tailscale 依赖，改成**多地址直连**：二维码同时携带本机全部可用地址，手机扫码后自己探测哪条路通就走哪条，Wi-Fi 和蜂窝流量都不需要装任何额外软件。

## 同一个 Wi-Fi：修好并钉死

- **候选地址排序修正**：配对二维码首选地址从"尾网置顶"改回**局域网 IPv4 置顶**——同一 Wi-Fi 下必达、零依赖。尾网（Tailscale/ZeroTier 的 100.x 地址）降到**最后兜底**，只有其余通道全不通时才尝试。
- **排序契约写进了测试**：局域网 IPv4 → 公网 IPv6 → 尾网垫底的顺序用确定性单测钉死，这个回归不许再来。

## 蜂窝流量免 Wi-Fi：扫码即用

- **二维码携带全部候选地址**（新增 `al` 参数）：首选地址之外，公网 IPv6 等其余候选一并编进二维码。手机不再被单地址绑死——首选不可达时不是干等超时，而是并行探测全部候选、直接加载第一个可达的。
- **公网 IPv6 直连是主路径**：电脑挂在家宽、手机用蜂窝，两端都有 IPv6（国内运营商默认下发）即可点对点直连，零成本、零中继。本版发布前实测：本机 4 个中国移动公网 IPv6 候选全部可达，配对页正常打开。
- **换网自动恢复，不用重新扫码**：手机在 Wi-Fi ↔ 蜂窝之间切换导致断线时，远程连接按候选顺序轮换重连，自动落回当前网络下可达的地址。

## 防火墙放行：提权链路实证修复

- **修掉一个从未真正生效的环节**：开启远程访问需要弹 UAC 添加 Windows 防火墙入站规则（放行 47651 端口），旧版提权命令的引号处理有缺陷——UAC 你点了"是"，规则实际没建上，端口放行全凭运气。修复后本机实测：提权建规则、验证存在、删除干净，全链路真实通过。升级后重新开启一次远程访问，规则即正确落地。

## 桌面面板：尾网地址如实归类

- 移动伴侣设置页把尾网地址**单独列出**并注明"需手机登录同一虚拟组网，仅作兜底"，不再混在局域网地址里误导判断。

## 你需要做的两件事

1. **卸载手机上的 Tailscale**（如果装过）——本版不再需要它，半连接状态反而会拖慢探测。
2. **重新扫码配对一次**：旧配对仍然有效，但只有新二维码才携带全部候选地址，重扫后手机才能获得换网轮换能力。

## 不改什么

- 不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。
- 不改既有界面布局与交互习惯。
- 不做云账号、不做官方中继服务器；自托管中继（M4）仍为预留设置项。

## 兼容与覆盖安装

- Windows 端直接覆盖安装即可，配置、会话与数据全部保留。
- 更新源只认最新版本；本版安装包不得覆盖更早 tag 的 digest。
