# Lunitide 0.12.0

装上 0.11.0 之后：点附件按钮从文件对话框选文件，选中的文件还是要整份切块传一遍；拖文件进来时，后台偶尔会把同一批文件登记两遍。0.12.0 把这两条收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.11.0 可直接覆盖安装。不要覆盖 `v0.11.0` 及更早 tag 的 digest。不要重签 `v0.11.0` 及更早版。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 文件对话框选的文件

- 点附件按钮选文件，和拖进来一样按你选中的本机路径登记，不再把整份文件切块重传。
- 路径只认你在对话框里亲手交给这一批的文件，页面报不出别的名字。
- 一次最多 20 个文件走路径登记；一批超过 20 个，整批退回上传办法，附件照常能发。

## 2. 拖放更稳

- 拖进首页或对话时，两条通道谁先到用谁，同一批文件不会登记两遍。
- 老版本运行环境、主机没回话或只回了一部分时，自动退回 0.11.0 的上传办法，不会卡住。

## 3. 首页与对话一致

- 首页选好的附件带进对话后，路径登记关系保持不变。

## 4. 不做

- 不重签 `v0.11.0` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不改媒体中心的歌曲和视频来源。
- 不提高单轮步数上限，不合并办公流水线。
