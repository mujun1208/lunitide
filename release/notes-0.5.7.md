# Lunitide 0.5.7

0.5.6 装上之后：让汽水音乐播放、暂停、上一曲、下一曲或关掉软件，经常点不准、停不住，或者自己再试一次。打开网页时浏览器拉不起来，同一句话里会再试第二遍。把桌面上的文档路径发给它，它说系统找不到路径；PDF、Word、Excel 拖进对话会被跳过。产品总览打开时用的是上次保存的快照，健康数字和功能说明对不上当前这一版实际有的页面。0.5.7 把这四件事收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.5.6 可直接覆盖安装。不要覆盖 `v0.5.6` 及更早 tag 的 digest。不要重打 `v0.5.6`。本包挂 GitHub Latest，应用内更新读 `latest.json` 下这一版。

## 1. 汽水音乐和关掉软件

- 播放、暂停、上一曲、下一曲走系统媒体键，按软件名对准汽水音乐这一路，不再只认精确的应用标识。
- 只发了播放键、还没从系统会话里读到正在播放时，会告诉你已经让它播放，同时标成未核实，不会说成已经在播。
- 「关掉汽水音乐」只退出那个程序。关一个窗口不会把整个软件退掉。

## 2. 浏览器启动失败就停

- 网页操作改用本机已安装的 Edge。Chromium 起不来时，这一步停在「浏览器没能启动」，同一句话里不再自动再开一次浏览器，也不改用屏幕点击去补。
- 已经装过的 Playwright 预设如果缺浏览器参数，下次握手前会补上，并清掉旧的固定指纹，避免下一次握手被判成漂移。

## 3. 本地文件、文档和网页链接

- 完全访问模式下，对话里给出的绝对路径（TXT、MD、CSV、JSON、日志、PDF、Word、Excel、PPT、常见图片）会直接读出来，不再被拼到会话目录下面导致「系统找不到路径」。
- 对话可以带上 PDF、Word（.docx）、Excel（.xlsx）、PPT（.pptx）。GIF、BMP 会转成预览能看的图。旧版 .doc / .xls 仍然不收。
- 网页抓取跟随跳转的次数提高到上限。抓取失败时，预览里留下网址和原因。需要登录的飞书文档仍然读不到正文。

## 4. 产品总览对照当前说明书

- 打开产品总览会按当前页面、设置、媒体动作、插件和动词重算覆盖，不另存一版快照，也不改业务代码。
- 每张功能卡写清怎么进入、这一卡管什么。诊断报告里的新增、更新、退役和未闭合来自这次对照，不再写死样例数字。
- 「不再处理」会记在快照里。重新检测才写入新快照。执行净化只改目录标签，不改 Go 或前端业务源码。

## 5. 不做

- 不重打 `v0.5.6` 及更早。
- 不改月伴音色、月亮外观和星尘配方。
- 不把产品总览的健康分说成产品已经完美。
- 不自动改业务代码来「修」诊断里的缺口。
