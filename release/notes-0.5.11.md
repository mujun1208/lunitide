# Lunitide 0.5.11

装上 0.5.10 之后：要一个能打开、能点、能存数据的演示系统，结果仍可能变成 PPT，或者把启动命令留给你自己去终端里贴。对话一打开就会在数据目录里多出一个空文件夹。模型强度只有开和关，看不清这一轮用了多深。界面在纯黑底上发灰。0.5.11 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.5.10 可直接覆盖安装。不要覆盖 `v0.5.10` 及更早 tag 的 digest。不要重打 `v0.5.10`。本包挂 GitHub Latest，应用内更新读 `latest.json` 下这一版。

## 1. 可以演示的系统会在本机自己跑起来

- 你要的是可操作页面、数据交互和存储时，不再改写成 PPT。周报、Word、Excel、演示文稿仍走原来的办公文件。
- 模型如果把 `python` 或 `node` 启动命令留给你去外面执行，产品会按它写的解释器在本机把服务拉起来，并在回复里给出地址。不用再复制命令到终端。

## 2. 模型使用强度

- 支持的模型上可以选低、高、极高。默认是高。选择会记住。
- 月伴语音不带这个强度，避免把打字时的深度设置套进语音回合。

## 3. 产物放进这一次对话的文件夹

- 设置里的「数据存储路径」是全产品的产物根目录。生成的文件落在「根目录 / 这一次对话」。
- 只是打开对话、或新建会话，不会先建一个空文件夹。写出产物，或你点「打开」，才会建立这个目录。
- 明确要放到桌面的文件仍去桌面。完全访问下改项目源码，仍写在你选中的工作区里。

## 4. 界面

- 深色底换成炭灰，极光、潮汐色和黑白切换还在。
- 技能市场、MCP 市场、插件市场、专家市场的卡片带上小图标、名称和一行说明。技能库、已安装、安装升级卸载、权限、版本和修复仍在。
- 项目管理和资产库的标题区有插图。列表、搜索、筛选、创建和上传不变。

## 5. 月伴插话

- 上一轮还在想、在用工具、或只说了开头时，你接着说的下一句会记下，这一轮说完再回，不会把正在做的事停掉。
- 喇叭里正在念的回复漏回麦克风，不会被当成你的下一句。
- 对着已经说出来的回复插话，以及明确说「撤了」或点打断，仍会停。

## 6. 不做

- 不重打 `v0.5.10` 及更早。
- 不改月伴音色、月亮外观和星尘配方。
- 不提供盗版影视或商业曲库下载。
- 不把「任务一定成功」写成承诺。
