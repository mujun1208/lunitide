# Lunitide 0.11.0

装上 0.10.3 之后：把文件拖进首页或对话，大文件仍要切成一块一块重传，进度会停在那里；点了允许之后，同一件事还会再开一轮。0.11.0 把这两条收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.10.3 可直接覆盖安装。不要覆盖 `v0.10.3` 及更早 tag 的 digest。不要重签 `v0.10.3` 及更早版。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 拖进对话

- 从资源管理器拖到首页或对话时，按你选中的本机路径登记，不再把整份文件切块重传。
- 附件卡片显示类型和大小，例如 DOCX · 67.6 KB，不显示百分比。
- 剪贴板里的图片仍按图片发送。
- 没有经过这次选择的路径读不进来。
- 超过 500MB 的文件在读取前就会拒绝。正文超过 32MB 时，文件会完整保存，对话里只带开头，或说明正文没有整份放进来。

## 2. 允许之后接着做

- 点允许之后，结果写回正在进行的这一轮，不再另开一轮把同一个工具做第二遍。
- 需要你打字回答的提问，仍然作为下一条消息发出。
- 压缩或摘要读失败时，这一轮用已经有的上下文继续。取消和超时仍会停。
- 这一轮只是让模型读附件时，不再同时摆出整套改文件和跑命令的工具。你要它执行时，在这句话里说出来。

## 3. 首页输入

- 首页输入框和对话里一样，可以选择推理强度、执行方式，并打开模型管理。

## 4. 不做

- 不重签 `v0.10.3` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不把联系人里发给对方的文件改成对话附件。
- 不提高单轮步数上限，不合并办公流水线。
