# Lunitide 0.18.1

0.18.0 有两个显眼的问题：一是联网搜索结果的标题会变成一串粘连文字，比如 `caict.ac.cnhttps://www.caict.ac.cn › kxyj › qwfb › bps › …`——站点域名和链接黏在一起，既不是标题也没法点；有的结果摘要整段丢失；摘要里还会残留 `&ensp;` 这样的原始代码。二是对话的日期时间没有显示出来。这一版把两件事都修好。

## 搜索结果恢复为正常标题和完整摘要

- 每条结果的标题现在取自结果页的**真实标题**（如「中航材利顿航空科技股份有限公司 - 爱企查」），不再是域名和链接粘连的串。
- 摘要不再被结果内部的「阅读更多」链接截断，完整保留到段落结束。
- 摘要中的空格类字符（`&ensp;` 等）正常解码为空格，不再以代码形式残留。
- 三级搜索回退（DuckDuckGo Lite → 必应（中国）→ 必应）行为不变，只是必应降级页面的解析修正了。

## 对话日期时间显示

- **左侧对话列表**：每个对话右侧显示最后活跃时间——今天显示「HH:mm」，今年显示「MM-DD HH:mm」，更早的显示日期。
- **对话内每条消息**：每轮消息上方显示完整时间「YYYY-MM-DD HH:mm:ss」。个人对话页此前把这行整个隐藏了，现在只隐藏 USER/AGENT 身份标签、时间照常显示。
- 生成中的回复也显示本轮开始时间和状态（生成中…/已回复等）。

## 不改什么

- 不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。
- 不改搜索源顺序、审批模式语义、已连接 MCP 配置。

## 兼容与覆盖安装

- Windows 端直接覆盖安装，配置、会话、记忆、已配对信息全部保留。
- 更新源只认最新版本；本版安装包不得覆盖更早 tag 的 digest。
