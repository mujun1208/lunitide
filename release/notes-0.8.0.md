# Lunitide 0.8.0

装上 0.7.0 之后：点名要看的电影仍播成同一部公版片；点名要听的歌打不开你已登录的网站；会员登录关了窗口就丢；做长任务时会在几十步或几分钟时停住，并告诉你到了上限；截图识别会卡住；超过 10 MiB 的附件传不上去；演示文稿预览是一张白页；应用里的网页不能点。0.8.0 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.7.0 可直接覆盖安装。不要覆盖 `v0.7.0` 及更早 tag 的 digest。不要重签 `v0.7.0`。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 点名的电影和歌曲走官方页面

- 打字说要看某一部电影时，打开爱奇艺官方搜索，并给出优酷官方搜索。会员在这两个官方页面里播放，媒体中心不再拿另一部公版片顶上。
- 没点名、只说找一部电影时，媒体中心仍播放公版《Night of the Living Dead (1968)》。已经能直接播放的公版文件仍在媒体中心播放。
- 打字点名一首歌时，打开网易云音乐官方搜索。汽水音乐仍用本机已安装的桌面软件。不抓取这两个网站的音频地址。

## 2. 会员登录留在应用浏览器里

- 爱奇艺、优酷、网易云在应用自己的浏览器窗口里打开。第一次登录会记住，下次打开同一网站不用再登。
- 这个窗口可以保存密码、粘贴、使用网页自己的登录弹窗，也可以下载。它和主窗口分开，不开放调试接口，也不访问内网。

## 3. 长任务可以做完

- 同一轮工具调用可以一直做到 240 步、约 3 小时。写到一半会接着写，不再在几十步时停住。
- 已经查完并总结过的新闻不会被再推着点一次。准备步骤连续没有新进展时仍会停。
- 对话过程里不再对你说步数、额度或上限。较早的内容太长时会先收起，当前这一步接着做。

## 4. 附件、幻灯片、应用内网页

- 对话、资产库和办公工作室的单个文件可以传到 500 MiB。项目交付物仍是单次 10 MiB。
- 资产库里有一份可用的演示文稿模板时，按那份模板填；没有模板时仍生成一份完整文稿，预览里能看到每一页的形状。
- 工作区里的网页可以点、可以填。脚本在隔离预览里运行，不连外网，也不读应用自己的数据。需要登录的官方页面用旁边的应用浏览器窗口。

## 5. 语音里的新一句

- 正在做别的事时，说「打开新闻」或「点开第一条」会改做这一条，并点击结果，不再并进上一句的文章里。
- 截图识别读到字就停，不再把每张图都转四次。

## 6. 不做

- 不重签 `v0.7.0` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不把 SenseVoice 换成默认听写，也不安装 FunASR、Codex 插件、AnySearch 或仓颉工具链。
- 不把应用内的 browser.close 接上，也不把每一次对话都升到最高执行档。
- 不从爱奇艺、优酷、网易云抓取播放地址。
