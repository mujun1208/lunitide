# Lunitide 0.5.6

0.5.5 装上之后：月伴里让它做事，经常一开口就是「已达上限」，并叫你新开对话。月伴是同一个长期会话，额度按整个会话往上加，加满之后下一句也被拒。打字对话用久了会碰到同一笔账。上下文装不下时，提示也写成额度用完。思考用掉的 token 超出预留时，这笔预留会卡住，后面的轮次更早被挡。0.5.6 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.5.5 可直接覆盖安装。不要覆盖 `v0.5.5` 及更早 tag 的 digest。不要重打 `v0.5.5`。本包挂 GitHub Latest，应用内更新读 `latest.json` 下这一版。

## 1. 月伴不再被额度拦住

- 语音对话不进执行额度。说完一句再做下一句，不会因为这个会话已经用了很久而被拒绝。
- 一句话里面的评议会、桌面核对，跟着这句语音一起豁免，不会中途又被记进额度。
- 语音仍然只带最近几轮原文和当前摘要，回复长度仍按短开口来。省 token 的方式和额度是两回事。

## 2. 打字按这一轮算

- 打字的额度按这一轮用户消息计算。这一轮里的工具循环有自己的上限，下一句重新开始。
- 真的把这一轮的额度用完时，提示是「本轮执行额度已用完，请再试一次。」不再要求新开对话。
- 请求超出模型上下文窗口时，单独说明「请减少附件或历史后重试」，不再和额度用完混成一句。

## 3. 思考超出预留时账能结清

- 模型思考 token 超过这一次预留时，结算可以记成超出并完成。此前数据库不接受这种记录，预留会永远停在占用中，后面的调用更早碰到上限。

## 4. GLM 与 DeepSeek

- 同一会话从 DeepSeek 换成 GLM，或换成没有专属协议的模型时，不再把上一个模型的私有思考原文塞进新请求。正文、工具回执和摘要仍在。
- 同一族模型之间仍按原协议续接。GLM 不能关闭思考时，仍按产品合同收成最低思考强度。
- 对话过长需要压缩时，按你为该模型配置的上下文窗口计算。语音说完后再压，不挡第一句开口；压缩失败会留在日志里，这一句照常结束。

## 5. 不做

- 不重打 `v0.5.5` 及更早。
- 不改月伴音色、月亮外观和星尘配方。
- 不把未做线上探测的模型画像窗口写进安装包。
- 不把综合尺 10 分说成本职完成。
