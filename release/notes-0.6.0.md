# Lunitide 0.6.0

装上 0.5.18 之后：资产库还不能把 PPT、Word、Excel 模版交给办公平台当底稿；一次放进多份仍要逐份填名字；产品中心点「重新检测」只重算入口覆盖，不跑听写、播放、下载和图片识别；媒体中心播放没有声音，音量也不好调；首页和关于页的月亮没有动画和光圈；窗口图标下面没有云彩线；本地语音包在公开仓库里已经换过一版，重试下载仍按旧大小拒绝；聊天里发图片时，本机文字识别有时读不完。0.6.0 把这些收口。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。

已装 0.5.18 可直接覆盖安装。不要覆盖 `v0.5.18` 及更早 tag 的 digest。不要重签 `v0.5.18`。本包挂 GitHub Latest，应用内更新从 `latest.json` 下这一版。

## 1. 办公模版

- 资产库可以上传 PPT模版、Word模版、Excel模版，只收 .pptx、.docx、.xlsx。
- 上传后状态是「创建」。启用之后，办公平台首页可以选择这份模版当底稿，在这份文件上修改并输出。
- 「批量入库」一次选多份 .pptx、.docx、.xlsx。当前对话模型根据文件里的文字起一个中文名字和一行说明。模型没有，或文件里读不出文字时，名字用文件名，说明写成「办公模版」。原来的文件名保留。状态仍是「创建」，这一步不启用。
- 旧的 .ppt、.doc、.xls 不会入库。文档模版和脚手架仍走原来的表单。

## 2. 重新检测跑真实任务

- 点「重新检测」会去跑听写、播放、语音包下载检查和图片识别，并记下链路错误、反复失败和报错。
- 跑完之后，诊断环是这一轮实测的通过比例。图景页上选来对比的产品不计入这个分数。
- 还没点「重新检测」时，环仍是入口覆盖，表示这一版说明书和活源对齐。
- 诊断不改产品代码。净化仍只给目录重打标签。

## 3. 媒体中心的声音和进度

- 从聊天打开的音视频可以出声，能暂停、拖进度、调音量，也能全屏。
- 状态写成「正在播放」或「已暂停」。关掉的记录里仍能看到这一条命令。

## 4. 月亮和图标

- 首页「今天想聊什么」和关于页用带动画和光圈的月亮。
- 窗口、任务栏和快捷方式图标是大月亮，下面有云彩线。

## 5. 语音包和图片文字

- 本地语音包的校验跟上公开仓库里重新发布的那一包。装上这一版后再点重试下载，会按新的大小和校验收包。
- 聊天里发图片时，本机文字识别能把文件读完。

## 6. 不做

- 不重签 `v0.5.18` 及更早版。
- 不改月伴音色、玉盘像素和星尘配方。
- 不把 SenseVoice 换成默认听写，也不安装 FunASR、Codex 插件、AnySearch 或仓颉工具链。
- 还没点「重新检测」时，不把诊断环说成语音、播放或任务的实测分。
