# Lunitide 0.19.0

0.18.x 把「听懂你要查什么」修到了句子级，但还有一类更深的问题：意图一旦判错，整轮对话的可用工具就被判错的那个档位锁死——裸实体、催促句这些 0.18.3 修过的事故之后，任何一个新的措辞形态还会踩同一个坑。这一版把根源拆掉：意图判断从此只决定「花多少预算、用什么语气」，不再决定「能用哪些工具」。误判的代价从「整轮报废」降到「多花几步预算」。

## 误判不再丢能力

- 以前：一句没认出来的话会被分到某个精简档，联网搜索、文件写入这些工具直接从工具表里消失，助手只能道歉。
- 现在：任何一轮对话，工具表都是完整能力面。意图判断只影响步数预算与提示词引导。你换任何说法——哪怕是完全没见过的措辞——助手都拿得着全部工具。
- 0.18.3 修过的「裸实体」「查询啊」两类事故在新架构下整类收口，不再依赖逐个措辞打补丁。

## 没有材料，先问清或先核实，不再硬编

- 你说「帮我写周报」但没给任何材料时，助手会先用一句话问清缺什么（一次问清即停），或者先联网核实——只有「无材料却直接生成」会被拦下。
- 生成类调用被拦时你会看到明确提示，不会静默失败。
- 绑定了参考文档、或明确说「不联网、用下面内容」的轮次不受影响，直接进入成稿。

## 打开就是打开，不再画蛇添足

- 「帮我打开这个文件」完成后，助手不会再自作主张读一遍内容又生成一份新文件。
- 你明确说「转换 / 另存 / 修改」时，这个保护自动让位。

## 媒体续播、余票查询的既有保护全部保留

- 「下一首」「暂停」直接走内置播放会话，不会抽歌名去联网搜索。
- 余票/行情类查询在无可用数据源时仍然 fail-closed：明确告诉你没接入，不再空转。

## 预算升级：小档误判中途自动加力

- 对话分三档预算：闲聊 4 步、任务 12 步、代理 24 步。闲聊轮仍然快、省 token。
- 一句话被误判成小档、预算快用完又一事无成时，自动升一档接着做（每轮最多升两次），不再「宣布计划然后预算耗尽」。

## 不改什么

- 不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。
- 不改审批模式语义、已连接 MCP 配置、token 台账。
- 桌面操作、浏览器、代码/电脑控制能力一项不收——这次重构只动「怎么分配预算」，不动「有哪些能力」。
- 会话恢复与历史记录兼容，旧版本数据直接继续用。

## 兼容与覆盖安装

- Windows 端直接覆盖安装，配置、会话、记忆、已配对信息全部保留。
- 更新源只认最新版本；本版安装包不得覆盖更早 tag 的 digest。
