# Lunitide 0.17.6  上一版把多地址直连修通了，但移动伴侣的**使用流程**还有一连串硬伤：扫码要把手机横过来、下载的 APK 文件名没版本号分不清新旧、浏览器扫码直接让配对而不是先装 APP、配对成功后连不上电脑时界面白屏卡死没有出口。这一版把配对→使用的整条链路重新梳理了一遍。  ## 扫码不再横屏  - 内置扫码器默认强制横屏，用户必须把手机转 90° 才能对准二维码。现在取消方向锁定，竖屏直接扫。  ## 下载文件名带版本号  - 网关对 APK 下载响应加了 `Content-Disposition`，下载文件名从 `lunitide.apk` 改成 `Lunitide-Android-<版本号>.apk`，覆盖安装前一眼能看出新旧。 - APP 欢迎页和连接错误页也显示当前版本号。  ## 扫码先下载，再配对  - 手机浏览器扫描二维码后，页面**优先**展示「下载安装 Lunitide APP」大按钮，配对表单降级为折叠的「继续用浏览器配对（不推荐）」。 - 正确流程：扫码 → 下载安装 APP → 打开 APP → APP 内扫码配对。装完 APP 不需要在浏览器里配对。  ## 连不上电脑不再白屏  - WsTransport 的连接状态（connecting / open / reconnecting / closed）现在实时通知安卓壳。 - 连接建立后 15 秒内仍未连上（或网关主动断开），壳会弹「连不上电脑」错误页，提供「清除并重新扫码配对」和「重试连接」两个出口——不再停留在白屏或历史页面上。 - 「清除并重新扫码配对」会删除已保存的网关凭据，回到欢迎页重新扫码，电脑换网络、被吊销、或配对失败后走这条即可恢复。  ## 不改什么  - 不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。 - 不改既有界面布局与交互习惯。 - 不做云账号、不做官方中继服务器。  ## 兼容与覆盖安装  - Windows 端直接覆盖安装即可，配置、会话与数据全部保留。 - 安卓端用新 APK 覆盖安装即可。 - 更新源只认最新版本；本版安装包不得覆盖更早 tag 的 digest。
