# Lunitide 0.5.4

0.5.3 装上之后，Work 里和 Cursor 对话时标题栏按钮叠在一起；技能中心同名技能重复堆积；专家「自动匹配并保存」会把全部已装技能和 MCP 勾上；从技能/专家/插件点创建仍停在 Work，Chart 标签对不上；插件市场失败包按钮写「继续操作」，点修复再点继续安装仍上不去；办公菜单行距过宽。周报技能只挂在会议包，报告专家和报告写作包对不上。0.5.4 把这些收口进同一版。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。**本职 9.5 要装上本包后再跑场验清单，本说明不报 9.5。10 分仍要 14 天 soak。**

已装 0.5.3 可直接覆盖安装。不要覆盖 `v0.5.3` 及更早 tag 的 digest。不要重打 `v0.5.3`。本包挂 GitHub Latest，应用内更新读 `latest.json` 下这一版。

## 1. Work 标题栏

- AgentHub 线程页不再画「返回 / 新对话 / 在对话中打开」。这些入口只留在侧栏和 Chart/Work 切换，避免和标题、工作区按钮叠在一起。

## 2. 技能中心

- 同名技能（含 `tpl-` 前缀）只保留最新 semver；载入时删掉旧副本。
- 市场安装：更新版可覆盖，同版本拒绝，更旧版本不允许。
- 对话自建技能会带上已有技能清单，提示在原技能上升级，不要再造一份同名。

## 3. 专家中心

- 清单每行显示该岗位匹配的技能数和 MCP 数（工厂包优先，没有工厂包再按名称/条线推断）。
- 「自动匹配并保存」按岗位描述勾已安装的技能和 MCP，不再全选。
- 「岗位需要但技能库还没有」点按钮在本页安装捆绑模板，不是网上检索。
- 报告编写专家挂上 `weekly-report`。

## 4. Chart / Work

- 从技能、专家、插件点创建（以及技能试用、打开非同事专家）会切到 Chart，标签和对话页一致。

## 5. 插件

- 失败组合包按钮统一为「复核并修复」。
- 修复仍失败时先撤下再重装，避免「继续安装」卡在同一条坏记录上。
- 报告写作包带上周报技能。

## 6. 办公菜单

- 办公子项行高从 30px 收到 24px。

## 7. 不做

- 不重打 `v0.5.3` 及更早。
- 不加公网 Gateway，不加无人批准的 `skill_manage`。
- 不把综合尺 10 分说成本职完成。装上后按场验清单打勾。
