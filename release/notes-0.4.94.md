# Lunitide 0.4.94

0.4.93 装上之后，媒体中心选本地文件再播放会把 Host 打退，再开也会跟着退。设置里的运行状态还停在 Chat 前台。长会话撞上窗口溢出、无动词目标收面漏召、Hub 线程和对话会话也对不齐。0.4.94 把已经接线的媒体 COM 修复、设置指示灯、溢出重试、工具面放宽、Hub 投影和记忆提名整理收进安装包。覆盖升级仍走 GitHub `latest.json`。不改 poison / 月伴 TTS 音色 / 玉盘像素 / 星尘配方。不声称产品 100%。不把 AgentHub 焊进 SessionPage。不重做办公 PPT 视觉稿。不把本机 OCR 换成 PaddleOCR-VL-1.6。

已装 0.4.93 可直接覆盖安装。`v0.4.94` 的 Setup + `latest.json` 挂到 GitHub Latest。不要覆盖 `v0.4.93` / `v0.4.92` / `v0.4.91` / `v0.4.90` / `v0.4.89` / `v0.4.88` / `v0.4.87` / `v0.4.86` / `v0.4.85` / `v0.4.84` 的 digest。不要重打 `v0.4.93`。

## 1. 媒体

- 本地媒体票的 WebView2 响应在 UI 等待里 Complete 并 Release，不再把 COM 指针带出 STA 再放。
- 只有用户要点播放才会打开播放地址；杀 Host 再开不会因为恢复快照自动出声或重开票。
- 同一资源同一轮次已打开则不再重铸地址。

## 2. 设置指示灯

- Chat / 月伴 / 主页不再出现「运行状态」。点设置就能看见四盏灯：工具、识别、媒体、诊断。
- 没活动是绿灯；不确定是黄灯；失败是红灯；总览取最差一盏。MCP 被隔离是黄灯，其它诊断降级是红灯。
- 打开设置会幂等跑一遍压缩 Recover 和运行扫描；失败只记日志，不挡页面。不自动解封 MCP。

## 3. 长会话与调度

- 只有 `model_context_window_exceeded` 会压缩当前步再试一次。`length` / `max_tokens` 仍按截断失败关闭。
- 月伴热路径仍跳过回合前压缩；超窗走冷路径检查点，不靠「嗯」假出字。
- 无动词目标若本步没收工具，会用完整工具面再试一次。问候、天气闲聊不触发。不加新关键词表。

## 4. Work / Hub / 记忆

- Agent Hub 线程绑到同一条 `message.append` → `chat.start` 会话。线程页有「在对话中打开」。Hub 仍是 PATH 子代理，不另起大脑。
- 空闲后整理和压缩前 flush 只产生记忆提名，人点确认才注入。设置里能看见待确认列表，可撤回。过期或重复 gist 只撤回提名。
- 电脑控制未绑定 GUI 时，「三步启用」不可点。会议截图未绑定视觉能力时按钮不可用。对外只说：月汐是这台 Windows 电脑上的本地优先办公助手——对话、工具、记忆、办公、语音、审批，在这一台机器上做完。

## 5. 发布

- GitHub Latest 指向 `v0.4.94`。旧版 tag 保留。本地只保留这一次签名安装包。
